### INC-09349  [↗](/incident/INC-09349.html)

**Svelte: XSS via HTML Comment Injection in SSR Error Boundary Hydration Markers**  
_2026-02 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-27901`, `CVE-2026-27902`
CWEs: `CWE-79`

Errors from `transformError` were not correctly escaped prior to being embedded in the HTML output, causing potential HTML injection and XSS if attacker-controlled content is returned from `transformError`.

**Affected:** npm/svelte  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
