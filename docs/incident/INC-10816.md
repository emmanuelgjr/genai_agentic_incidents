### INC-10816  [↗](/incident/INC-10816.html)

**Apache XML Graphics FOP XML External Entity Reference ('XXE') vulnerability**  
_2024-10 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2017-5661`, `CVE-2022-41704`, `CVE-2022-44729`, `CVE-2022-44730`, `CVE-2024-28168`
CWEs: `CWE-611`, `CWE-918`
CVSS: **5.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:L`

Improper Restriction of XML External Entity Reference ('XXE') vulnerability in Apache XML Graphics FOP. This issue affects Apache XML Graphics FOP: 2.9. Users are recommended to upgrade to version 2.10, which fixes the issue.

**Affected:** maven/org.apache.xmlgraphics:fop-core  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
