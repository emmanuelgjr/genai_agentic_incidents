### INC-00786  [↗](/incident/INC-00786.html)

**Chinese AI Security Firm Leaks SSL Private Key in OpenClaw-Based Product**  
_2026-03-16 · real-world · Severity: Critical_

Qihoo 360, a major Chinese cybersecurity company, released its AI assistant '360 Security Claw' based on OpenClaw, but mistakenly included a wildcard SSL private key in the installation package. This critical error exposed users to security risks, enabling attackers to intercept and manipulate communications.

**Attack vector:** `data-exfiltration`
