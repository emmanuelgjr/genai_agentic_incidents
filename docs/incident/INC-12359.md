### INC-12359  [↗](/incident/INC-12359.html)

**Cloud Foundry UAA Privilege Escalation**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2018-15761`
CVSS: **8.8** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

Cloud Foundry UAA release, versions prior to v64.0, and UAA, versions prior to 4.23.0, contains a validation error which allows for privilege escalation. A remote authenticated user may modify the url and content of a consent page to gain a token with arbitrary scopes that escalates their privileges.

**Affected:** maven/org.cloudfoundry.identity:cloudfoundry-identity-server  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
