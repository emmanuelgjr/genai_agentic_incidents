### INC-11507  [↗](/incident/INC-11507.html)

**Jenkins AbsInt a³ Plugin XML External Entity Reference vulnerability**  
_2023-07 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-28680`, `CVE-2023-28681`, `CVE-2023-28682`, `CVE-2023-28683`, `CVE-2023-28684`, `CVE-2023-28685`
CWEs: `CWE-611`
CVSS: **7.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:L/A:N`

Jenkins AbsInt a³ Plugin 1.1.0 and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks. This allows attackers able to control `Project File (APX)` contents to have Jenkins parse a crafted XML document that uses external entities for extraction of secrets from the Jenkins controller or server-side request forgery.

**Affected:** maven/org.jenkins-ci.plugins:absint-a3  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
