### INC-07666  [↗](/incident/INC-07666.html)

**SQL injection vulnerability in the Real Estate Property (com_properties) component 3.1.22-03 for Joomla!**  
_2010-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2010-1874`
CWEs: `CWE-89`
CVSS: **7.5**

SQL injection vulnerability in the Real Estate Property (com_properties) component 3.1.22-03 for Joomla! allows remote attackers to execute arbitrary SQL commands via the aid parameter in an agentlisting action to index.php. NOTE: some of these details are obtained from third party information.

**Affected:** com-property/com_properties, joomla/joomla\!  
**Attack vector:** `sql-injection`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
