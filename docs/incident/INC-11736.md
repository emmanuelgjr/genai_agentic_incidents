### INC-11736  [↗](/incident/INC-11736.html)

**Heap buffer overflow in GPU**  
_2022-11 · vulnerability-disclosure · Severity: Critical_

**🚨 Exploited in the wild** (CISA KEV, added 2022-11-28)

CVEs: `CVE-2022-4135`
CWEs: `CWE-787`
CVSS: **9.6** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:H/I:H/A:H`

Heap buffer overflow in GPU in Google Chrome prior to 107.0.5304.121 allowed a remote attacker who had compromised the renderer process to potentially perform a sandbox escape via a crafted HTML page. (Chromium security severity: High)

**Affected:** npm/electron  
**Attack vector:** `sandbox-escape`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`
