### INC-12082  [↗](/incident/INC-12082.html)

**Jenkins HTML Publisher Plugin vulnerable to Cross-site Scripting**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2019-10432`, `CVE-2019-10433`
CWEs: `CWE-256`, `CWE-312`, `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

Jenkins HTML Publisher Plugin prior to version 1.21 did not escape the project and build display names in the HTML report frame, resulting in a cross-site scripting vulnerability exploitable by users able to change those. This issue has been patched in version 1.21

**Affected:** maven/org.jenkins-ci.plugins:htmlpublisher  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0050`
