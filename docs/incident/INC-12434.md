### INC-12434  [↗](/incident/INC-12434.html)

**Alkacon OpenCms XSS via query parameter in a search action**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2006-2571`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in search.html in Alkacon OpenCms 6.0.0, 6.0.2, and 6.0.3 allows remote attackers to inject arbitrary web script or HTML via the query parameter in a search action.

**Affected:** maven/org.opencms:opencms-core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
