### INC-04542  [↗](/incident/INC-04542.html)

**ChatGPT Redis bug exposes user chat histories and payment data**  
_2023-03 · real-world · Severity: High_

A bug in the open-source Redis client library used by ChatGPT briefly exposed other users' chat-history titles and, for a subset of paying subscribers, names, email addresses, billing addresses, last-four digits of credit cards and expiry dates. OpenAI took ChatGPT offline to patch and disclosed the incident.

**Affected:** OpenAI ChatGPT subscribers  
**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`  
**OWASP Agentic (ASI):** `ASI02`, `ASI03`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MANAGE-2.4`, `MAP-3.5`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0024`, `AML.T0053`, `AML.T0057`
