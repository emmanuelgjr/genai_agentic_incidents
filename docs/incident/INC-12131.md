### INC-12131  [↗](/incident/INC-12131.html)

**MoinMoin Cross-site scripting (XSS) vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2008-3381`, `CVE-2009-0260`, `CVE-2009-0312`, `CVE-2009-1482`, `CVE-2011-1058`, `CVE-2012-6082`, `CVE-2016-9119`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Cross-site scripting (XSS) vulnerability in the rsslink function in `theme/__init__.py` in MoinMoin before 1.9.6 allows remote attackers to inject arbitrary web script or HTML via the page name in a rss link.

**Affected:** pip/moin  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
