### INC-10366  [↗](/incident/INC-10366.html)

**ExecuTorch vulnerable to Heap-based Buffer Overflow attack**  
_2025-07 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-30402`
CWEs: `CWE-122`
CVSS: **8.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:N/A:H`

A heap-buffer-overflow vulnerability in the loading of ExecuTorch methods can cause the runtime to crash and potentially result in code execution or other undesirable effects. This issue affects ExecuTorch prior to commit 93b1a0c15f7eda49b2bc46b5b4c49557b4e9810f

**Affected:** swift/github.com/pytorch/executorch, maven/org.pytorch:executorch-android, pip/executorch  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
