### INC-02163  [↗](/incident/INC-02163.html)

**A stored cross-site scripting (XSS) vulnerability exists in automatic1111/stable-diffusion-webui version git 82a973c.**  
_2025-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-12374`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

A stored cross-site scripting (XSS) vulnerability exists in automatic1111/stable-diffusion-webui version git 82a973c. An attacker can upload an HTML file, which the application interprets as content-type application/html. If a victim accesses the malicious link, it will execute arbitrary JavaScript in the victim's browser.

**Affected:** automatic1111/stable-diffusion-webui  
**Attack vector:** `xss`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
