### INC-07168  [↗](/incident/INC-07168.html)

**Bypassing Cylance's AI Malware Detection**  
_2019-09-07 · research · Severity: Critical_

Researchers at Skylight were able to create a universal bypass string that evades detection by Cylance's AI Malware detector when appended to a malicious file.

**Affected:** CylancePROTECT, Cylance Smart Antivirus  
**Attack vector:** `adversarial-input`  

**NIST AI RMF:** `MANAGE-2.1`, `MEASURE-2.6`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0015`, `AML.T0040`, `AML.T0042`, `AML.T0043`
