### INC-12125  [↗](/incident/INC-12125.html)

**OWASP HTML Sanitizer allows redirecting to an arbitrary URL when JavaScript is disabled**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2011-4457`
CWEs: `CWE-200`

OWASP HTML Sanitizer (aka owasp-java-html-sanitizer) before 88, when JavaScript is disabled, allows user-assisted remote attackers to obtain potentially sensitive information via a crafted FORM element within a NOSCRIPT element.

**Affected:** maven/com.googlecode.owasp-java-html-sanitizer:owasp-java-html-sanitizer  
**Attack vector:** `info-disclosure`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`  
**OWASP Agentic (ASI):** `ASI02`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0024`, `AML.T0053`, `AML.T0057`
