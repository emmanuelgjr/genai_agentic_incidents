### INC-12279  [↗](/incident/INC-12279.html)

**Stored cross-site scripting vulnerability in Jenkins TestLink Plugin**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2018-1000106`, `CVE-2018-1000113`
CWEs: `CWE-79`, `CWE-863`
CVSS: **5.4** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

A cross-site scripting vulnerability exists in Jenkins TestLink Plugin 2.12 and earlier in TestLinkBuildAction/summary.jelly and others that allow an attacker who can control e.g. TestLink report names to have Jenkins serve arbitrary HTML and JavaScript

**Affected:** maven/org.jenkins-ci.plugins:testlink  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0050`
