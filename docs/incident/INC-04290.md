### INC-04290  [↗](/incident/INC-04290.html)

**There exists a stored XSS Vulnerability in Kubeflow Pipeline View web UI.**  
_2024-11 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-9526`
CVSS: **5.4**

There exists a stored XSS Vulnerability in Kubeflow Pipeline View web UI. The Kubeflow Web UI allows to create new pipelines. When creating a new pipeline, it is possible to add a description. The description field allows html tags, which are not filtered properly. Leading to a stored XSS. We recommend upgrading past commit 930c35f1c543998e60e8d648ce93185c9b5dbe8d

**Affected:** kubeflow/pipelines  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`

- [NVD](https://nvd.nist.gov/vuln/detail/CVE-2024-9526) _(advisory)_
- [cve-coordination@google.com](https://github.com/kubeflow/pipelines/pull/10315) _(patch)_
