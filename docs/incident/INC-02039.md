### INC-02039  [↗](/incident/INC-02039.html)

**Vercel Breach via Compromised AI Tool Exposes Crypto Projects to Security Risks**  
_2026-04-19 · real-world · Severity: Critical_

Vercel, a major web infrastructure provider, suffered a security breach after a third-party AI tool (Context.ai) was compromised, granting attackers unauthorized access to internal systems. The incident exposed sensitive credentials, prompting crypto developers to rotate API keys and raising concerns about third-party AI tool security.

**Attack vector:** `data-exfiltration`
