### INC-03953  [↗](/incident/INC-03953.html)

**llama.cpp provides LLM inference in C/C++.**  
_2024-08 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2024-41130`, `CVE-2024-42477`, `CVE-2024-42478`, `CVE-2024-42479`
CWEs: `CWE-123`, `CWE-125`, `CWE-401`, `CWE-476`, `CWE-787`
CVSS: **5.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N`

llama.cpp provides LLM inference in C/C++. The unsafe `type` member in the `rpc_tensor` structure can cause `global-buffer-overflow`. This vulnerability may lead to memory data leakage. The vulnerability is fixed in b3561.

**Affected:** ggml/llama.cpp
