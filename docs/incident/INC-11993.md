### INC-11993  [↗](/incident/INC-11993.html)

**Liferay Portal cross-site scripting (XSS) vulnerability in the Frontend Taglib module**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2021-35463`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Cross-site scripting (XSS) vulnerability in the Frontend Taglib module in Liferay Portal 7.4.0 allows remote attackers to inject arbitrary web script or HTML into the management toolbar search via the `keywords` parameter.

**Affected:** maven/com.liferay:com.liferay.frontend.taglib.clay, maven/com.liferay.portal:release.portal.bom  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
