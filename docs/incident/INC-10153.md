**`sveltekit-superforms` has Prototype Pollution in `parseFormData` function of `formData.js`**  
_2025-10 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-62381`

### Summary `sveltekit-superforms` v2.27.3 and prior are susceptible to a prototype pollution vulnerability within the `parseFormData` function of `formData.js`. An attacker can inject string and array properties into `Object.prototype`, leading to denial of service, type confusion, and potential remote code execution in downstream applications that rely on polluted objects. ### Details Superforms is a SvelteKit form library for server and client form validation.
