### INC-02973  [↗](/incident/INC-02973.html)

**NVIDIA Triton Inference Server contains a vulnerability in the model loading API, where a user could cause an integer overflow or wraparound error by loading a model with an ext...**  
_2025-02 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-53880`
CVSS: **4.9**

NVIDIA Triton Inference Server contains a vulnerability in the model loading API, where a user could cause an integer overflow or wraparound error by loading a model with an extra-large file size that overflows an internal variable. A successful exploit of this vulnerability might lead to denial of service.

**Affected:** nvidia/triton_inference_server, linux/linux_kernel, microsoft/windows  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
