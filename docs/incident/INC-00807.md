### INC-00807  [↗](/incident/INC-00807.html)

**Claude AI Uncovers Zero-Day RCE Vulnerabilities in Vim and Emacs**  
_2026-03-30 · real-world · Severity: High_

Anthropic's Claude AI discovered critical zero-day remote code execution vulnerabilities in the popular Vim and GNU Emacs text editors. The AI rapidly identified and generated proof-of-concept exploits, enabling attackers to execute arbitrary code by opening crafted files. The Vim flaw was patched, but the Emacs vulnerability remains unmitigated.

**Attack vector:** `rce`

**OWASP Agentic (ASI):** `ASI05`  
**NIST AI RMF:** `MEASURE-2.7`
