### INC-02641  [↗](/incident/INC-02641.html)

**Google's Antigravity AI coding tool hacked within 24 hours of launch**  
_2025-11-24 · vulnerability-disclosure · Severity: Critical_

Researchers demonstrated prompt-injection and tool-abuse attacks against Google's Antigravity natural-language coding agent within 24 hours of public launch, achieving persistent backdoor installation and arbitrary code execution on user machines.

**Affected:** Google Antigravity users  
**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM05`, `LLM06`  
**OWASP Agentic (ASI):** `ASI01`, `ASI02`, `ASI05`  
**NIST AI RMF:** `MANAGE-2.4`, `MAP-3.5`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0050`, `AML.T0051`, `AML.T0053`
