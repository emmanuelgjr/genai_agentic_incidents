### INC-11988  [↗](/incident/INC-11988.html)

**Magento Information Disclosure vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2020-24400`, `CVE-2020-24401`, `CVE-2020-24402`, `CVE-2020-24403`, `CVE-2020-24404`, `CVE-2020-24405`, `CVE-2020-24406`, `CVE-2020-24407`, `CVE-2020-24408`, `CVE-2021-28556`, `CVE-2021-28563`, `CVE-2021-28566`, `CVE-2021-28567`, `CVE-2021-28583`, `CVE-2021-28584`, `CVE-2021-28585`
CWEs: `CWE-20`, `CWE-200`, `CWE-22`, `CWE-276`, `CWE-285`, `CWE-434`, `CWE-657`, `CWE-79`, `CWE-863`, `CWE-89`
CVSS: **3.7** — `CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:L/I:N/A:N`

Magento versions 2.4.2 (and earlier), 2.4.1-p1 (and earlier) and 2.3.6-p1 (and earlier) are vulnerable to an Information Disclosure vulnerability when uploading a modified png file to a product image. Successful exploitation could lead to the disclosure of document root path by an unauthenticated attacker. Access to the admin console is required for successful exploitation.

**Affected:** composer/magento/community-edition, composer/magento/community-edition  
**Attack vector:** `info-disclosure`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`, `LLM05`
