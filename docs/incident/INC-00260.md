### INC-00260  [↗](/incident/INC-00260.html)

**AI-Assisted Commit Enables North Korean Malware Attack on Crypto Trading Agent**  
_2026-04-29 · real-world · Severity: High_

Anthropic's Claude Opus AI model co-authored a code commit that introduced a malicious npm package into an autonomous crypto trading agent. The malware, linked to North Korean group Famous Chollima, enabled theft of crypto assets and sensitive data, demonstrating direct harm caused by AI-assisted software development.

**Attack vector:** `data-exfiltration`

**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`
