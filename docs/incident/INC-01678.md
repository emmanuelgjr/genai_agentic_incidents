### INC-01678  [↗](/incident/INC-01678.html)

**Predator Spyware Bypasses iPhone Privacy Indicators for Covert Surveillance**  
_2026-02-19 · real-world · Severity: High_

Security researchers discovered that Intellexa's Predator spyware can suppress iPhone camera and microphone indicators by injecting code into system processes, allowing covert recording without user knowledge. This AI-driven technique violates user privacy and fundamental rights, enabling undetected surveillance on compromised devices.

**Attack vector:** `privacy-violation`
