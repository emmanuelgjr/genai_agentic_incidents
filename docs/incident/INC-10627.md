### INC-10627  [↗](/incident/INC-10627.html)

**A cross-site scripting (xss) vulnerability exists in the dataset upload functionality of ClearML Enterprise Server 3.22.5-1533.**  
_2025-02 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2024-39272`
CWEs: `CWE-79`
CVSS: **9.0** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:H/I:H/A:H`

A cross-site scripting (xss) vulnerability exists in the dataset upload functionality of ClearML Enterprise Server 3.22.5-1533. A specially crafted HTTP request can lead to an arbitrary html code. An attacker can send a series of HTTP requests to trigger this vulnerability.

**Affected:** clear/clearml_enterprise_server  
**Attack vector:** `xss`

**MITRE ATLAS:** `AML.T0010`, `AML.T0020`, `AML.T0050`
