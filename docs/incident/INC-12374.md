### INC-12374  [↗](/incident/INC-12374.html)

**golang.org/x/net/html NULL Pointer Dereference vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2018-17075`, `CVE-2018-17142`
CWEs: `CWE-476`
CVSS: **7.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H`

The html package (aka x/net/html) through 2018-09-17 in Go mishandles <math><template><mo><template>, leading to a "panic: runtime error" in parseCurrentToken in parse.go during an html.Parse call

**Affected:** go/golang.org/x/net
