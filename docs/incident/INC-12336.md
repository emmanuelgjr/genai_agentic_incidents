### INC-12336  [↗](/incident/INC-12336.html)

**Apache ActiveMQ Apollo XXE Vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2014-3579`, `CVE-2014-3600`, `CVE-2014-8110`
CWEs: `CWE-611`, `CWE-79`
CVSS: **9.8** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

XML external entity (XXE) vulnerability in Apache ActiveMQ Apollo 1.x before 1.7.1 allows remote consumers to have unspecified impact via vectors involving an XPath based selector when dequeuing XML messages.

**Affected:** maven/org.apache.activemq:apollo-project  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
