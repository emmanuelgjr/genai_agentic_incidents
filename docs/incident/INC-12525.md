### INC-12525  [↗](/incident/INC-12525.html)

**Cross-site scripting in @atlaskit/editor-core**  
_2022-02 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2019-20903`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

The hyperlinks functionality in atlaskit/editor-core in before version 113.1.5 allows remote attackers to inject arbitrary HTML or JavaScript via a Cross-Site Scripting (XSS) vulnerability in link targets.

**Affected:** npm/@atlaskit/editor-core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
