### INC-03034  [↗](/incident/INC-03034.html)

**PocketOS Production Database Was Reportedly Deleted by Cursor AI Agent Running Claude Opus 4.6**  
_2025 · real-world · Severity: Medium_
AIID: [`#1469`](https://incidentdatabase.ai/cite/1469/)

A Cursor AI coding agent reportedly running Anthropic&#x27;s Claude Opus 4.6 deleted PocketOS&#x27;s production database and volume-level backups through Railway while working on a staging-environment task. Reporting said the agent used a broadly scoped API token to delete a Railway volume, disrupting PocketOS and its car-rental business customers before Railway helped recover data and patch safeguards.
