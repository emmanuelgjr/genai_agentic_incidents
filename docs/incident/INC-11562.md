### INC-11562  [↗](/incident/INC-11562.html)

**glazedlists XML Deserialization vulnerability**  
_2023-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2023-31890`
CWEs: `CWE-502`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

An XML Deserialization vulnerability in glazedlists v1.11.0 allows an attacker to execute arbitrary code via the BeanXMLByteCoder.decode() parameter.

**Affected:** maven/com.glazedlists:glazedlists  
**Attack vector:** `deserialization`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0010.001`, `AML.T0050`
