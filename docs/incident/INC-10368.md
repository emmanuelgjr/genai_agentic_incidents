### INC-10368  [↗](/incident/INC-10368.html)

**Jenkins Applitools Eyes Plugin vulnerability exposes unencrypted keys to certain authenticated users**  
_2025-07 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-53651`, `CVE-2025-53653`, `CVE-2025-53657`, `CVE-2025-53658`, `CVE-2025-53665`, `CVE-2025-53666`, `CVE-2025-53668`, `CVE-2025-53670`, `CVE-2025-53675`, `CVE-2025-53742`
CWEs: `CWE-256`, `CWE-311`, `CWE-312`, `CWE-36`, `CWE-522`, `CWE-779`, `CWE-79`
CVSS: **4.3** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:N/A:N`

Jenkins Applitools Eyes Plugin 1.16.5 and earlier stores Applitools API keys unencrypted in job config.xml files on the Jenkins controller, where they can be viewed by users with Item/Extended Read permission or access to the Jenkins controller file system.

**Affected:** maven/org.jenkins-ci.plugins:applitools-eyes  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0050`
