### INC-05510  [↗](/incident/INC-05510.html)

**ByteDance Intern Accidentally Deletes Key Machine Learning Models, Disrupting Operations**  
_2021-06-21 · real-world · Severity: Medium_

A ByteDance intern accidentally deleted all sub-GB machine learning models, including TensorFlow Lite models, by removing a parent directory with 'skip trash' enabled, making recovery impossible. The incident caused significant operational disruption, required a large-scale response, and delayed AI model deployment, though most affected data was offline and impact was limited.

**Attack vector:** `other`
