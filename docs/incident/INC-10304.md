### INC-10304  [↗](/incident/INC-10304.html)

**moonshine Stored Cross-Site Scripting Vulnerability in Create Article**  
_2025-08 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-51487`, `CVE-2025-51488`
CWEs: `CWE-79`
CVSS: **4.5** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:R/S:U/C:H/I:N/A:N`

A stored cross-site scripting (XSS) vulnerability in the Create Article function of MoonShine v3.12.3 allows attackers to execute arbitrary web scripts or HTML via injecting a crafted payload into the Link parameter.

**Affected:** composer/moonshine/moonshine  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
