### INC-12236  [↗](/incident/INC-12236.html)

**Typo3 Function Menu API XSS Vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2012-6145`, `CVE-2012-6147`, `CVE-2012-6148`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the function menu API in TYPO3 4.5.x before 4.5.21, 4.6.x before 4.6.14, and 4.7.x before 4.7.6 allows remote authenticated backend users to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/typo3/cms, composer/typo3/cms, composer/typo3/cms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
