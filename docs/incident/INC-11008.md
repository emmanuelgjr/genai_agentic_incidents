### INC-11008  [↗](/incident/INC-11008.html)

**Zendframework Potential XSS or HTML Injection vector in Zend_Json**  
_2024-06 · vulnerability-disclosure · Severity: Medium_
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

`Zend_Json_Encoder` was not taking into account the solidus character (/) during encoding, leading to incompatibilities with the JSON specification, and opening the potential for XSS or HTML injection attacks when returning HTML within a JSON string.

**Affected:** composer/zendframework/zendframework1, composer/zendframework/zendframework1, composer/zendframework/zendframework1  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
