### INC-12517  [↗](/incident/INC-12517.html)

**Deserialization of Untrusted Data in Magnolia CMS**  
_2022-02 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2021-46364`, `CVE-2021-46365`
CWEs: `CWE-502`, `CWE-611`
CVSS: **7.8** — `CVSS:3.1/AV:L/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

A vulnerability in the Snake YAML parser of Magnolia CMS v6.2.3 and below allows attackers to execute arbitrary code via a crafted YAML file.

**Affected:** maven/info.magnolia:magnolia-core  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
