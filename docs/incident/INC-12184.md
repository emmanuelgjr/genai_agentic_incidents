### INC-12184  [↗](/incident/INC-12184.html)

**Improper Certificate Validation in Shibboleth Identity Provider and OpenSAML**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2015-1796`
CWEs: `CWE-295`

The PKIX trust engines in Shibboleth Identity Provider before 2.4.4 and OpenSAML Java (OpenSAML-J) before 2.6.5 trust candidate X.509 credentials when no trusted names are available for the entityID, which allows remote attackers to impersonate an entity via a certificate issued by a shibmd:KeyAuthority trust anchor.

**Affected:** maven/edu.internet2.middleware:shibboleth-identityprovider, maven/org.opensaml:opensaml  
**Attack vector:** `deepfake`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`
