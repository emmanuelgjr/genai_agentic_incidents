### INC-11312  [↗](/incident/INC-11312.html)

**WSO2 products vulnerable to XML External Entity attack**  
_2023-12 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2023-6836`
CWEs: `CWE-611`
CVSS: **4.6** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:U/C:L/I:L/A:N`

Multiple WSO2 products have been identified as vulnerable due to an XML External Entity (XXE) attack abuses a widely available but rarely used feature of XML parsers to access sensitive information.

**Affected:** maven/org.wso2.carbon.governance:org.wso2.carbon.governance.common, maven/org.wso2.carbon.analytics-common:org.wso2.carbon.event.input.adapter.core, maven/org.wso2.carbon.event-processing:org.wso2.carbon.event.processor.core  
**Attack vector:** `info-disclosure`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`  
**OWASP Agentic (ASI):** `ASI02`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0024`, `AML.T0053`, `AML.T0057`
