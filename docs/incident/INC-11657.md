### INC-11657  [↗](/incident/INC-11657.html)

**rangy vulnerable to Prototype Pollution**  
_2023-02 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-26102`
CWEs: `CWE-1321`
CVSS: **8.2** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:L/A:H`

All versions of the package rangy are vulnerable to Prototype Pollution when using the `extend()` function in file `rangy-core.js`.The function uses recursive merge which can lead an attacker to modify properties of the Object.prototype.

**Affected:** npm/rangy  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
