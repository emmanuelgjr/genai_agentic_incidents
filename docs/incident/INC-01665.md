### INC-01665  [↗](/incident/INC-01665.html)

**PPTAgent — Rce (CVE-2026-42079)**  
_2026-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-42078`, `CVE-2026-42079`, `CVE-2026-42080`
CWEs: `CWE-22`, `CWE-95`
CVSS: **8.6** — `CVSS:3.1/AV:L/AC:L/PR:N/UI:R/S:C/C:H/I:H/A:H`

PPTAgent is an agentic framework for reflective PowerPoint generation. Prior to commit 418491a, PPTAgent is vulnerable to arbitrary code execution via Python eval() of LLM-generated code with builtins in scope. This issue has been patched via commit 418491a.

**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
