### INC-01665  [↗](/incident/INC-01665.html)

**PPTAgent — Path Traversal (CVE-2026-42078)**  
_2026-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-42078`, `CVE-2026-42079`, `CVE-2026-42080`
CVSS: **4.6**

PPTAgent is an agentic framework for reflective PowerPoint generation. Prior to commit 418491a, PPTAgent is vulnerable to arbitrary file write and directory creation via markdown_table_to_image. This issue has been patched via commit 418491a.

**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
