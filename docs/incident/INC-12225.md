### INC-12225  [↗](/incident/INC-12225.html)

**TYPO3 Cross-site scripting (XSS) vulnerability in the click enlarge functionality**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2010-5097`, `CVE-2010-5098`, `CVE-2010-5100`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the click enlarge functionality in TYPO3 4.3.x before 4.3.9 and 4.4.x before 4.4.5 when the caching framework is enabled, allows remote attackers to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/typo3/cms-frontend, composer/typo3/cms-frontend  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
