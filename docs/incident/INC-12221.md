### INC-12221  [↗](/incident/INC-12221.html)

**Loggerhead XSS via filename**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2011-0728`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in `templatefunctions.py` in Loggerhead before 1.18.1 allows remote authenticated users to inject arbitrary web script or HTML via a filename, which is not properly handled in a revision view.

**Affected:** pip/loggerhead  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
