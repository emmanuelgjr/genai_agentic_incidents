### INC-02754  [↗](/incident/INC-02754.html)

**Incomplete validation of dunder attributes allows an attacker to escape from the Local Python execution environment sandbox, enforced by smolagents.**  
_2025-09 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-9959`
CVSS: **7.6**

Incomplete validation of dunder attributes allows an attacker to escape from the Local Python execution environment sandbox, enforced by smolagents. The attack requires a Prompt Injection in order to trick the agent to create malicious code.

**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM05`  
**OWASP Agentic (ASI):** `ASI01`, `ASI05`  
**NIST AI RMF:** `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0050`, `AML.T0051`
