### INC-01523  [↗](/incident/INC-01523.html)

**New API — Xss (CVE-2026-25802)**  
_2026-02 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-25802`
CWEs: `CWE-79`
CVSS: **7.6** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:N/I:H/A:L`

New API is a large language mode (LLM) gateway and artificial intelligence (AI) asset management system. Prior to version 0.10.8-alpha.9, a potential unsafe operation occurs in component `MarkdownRenderer.jsx`, allowing for Cross-Site Scripting(XSS) when the model outputs items containing `<script>` tag. Version 0.10.8-alpha.9 fixes the issue.

**Affected:** newapi/new_api  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
