### INC-07670  [↗](/incident/INC-07670.html)

**Cross-site scripting (XSS) vulnerability in Joomla!**  
_2009-06 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2009-1938`
CVSS: **4.3**

Cross-site scripting (XSS) vulnerability in Joomla! 1.5.x through 1.5.10 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors related to database output and the frontend administrative panel.

**Affected:** joomla/joomla  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
