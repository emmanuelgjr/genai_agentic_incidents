**Cross-site scripting (XSS) vulnerability in Opera.dll in Opera 9.52 allows remote attackers to inject arbitrary web script or HTML via the query string, which is not properly es...**  
_2008-10 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2008-4725`
CVSS: **4.3**

Cross-site scripting (XSS) vulnerability in Opera.dll in Opera 9.52 allows remote attackers to inject arbitrary web script or HTML via the query string, which is not properly escaped before storage in the History Search database (aka md.dat), a different vector than CVE-2008-4696. NOTE: some of these issues were addressed before 9.60.

**Affected:** opera/opera_browser  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
