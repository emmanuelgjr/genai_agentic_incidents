### INC-00864  [↗](/incident/INC-00864.html)

**Critical Vulnerability in Anthropic's MCP Exposes AI Systems to Remote Code Execution**  
_2026-04-20 · real-world · Severity: High_

A critical architectural flaw in Anthropic's Model Context Protocol (MCP), widely used in AI agents and frameworks like Flowise, enables remote code execution and data breaches. Security researchers demonstrated live exploitation, affecting millions of users and over 200,000 servers, with sensitive data and systems compromised due to the protocol's design.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`, `LLM05`
