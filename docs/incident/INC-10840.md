### INC-10840  [↗](/incident/INC-10840.html)

**Eclipse Glassfish improperly handles http parameters**  
_2024-09 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-9329`
CWEs: `CWE-233`, `CWE-601`
CVSS: **5.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:L/A:N`

In Eclipse Glassfish versions before 7.0.17, the Host HTTP parameter could cause the web application to redirect to the specified URL, when the requested endpoint is `/management/domain`. By modifying the URL value to a malicious site, an attacker may successfully launch a phishing scam and steal user credentials.

**Affected:** maven/org.glassfish.main.admin:rest-service  
**Attack vector:** `phishing`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`
