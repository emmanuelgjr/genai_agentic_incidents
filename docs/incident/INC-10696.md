### INC-10696  [↗](/incident/INC-10696.html)

**REDAXO CMS Cross-site Scripting vulnerability**  
_2025-01 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2024-46209`
CWEs: `CWE-79`

A stored cross-site scripting (XSS) vulnerability in the component /media/test.html of REDAXO CMS v5.17.1 allows attackers to execute arbitrary web scripts or HTML via injecting a crafted payload into the password parameter.

**Affected:** composer/redaxo/source  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
