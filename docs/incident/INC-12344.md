### INC-12344  [↗](/incident/INC-12344.html)

**Puppet allows local users to modify the permissions of arbitrary files**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2011-3870`
CWEs: `CWE-59`

Puppet 2.7.x before 2.7.5, 2.6.x before 2.6.11, and 0.25.x allows local users to modify the permissions of arbitrary files via a symlink attack on the SSH authorized_keys file.

**Affected:** rubygems/puppet, rubygems/puppet  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
