### INC-10461  [↗](/incident/INC-10461.html)

**tarteaucitron-wp WordPress Plugin Vulnerable to Stored Cross-Site Scripting**  
_2025-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-11718`
CWEs: `CWE-79`
CVSS: **4.8** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:R/S:C/C:L/I:L/A:N`

The tarteaucitron-wp WordPress plugin before 0.3.0 allows author level and above users to add HTML into a post/page, which could allow users with the contributor role and above to perform Stored Cross-Site Scripting attacks.

**Affected:** composer/couleurcitron/tarteaucitron-wp  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
