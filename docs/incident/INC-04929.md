### INC-04929  [↗](/incident/INC-04929.html)

**TensorFlow — Vulnerability (CVE-2023-25673)**  
_2023-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-25673`, `CVE-2023-25674`
CVSS: **7.5**

TensorFlow is an open source platform for machine learning. Versions prior to 2.12.0 and 2.11.1 have a Floating Point Exception in TensorListSplit with XLA. A fix is included in TensorFlow version 2.12.0 and version 2.11.1.

**Affected:** google/tensorflow  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
