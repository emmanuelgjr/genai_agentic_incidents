### INC-12011  [↗](/incident/INC-12011.html)

**GramAddict bot uses dependency with reverse tcp backdoor**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-36245`
CWEs: `CWE-306`, `CWE-94`
CVSS: **8.8** — `CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

GramAddict before 1.2.5 allows remote attackers to execute arbitrary code because of use of UIAutomator2 and ATX-Agent. The attacker must be able to reach TCP port 7912, e.g., by being on the same Wi-Fi network.

**Affected:** pip/GramAddict  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
