### INC-01815  [↗](/incident/INC-01815.html)

**Studies Link ChatGPT Use to Reduced Brain Activity and Cognitive Skills**  
_2026-04-21 · real-world · Severity: Medium_

Multiple studies led by MIT's Nataliya Kosmyna found that students using AI tools like ChatGPT showed up to 55% less brain activity in creativity and information-processing areas, produced similar essays, and struggled with memory recall. These findings raise concerns about AI's negative impact on human cognition.
