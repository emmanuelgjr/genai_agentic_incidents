### INC-04092  [↗](/incident/INC-04092.html)

**Planting Instructions for Delayed Automatic AI Agent Tool Invocation**  
_2024-02-01 · research · Severity: High_

[Embrace the Red](https://embracethered.com/blog/) demonstrated that Google Gemini is susceptible to automated tool invocation by delaying the execution to the next conversation turn. This bypasses a security control that restricts Gemini from invoking tools that can access sensitive user information in the same conversation turn that untrusted data enters context.

**Affected:** Google Gemini  
**Attack vector:** `adversarial-input`  

**OWASP LLM Top 10:** `LLM01`, `LLM06`  
**OWASP Agentic (ASI):** `ASI01`, `ASI02`, `ASI06`  
**NIST AI RMF:** `MANAGE-2.1`, `MAP-3.5`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0051`, `AML.T0051.001`, `AML.T0053`, `AML.T0066`, `AML.T0085.001`
