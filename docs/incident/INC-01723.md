### INC-01723  [↗](/incident/INC-01723.html)

**Anyscale Ray LFI via /static/ directory (missing authorization)**  
_2023-09-05 · real-world · Severity: Critical_

CVEs: `CVE-2023-48022`, `CVE-2023-6019`, `CVE-2023-6020`, `CVE-2023-6021`, `CVE-2025-34351`, `CVE-2026-27482`, `CVE-2026-32981`
CWEs: `CWE-1188`, `CWE-22`, `CWE-29`, `CWE-304`, `CWE-396`, `CWE-78`, `CWE-829`, `CWE-862`, `CWE-918`
CVSS: **7.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N`

Local file inclusion in Ray's /static/ directory allows attackers to read any file on the server without authentication. Fixed in 2.8.1+.

**Affected:** ray < 2.8.1  
**Attack vector:** `path-traversal`  
**Impact:** Cluster-wide malware propagation; cryptocurrency mining hijack; compute resource theft  

**OWASP LLM Top 10:** `LLM01`, `LLM02`, `LLM03`, `LLM05`, `LLM06`  
**OWASP Agentic (ASI):** `ASI01`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.1`, `GOVERN-1.4`, `GOVERN-6.1`, `GOVERN-6.2`, `MANAGE-2.3`, `MANAGE-3.1`, `MAP-2.1`, `MAP-3.5`, `MAP-4.1`, `MEASURE-2.10`, `MEASURE-2.5`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0010.001`, `AML.T0011`, `AML.T0018`, `AML.T0040`, `AML.T0048`, `AML.T0049`, `AML.T0050`, `AML.T0051`, `AML.T0051.000`, `AML.T0051.001`, `AML.T0053`, `AML.T0055`, `AML.T0057`, `AML.T0060`  

**Mitigations:**
- Authentication on job submission APIs
- Network segmentation for AI compute clusters
- Patch Ray framework promptly
