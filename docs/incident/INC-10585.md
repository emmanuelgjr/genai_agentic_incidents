### INC-10585  [↗](/incident/INC-10585.html)

**Additional TCA Allows Cross-Site Scripting (XSS)**  
_2025-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-30083`
CWEs: `CWE-79`
CVSS: **5.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:U/C:L/I:L/A:L/E:F/RL:O/RC:C`

A cross-site scripting (XSS) vulnerability has been discovered in the Additional TCA extension. This vulnerabily is exploitable by a logged in backend user utilizing the TYPO3 backend user interface. This user can create output in the HTML context by exploiting improperly encoded user input. Updates 1.15.17 and 1.16.9 are available for download.

**Affected:** composer/codingms/additional-tca, composer/codingms/additional-tca  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
