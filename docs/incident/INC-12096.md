### INC-12096  [↗](/incident/INC-12096.html)

**Grafana Cross-site Scripting vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2019-13068`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:U/C:L/I:L/A:N`

`public/app/features/panel/panel_ctrl.ts` in Grafana before 6.2.5 allows HTML Injection in panel drilldown links (via the Title or url field).

**Affected:** go/github.com/grafana/grafana  
**Attack vector:** `xss`

**OWASP Agentic (ASI):** `ASI04`
