### INC-12428  [↗](/incident/INC-12428.html)

**Apache Tomcat's CookieExample Vulnerable to XSS**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2007-3384`
CWEs: `CWE-80`

Multiple cross-site scripting (XSS) vulnerabilities in `examples/servlet/CookieExample` in Apache Tomcat 3.3 through 3.3.2 allow remote attackers to inject arbitrary web script or HTML via the (1) Name or (2) Value field, related to error messages.

**Affected:** maven/org.apache.tomcat:tomcat  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
