### INC-12089  [↗](/incident/INC-12089.html)

**Magento Filter extension bypass via crafted store configuration keys**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2019-7912`
CWEs: `CWE-434`
CVSS: **7.2** — `CVSS:3.0/AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:H/A:H`

A file upload filter bypass exists in Magento 2.1 prior to 2.1.18, Magento 2.2 prior to 2.2.9, Magento 2.3 prior to 2.3.2. This can be exploited by an authenticated user with admin privileges to edit configuration keys to remove file extension filters, potentially resulting in the malicious upload and execution of malicious files on the server.

**Affected:** composer/magento/community-edition, composer/magento/community-edition, composer/magento/community-edition  
**Attack vector:** `other`
