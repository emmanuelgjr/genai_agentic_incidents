**Nginx-UI: Cross-Site WebSocket Hijacking (CSWSH) via missing origin validation on all WebSocket endpoints**  
_2026-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-34403`
CWEs: `CWE-1385`, `CWE-352`
CVSS: **8.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:N`

## Summary All WebSocket endpoints in nginx-ui use a gorilla/websocket Upgrader with CheckOrigin unconditionally returning true, allowing Cross-Site WebSocket Hijacking (CSWSH).
