### INC-12132  [↗](/incident/INC-12132.html)

**phpMyAdmin Unsafe Fetching of Javascript Code**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2012-5339`, `CVE-2012-5368`
CWEs: `CWE-79`

phpMyAdmin 3.5.x before 3.5.3 uses JavaScript code that is obtained through an HTTP session to phpmyadmin.net without SSL, which allows man-in-the-middle attackers to conduct cross-site scripting (XSS) attacks by modifying this code.

**Affected:** composer/phpmyadmin/phpmyadmin  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
