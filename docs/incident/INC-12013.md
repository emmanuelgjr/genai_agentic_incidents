**Magento Insufficient Session Expiration**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2021-21014`, `CVE-2021-21015`, `CVE-2021-21016`, `CVE-2021-21018`, `CVE-2021-21019`, `CVE-2021-21020`, `CVE-2021-21022`, `CVE-2021-21023`, `CVE-2021-21024`, `CVE-2021-21025`, `CVE-2021-21026`, `CVE-2021-21027`, `CVE-2021-21029`, `CVE-2021-21030`, `CVE-2021-21031`, `CVE-2021-21032`
CWEs: `CWE-284`, `CWE-285`, `CWE-352`, `CWE-434`, `CWE-613`, `CWE-639`, `CWE-78`, `CWE-79`, `CWE-89`, `CWE-91`
CVSS: **5.6** — `CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:L/I:L/A:L`

Magento versions 2.4.1 (and earlier), 2.4.0-p1 (and earlier) and 2.3.6 (and earlier) do not adequately invalidate user sessions. Successful exploitation could lead to unauthorized access to restricted resources. Access to the admin console is not required for successful exploitation.
