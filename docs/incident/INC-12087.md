### INC-12087  [↗](/incident/INC-12087.html)

**Magento 2 Community Edition CSRF vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2019-7849`, `CVE-2019-7851`, `CVE-2019-7852`, `CVE-2019-7857`, `CVE-2019-7860`, `CVE-2019-7864`, `CVE-2019-7865`, `CVE-2019-7873`, `CVE-2019-7886`, `CVE-2019-7888`, `CVE-2019-7899`, `CVE-2019-7929`, `CVE-2019-7947`
CWEs: `CWE-20`, `CWE-200`, `CWE-330`, `CWE-338`, `CWE-352`, `CWE-384`, `CWE-639`, `CWE-79`
CVSS: **6.5** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:H/A:N`

A cross-site request forgery vulnerability exists in the GiftCardAccount removal feature for Magento Open Source prior to 1.9.4.2, and Magento Commerce prior to 1.14.4.2, Magento 2.1 prior to 2.1.18, Magento 2.2 prior to 2.2.9, Magento 2.3 prior to 2.3.2.

**Affected:** composer/magento/community-edition, composer/magento/community-edition, composer/magento/community-edition  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`  
**OWASP Agentic (ASI):** `ASI02`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0024`, `AML.T0053`, `AML.T0057`
