### INC-12571  [↗](/incident/INC-12571.html)

**Multiple SQL injection vulnerabilities in phpYellowTM Pro Edition and Lite Edition 5.33 allow remote attackers to execute arbitrary SQL commands via the (1) haystack parameter t...**  
_2005-12 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2005-4001`
CVSS: **7.5**

Multiple SQL injection vulnerabilities in phpYellowTM Pro Edition and Lite Edition 5.33 allow remote attackers to execute arbitrary SQL commands via the (1) haystack parameter to search_result.php or (2) ckey parameter to print_me.php.

**Affected:** phpyellow/phpyellowtm_lite, phpyellow/phpyellowtm_pro  
**Attack vector:** `sql-injection`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
