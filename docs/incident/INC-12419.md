### INC-12419  [↗](/incident/INC-12419.html)

**Django Cross-site scripting (XSS) vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2008-2302`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Cross-site scripting (XSS) vulnerability in the login form in the administration application in Django 0.91 before 0.91.2, 0.95 before 0.95.3, and 0.96 before 0.96.2 allows remote attackers to inject arbitrary web script or HTML via the URI of a certain previous request.

**Affected:** pip/django, pip/django, pip/django  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
