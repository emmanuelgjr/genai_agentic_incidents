### INC-12052  [↗](/incident/INC-12052.html)

**XXE vulnerability in Jenkins RapidDeploy Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-2163`, `CVE-2020-2166`, `CVE-2020-2167`, `CVE-2020-2168`, `CVE-2020-2171`
CWEs: `CWE-20`, `CWE-502`, `CWE-611`, `CWE-79`
CVSS: **7.6** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:L/A:L`

RapidDeploy Plugin 4.2 and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks. This allows a user able to control the input files for the 'RapidDeploy deployment package build' build or post-build step to have Jenkins parse a crafted file that uses external entities for extraction of secrets from the Jenkins controller, server-side request forgery, or denial-of-service attacks. RapidDeploy Plugin 4.2.1 disables external entity resolution for its XML parser.

**Affected:** maven/org.jenkins-ci.plugins:rapiddeploy-jenkins  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`
