### INC-11384  [↗](/incident/INC-11384.html)

**Arduino Create Agent path traversal - arbitrary file deletion vulnerability**  
_2023-10 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-43800`, `CVE-2023-43801`, `CVE-2023-43802`, `CVE-2023-43803`
CWEs: `CWE-22`, `CWE-345`, `CWE-35`
CVSS: **6.1** — `CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:N/I:H/A:L`

### Impact The vulnerability affects the endpoint `/v2/pkgs/tools/installed` and the way it handles plugin names supplied as user input. A user who has the ability to perform HTTP requests to the localhost interface, or is able to bypass the CORS configuration, can delete arbitrary files or folders belonging to the user that runs the Arduino Create Agent via a crafted HTTP POST request. Further details are available in the references. ### Fixed Version * `1.3.3` ### References The issue was reported by Nozomi Networks Labs. Further details on the issue are available at the following URL: * https://www.nozominetworks.com/blog/security-flaws-affect-a-component-of-the-arduino-create-cloud-ide

**Affected:** go/github.com/arduino/arduino-create-agent  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
