### INC-09407  [↗](/incident/INC-09407.html)

**Picklescan (scan_pytorch) Bypass via dynamic eval MAGIC_NUMBER**  
_2026-02 · vulnerability-disclosure · Severity: High_
CWEs: `CWE-184`

### Summary This is a scanning bypass to `scan_pytorch` function in `picklescan`.
