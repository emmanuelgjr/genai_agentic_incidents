**DDEV has ZipSlip path traversal in tar and zip archive extraction**  
_2026-04 · vulnerability-disclosure · Severity: Medium_

CWEs: `CWE-22`

## Summary The DDEV local dev tool has unsanitized extraction in both `Untar()` and `Unzip()` functions in `pkg/archive/archive.go`.
