### INC-03649  [↗](/incident/INC-03649.html)

**ChatGPT memory exploit exposes user data**  
_2024-09-24 · vulnerability-disclosure · Severity: High_

Researchers demonstrated a prompt-injection attack against ChatGPT's long-term memory feature that quietly stored attacker-controlled instructions and then exfiltrated user data on future interactions, persisting across sessions.

**Affected:** OpenAI ChatGPT users  
**Attack vector:** `memory-poisoning`  

**OWASP LLM Top 10:** `LLM01`, `LLM04`  
**OWASP Agentic (ASI):** `ASI03`, `ASI06`  
**NIST AI RMF:** `GOVERN-1.4`, `MAP-4.2`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0020`, `AML.T0051`, `AML.T0066`  

**References:**
- [OECD AIM - ChatGPT Memory Exploit Exposes User Data](https://oecd.ai/en/incidents/2024-09-24-3c27) _(research)_

**Tags:** `memory-poisoning`, `prompt-injection`, `openai`
