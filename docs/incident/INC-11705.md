### INC-11705  [↗](/incident/INC-11705.html)

**YAML Go package vulnerable to denial of service**  
_2022-12 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2021-4235`, `CVE-2022-3064`
CWEs: `CWE-400`
CVSS: **5.5** — `CVSS:3.1/AV:L/AC:L/PR:N/UI:R/S:U/C:N/I:N/A:H`

Due to unbounded alias chasing, a maliciously crafted YAML file can cause the system to consume significant system resources. If parsing user input, this may be used as a denial of service vector.

**Affected:** go/github.com/go-yaml/yaml, go/gopkg.in/yaml.v2  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
