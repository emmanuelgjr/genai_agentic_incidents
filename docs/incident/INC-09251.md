### INC-09251  [↗](/incident/INC-09251.html)

**Netmaker has Insufficient Authorization in Host Token Verification**  
_2026-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-29194`
CWEs: `CWE-863`
CVSS: **8.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:N`

The Authorise middleware in Netmaker incorrectly validates host JWT tokens. When a route permits host authentication (hostAllowed=true), a valid host token bypasses all subsequent authorisation checks without verifying that the host is authorised to access the specific requested resource. Any entity possessing knowledge of object identifiers (node IDs, host IDs) can craft a request with an arbitrary valid host token to access, modify, or delete resources belonging to other hosts. Affected endpoints include node info retrieval, host deletion, MQTT signal transmission, fallback host updates, and failover operations. > Credits > Artem Danilov (Positive Technologies)
