### INC-12127  [↗](/incident/INC-12127.html)

**HTML Purifier allows remote attackers to obtain sensitive information**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2011-3744`
CWEs: `CWE-200`
CVSS: **5.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N`

HTML Purifier 4.2.0 allows remote attackers to obtain sensitive information via a direct request to a .php file, which reveals the installation path in an error message, as demonstrated by tests/PHPT/Reporter/SimpleTest.php and certain other files.

**Affected:** composer/ezyang/htmlpurifier  
**Attack vector:** `info-disclosure`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`  
**OWASP Agentic (ASI):** `ASI02`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0024`, `AML.T0053`, `AML.T0057`
