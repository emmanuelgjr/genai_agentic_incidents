### INC-12027  [↗](/incident/INC-12027.html)

**Arbitrary file write vulnerability in Jenkins Storable Configs Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-2259`, `CVE-2020-2261`, `CVE-2020-2278`
CWEs: `CWE-22`, `CWE-78`, `CWE-79`
CVSS: **6.5** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:H/A:N`

Jenkins Storable Configs Plugin 1.0 and earlier does not restrict the user-specified file name, allowing attackers with Job/Configure permission to replace any other '.xml' file on the Jenkins controller with a job config.xml file's content.

**Affected:** maven/org.jvnet.hudson.plugins:storable-configs-plugin  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
