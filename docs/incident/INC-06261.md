### INC-06261  [↗](/incident/INC-06261.html)

**AI Systems Vulnerable to Data Poisoning and Image-Scaling Attacks Pose Security Risks**  
_2020-08-09 · real-world · Severity: High_

Researchers highlight that machine learning models in IoT and computer vision are vulnerable to data poisoning and image-scaling attacks, which can degrade performance or cause misclassification. These vulnerabilities could lead to security breaches or operational failures, underscoring the need for robust AI defenses.

**Attack vector:** `model-poisoning`  

**OWASP LLM Top 10:** `LLM04`  
**OWASP Agentic (ASI):** `ASI06`  
**NIST AI RMF:** `MAP-4.2`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0020`, `AML.T0066`
