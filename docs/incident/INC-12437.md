### INC-12437  [↗](/incident/INC-12437.html)

**Alkacon OpenCms XSS via username during login**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2005-4294`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in Alkacon OpenCms before 6.0.3 allows remote attackers to inject arbitrary web script or HTML via the username in the login page.

**Affected:** maven/org.opencms:opencms-core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
