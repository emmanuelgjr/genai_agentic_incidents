### INC-12073  [↗](/incident/INC-12073.html)

**Magento SQL injection vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2019-8130`
CWEs: `CWE-89`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

A SQL injection vulnerability exists in Magento 2.2 prior to 2.2.10, Magento 2.3 prior to 2.3.3 or 2.3.2-p1. A user with store manipulation privileges can execute arbitrary SQL queries by getting access to the database connection through group instance in email templates.

**Affected:** composer/magento/community-edition, composer/magento/community-edition  
**Attack vector:** `sql-injection`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
