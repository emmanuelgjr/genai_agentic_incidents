### INC-11232  [↗](/incident/INC-11232.html)

**Enhavo Cross-site Scripting vulnerability**  
_2024-02 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-25874`, `CVE-2024-25875`, `CVE-2024-25876`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

A cross-site scripting (XSS) vulnerability in the Header module of Enhavo CMS v0.13.1 allows attackers to execute arbitrary web scripts or HTML via a crafted payload injected into the Title text field.

**Affected:** composer/enhavo/enhavo-app  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
