### INC-12557  [↗](/incident/INC-12557.html)

**Sandbox Bypass in Apache Velocity Engine**  
_2022-01 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-13936`
CWEs: `CWE-20`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

An attacker that is able to modify Velocity templates may execute arbitrary Java code or run arbitrary system commands with the same privileges as the account running the Servlet container. This applies to applications that allow untrusted users to upload/modify velocity templates running Apache Velocity Engine versions up to 2.2.

**Affected:** maven/org.apache.velocity:velocity, maven/org.apache.velocity:velocity-engine-parent  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
