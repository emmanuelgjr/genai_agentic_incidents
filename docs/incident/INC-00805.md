### INC-00805  [↗](/incident/INC-00805.html)

**Claude AI Chrome Extension Vulnerability Exposes User Data to Malicious Extensions**  
_2026-05-08 · real-world · Severity: High_

Security researchers discovered a critical flaw, dubbed 'ClaudeBleed,' in Anthropic's Claude AI Chrome extension that allows any browser extension, even those without special permissions, to hijack the AI assistant. Attackers can exploit this to access sensitive data and perform unauthorized actions, despite Anthropic's partial security fix.

**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM03`  
**OWASP Agentic (ASI):** `ASI01`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0051`
