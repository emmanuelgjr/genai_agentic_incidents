### INC-07985  [↗](/incident/INC-07985.html)

**ChatGPT Summarization Vulnerability Enables Phishing Attacks via Prompt Injection**  
_2026-05-29 · real-world · Severity: High_

Researchers at Permiso Security revealed a vulnerability in ChatGPT's web summarization feature, dubbed ChatGPhish. Attackers can inject malicious content into web pages, which ChatGPT then renders as trusted links, images, or QR codes, exposing users to phishing, tracking, and social engineering attacks through the AI's interface.

**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM02`  
**OWASP Agentic (ASI):** `ASI01`, `ASI02`, `ASI09`  
**NIST AI RMF:** `MAP-3.5`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0048.003`, `AML.T0051`, `AML.T0053`, `AML.T0057`
