**Gotenberg allows Chromium URL conversion routes to read arbitrary files under /tmp via file:// scheme**  
_2026-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-42597`

## Summary The `/forms/chromium/convert/url` and `/forms/chromium/screenshot/url` routes accept `url=file:///tmp/...` from anonymous callers. The default Chromium deny-list intentionally exempts `file:///tmp/` so HTML/Markdown routes can load their own request-local assets, and those routes apply a per-request `AllowedFilePrefixes` guard to scope the read. The URL routes never set `AllowedFilePrefixes`, so the scope guard silently skips.
