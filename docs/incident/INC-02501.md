### INC-02501  [↗](/incident/INC-02501.html)

**DeepSeek AI vulnerability enables malware code generation**  
_2025-03-13 · vulnerability-disclosure · Severity: High_

Researchers found DeepSeek's R1 and V3 models could be jailbroken with relatively simple Evil-Jailbreak and Bad-Likert prompts to produce working malware, ransomware skeletons and keylogger code, with significantly lower refusal rates than GPT-4 or Claude.

**Affected:** DeepSeek users / potential victims  
**Attack vector:** `jailbreak`  

**OWASP LLM Top 10:** `LLM01`, `LLM09`  
**OWASP Agentic (ASI):** `ASI01`  
**NIST AI RMF:** `MEASURE-2.7`, `MEASURE-2.8`  
**MITRE ATLAS:** `AML.T0051`, `AML.T0054`, `AML.T0058`  

**References:**
- [OECD AIM - DeepSeek AI Vulnerability Enables Malware Code Generation](https://oecd.ai/en/incidents/2025-03-13-4007) _(research)_
