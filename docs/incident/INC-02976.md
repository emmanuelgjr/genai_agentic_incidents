### INC-02976  [↗](/incident/INC-02976.html)

**Obsidian GitHub Copilot Plugin versions prior to 1.1.7 store Github API token in cleartext form.**  
_2025-09 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-58401`
CVSS: **6.8**

Obsidian GitHub Copilot Plugin versions prior to 1.1.7 store Github API token in cleartext form. As a result, an attacker may perform unauthorized operations on the linked Github account.
