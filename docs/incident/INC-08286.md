### INC-08286  [↗](/incident/INC-08286.html)

**MCP Calculate Server — Rce (CVE-2026-44717)**  
_2026-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2026-44717`
CWEs: `CWE-94`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

MCP Calculate Server is a mathematical calculation service based on MCP protocol and SymPy library. Prior to 0.1.1, the use of eval() to evaluate mathematical expressions without proper input sanitization leads to remote code execution. This vulnerability is fixed in 0.1.1.

**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
