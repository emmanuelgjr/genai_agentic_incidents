### INC-11551  [↗](/incident/INC-11551.html)

**ruby-saml vulnerable to XPath injection**  
_2023-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2015-20108`
CWEs: `CWE-77`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

`xml_security.rb` in the ruby-saml gem before 1.0.0 for Ruby allows XPath injection and code execution because prepared statements are not used.

**Affected:** rubygems/ruby-saml  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
