### INC-10689  [↗](/incident/INC-10689.html)

**Vaultwarden HTML injection vulnerability**  
_2025-01 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2024-55224`
CWEs: `CWE-79`

An HTML injection vulnerability in Vaultwarden prior to v1.32.5 allows attackers to execute arbitrary code via injecting a crafted payload into the username field of an e-mail message.

**Affected:** rust/vaultwarden  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
