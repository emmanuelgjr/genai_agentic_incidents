### INC-11410  [↗](/incident/INC-11410.html)

**Subrion CMS Cross-site Scripting vulnerability in /panel/languages**  
_2023-09 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2023-43828`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

A Cross-site scripting (XSS) vulnerability in /panel/languages/ of Subrion v4.2.1 allow attackers to execute arbitrary web scripts or HTML via a crafted payload injected into 'Title' parameter.

**Affected:** composer/intelliants/subrion  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
