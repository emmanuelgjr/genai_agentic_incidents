### INC-11418  [↗](/incident/INC-11418.html)

**Magento Open Source affected by Improper Input Validation**  
_2023-09 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2022-24093`
CWEs: `CWE-20`
CVSS: **7.2** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:H/A:H`

Adobe Commerce versions 2.4.3-p1 (and earlier) and 2.3.7-p2 (and earlier) are affected by an improper input validation vulnerability. Exploitation of this issue does not require user interaction and could result in a post-authentication arbitrary code execution.

**Affected:** composer/magento/project-community-edition, composer/magento/community-edition, composer/magento/community-edition  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
