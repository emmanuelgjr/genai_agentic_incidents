### INC-11343  [↗](/incident/INC-11343.html)

**Liferay Portal XSS with `p_l_back_url_title` on edit content page**  
_2023-11 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2023-47797`
CWEs: `CWE-79`
CVSS: **9.6** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:H/I:H/A:H`

Reflected cross-site scripting (XSS) vulnerability on a content page’s edit page in Liferay Portal 7.4.3.94 through 7.4.3.95 allows remote attackers to inject arbitrary web script or HTML via the `p_l_back_url_title` parameter.

**Affected:** maven/com.liferay.portal:release.portal.bom  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
