### INC-11742  [↗](/incident/INC-11742.html)

**Jenkins Reverse Proxy Auth Plugin vulnerable due to plaintext storage of passwords**  
_2022-11 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2022-45384`, `CVE-2022-45386`, `CVE-2022-45395`, `CVE-2022-45396`, `CVE-2022-45397`, `CVE-2022-45400`
CWEs: `CWE-256`, `CWE-522`, `CWE-611`
CVSS: **6.5** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`

Jenkins Reverse Proxy Auth Plugin versions 1.7.3 and earlier stores the LDAP manager password unencrypted in the global config.xml file on the Jenkins controller where it can be viewed by attackers with access to the Jenkins controller file system.

**Affected:** maven/org.jenkins-ci.main:reverse-proxy-auth-plugin  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
