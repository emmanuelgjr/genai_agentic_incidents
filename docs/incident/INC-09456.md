### INC-09456  [↗](/incident/INC-09456.html)

**EVE Doesn't Protect Config Partition with Measured Boot**  
_2026-02 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2023-43634`
CWEs: `CWE-522`, `CWE-922`
CVSS: **5.9** — `CVSS:3.1/AV:P/AC:L/PR:L/UI:N/S:C/C:L/I:H/A:N`

### Impact Config partition measurement was moved from PCR 13 to PCR 14 in a commit, but PCR 14 was not added to the list of PCRs that seal/unseal the vault key. As a result, an attacker can remove the disk, use another server to modify the files in the config partition, and then re-insert the disk. ### Patches Fixed in EVE version 9.4.3-lts ### Workarounds None (apart from preventing physical access to the device) ### Resources https://help.zededa.com/hc/en-us/articles/43295940828827-TPM-PCR-Index-Security-Implications https://github.com/lf-edge/eve/commit/d9383a7ee4e1c39f5c8c6d4a63cb2ebd00695e8a
