**Admidio: CSRF in SSO client `enable` action toggles SAML/OIDC clients without token validation**  
_2026-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-47229`
CWEs: `CWE-352`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:L/A:L`

## Summary `modules/sso/clients.php` validates an `adm_csrf_token` on every state-changing branch except `enable`. The `enable` case loads the SAML or OIDC client by UUID, calls `$client->enable($enabled)`, and persists the new state with no token check. Because the action is reachable via plain GET parameters, a third-party page can trick an authenticated administrator into disabling (or silently re-enabling) any configured SAML or OIDC client.
