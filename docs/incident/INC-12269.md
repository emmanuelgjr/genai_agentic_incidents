### INC-12269  [↗](/incident/INC-12269.html)

**XXE vulnerability in Jenkins PMD Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2018-1000008`, `CVE-2018-1000009`, `CVE-2018-1000010`, `CVE-2018-1000011`, `CVE-2018-1000012`, `CVE-2018-1000015`
CWEs: `CWE-611`, `CWE-862`
CVSS: **8.8** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

Jenkins PMD Plugin 3.49 and earlier processes XML external entities in files it parses as part of the build process, allowing attackers with user permissions in Jenkins to extract secrets from the Jenkins master, perform server-side request forgery, or denial-of-service attacks.

**Affected:** maven/org.jvnet.hudson.plugins:pmd  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
