### INC-12507  [↗](/incident/INC-12507.html)

**Agent-to-controller security bypass in Jenkins HashiCorp Vault Plugin**  
_2022-02 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2022-25186`, `CVE-2022-25191`, `CVE-2022-25197`, `CVE-2022-25204`, `CVE-2022-25207`, `CVE-2022-25208`, `CVE-2022-25209`
CWEs: `CWE-352`, `CWE-611`, `CWE-693`, `CWE-79`, `CWE-862`
CVSS: **3.1** — `CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:U/C:L/I:N/A:N`

Jenkins HashiCorp Vault Plugin 3.8.0 and earlier implements functionality that allows agent processes to retrieve any Vault secrets for use on the agent, allowing attackers able to control agent processes to obtain Vault secrets for an attacker-specified path and key.

**Affected:** maven/com.datapipe.jenkins.plugins:hashicorp-vault-plugin  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
