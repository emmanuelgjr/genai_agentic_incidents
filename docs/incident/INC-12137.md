### INC-12137  [↗](/incident/INC-12137.html)

**Improper Neutralization of Input During Web Page Generation in JavaMelody**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2013-4378`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in HtmlSessionInformationsReport.java in JavaMelody 1.46 and earlier allows remote attackers to inject arbitrary web script or HTML via a crafted X-Forwarded-For header.

**Affected:** maven/net.bull.javamelody:javamelody-core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
