### INC-11611  [↗](/incident/INC-11611.html)

**HashiCorp Nomad vulnerable to unauthenticated client agent HTTP request privilege escalation**  
_2023-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-1782`
CWEs: `CWE-285`, `CWE-862`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

HashiCorp Nomad and Nomad Enterprise versions 1.5.0 up to 1.5.2 allow unauthenticated users to bypass intended ACL authorizations for clusters where mTLS is not enabled. This issue is fixed in version 1.5.3.

**Affected:** go/github.com/hashicorp/nomad  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
