### INC-12228  [↗](/incident/INC-12228.html)

**Fork CMS Multiple XSS Vulnerabilities**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2012-1188`
CWEs: `CWE-79`

Multiple cross-site scripting (XSS) vulnerabilities in Fork CMS before 3.2.7 allow remote attackers to inject arbitrary web script or HTML via the (1) type or (2) querystring parameters to `private/en/error` or (3) name parameter to `private/en/locale/index`.

**Affected:** composer/forkcms/forkcms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
