### INC-09246  [↗](/incident/INC-09246.html)

**StudioCMS has Privilege Escalation via Insecure API Token Generation**  
_2026-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-30944`
CWEs: `CWE-639`, `CWE-863`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

## Summary The /studiocms_api/dashboard/api-tokens endpoint allows any authenticated user (at least Editor) to generate API tokens for any other user, including owner and admin accounts. The endpoint fails to validate whether the requesting user is authorized to create tokens on behalf of the target user ID, resulting in a full privilege escalation. ## Details The API token generation endpoint accepts a user parameter in the request body that specifies which user the token should be created for. The server-side logic authenticates the session (via auth_session cookie) but does not verify that the authenticated user matches the target user ID nor checks if the caller has sufficient privileges to perform this action on behalf of another user.
