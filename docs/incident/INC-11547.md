### INC-11547  [↗](/incident/INC-11547.html)

**Hashicorp Consul allows user with service:write permissions to patch remote proxy instances**  
_2023-06 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-2816`
CWEs: `CWE-266`
CVSS: **8.7** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:C/C:H/I:H/A:N`

Consul and Consul Enterprise allowed any user with service:write permissions to use Envoy extensions configured via service-defaults to patch remote proxy instances that target the configured service, regardless of whether the user has permission to modify the service(s) corresponding to those modified proxies.

**Affected:** go/github.com/hashicorp/consul  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
