### INC-12278  [↗](/incident/INC-12278.html)

**Liferay Portal XSS vulnerability via movie parameter in the /html/portal/flash.jsp page**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2017-1000425`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Cross-site scripting (XSS) vulnerability in the /html/portal/flash.jsp page in Liferay Portal CE 7.0 GA4 and older allows remote attackers to inject arbitrary web script or HTML via a javascript: URI in the "movie" parameter.

**Affected:** maven/com.liferay.portal:release.portal.bom  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
