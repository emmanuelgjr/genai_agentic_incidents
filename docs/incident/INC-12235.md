### INC-12235  [↗](/incident/INC-12235.html)

**powermail extension for TYPO3 has Cross-site Scripting vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2012-5889`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the powermail extension before 1.6.5 for TYPO3 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/in2code/powermail  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
