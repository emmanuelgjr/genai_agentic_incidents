### INC-11789  [↗](/incident/INC-11789.html)

**Apache Batik vulnerable to Server-Side Request Forgery**  
_2022-09 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2022-38398`, `CVE-2022-38648`, `CVE-2022-40146`
CWEs: `CWE-918`
CVSS: **7.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N`

Server-Side Request Forgery (SSRF) vulnerability in Batik of Apache XML Graphics allows an attacker to access files using a Jar url. This issue affects Apache XML Graphics Batik 1.14.

**Affected:** maven/org.apache.xmlgraphics:batik  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
