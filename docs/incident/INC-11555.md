### INC-11555  [↗](/incident/INC-11555.html)

**Cross-site scripting in Liferay Portal**  
_2023-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2023-33937`, `CVE-2023-33938`, `CVE-2023-33939`, `CVE-2023-33940`, `CVE-2023-33941`, `CVE-2023-33942`, `CVE-2023-33943`, `CVE-2023-33944`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Cross-site scripting (XSS) vulnerability in Layout module in Liferay Portal 7.3.4 through 7.4.3.68, and Liferay DXP 7.3 before update 24, and 7.4 before update 69 allows remote attackers to inject arbitrary web script or HTML via a crafted payload injected into a container type layout fragment's `URL` text field.

**Affected:** maven/com.liferay.portal:release.portal.bom  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
