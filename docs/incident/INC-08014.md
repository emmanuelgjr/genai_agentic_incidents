### INC-08014  [↗](/incident/INC-08014.html)

**Critical Remote Code Execution Vulnerability in Flowise's MCP Implementation Exposes AI Deployments**  
_2026-06-01 · real-world · Severity: High_

A severe remote code execution vulnerability (CVE-2026-40933) was discovered in Flowise's implementation of the Model Context Protocol (MCP), allowing attackers to execute arbitrary code on self-hosted AI platforms. This flaw risks exposure of API keys, databases, and cloud resources, posing significant security threats to organizations using Flowise for AI workloads.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0050`, `AML.T0057`
