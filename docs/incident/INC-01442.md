### INC-01442  [↗](/incident/INC-01442.html)

**Microsoft's AI-Powered Recall Feature Still Exposes Sensitive User Data Despite Security Overhaul**  
_2026-04-15 · real-world · Severity: High_

Microsoft's AI-powered Recall feature for Windows continues to face criticism after cybersecurity researcher Alexander Hagenah demonstrated that sensitive user data can still be extracted using his TotalRecall Reloaded tool. Despite Microsoft's security redesign, flaws in Recall's data delivery process allow unauthorized access, raising ongoing privacy and data protection concerns.
