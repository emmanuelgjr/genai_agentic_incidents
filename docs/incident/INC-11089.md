### INC-11089  [↗](/incident/INC-11089.html)

**Magento remote code execution (RCE), Cross-Site Scripting (XSS) and other vulnerabilities**  
_2024-05 · vulnerability-disclosure · Severity: Critical_

Magento Commerce and Open Source 2.2.5 and 2.1.14 contain multiple security enhancements that help close authenticated Admin user remote code execution (RCE), Cross-Site Scripting (XSS) and other vulnerabilities.

**Affected:** composer/magento/community-edition, composer/magento/community-edition  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
