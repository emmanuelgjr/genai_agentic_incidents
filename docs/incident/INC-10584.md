### INC-10584  [↗](/incident/INC-10584.html)

**Clickstorm SEO Allows Cross-Site Scripting (XSS)**  
_2025-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-30081`
CWEs: `CWE-79`
CVSS: **5.9** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:L/A:L/E:F/RL:O/RC:C`

A cross-site scripting (XSS) vulnerability has been discovered in the Clickstorm SEO extension. This vulnerabily is exploitable by a logged in backend user utilizing the TYPO3 backend user interface. This user can create output in the HTML context by exploiting improperly encoded user input. Updates 6.7.0, 7.4.0, 8.3.0 and 9.2.0 are available for download.

**Affected:** composer/clickstorm/cs-seo, composer/clickstorm/cs-seo, composer/clickstorm/cs-seo  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
