### INC-04270  [↗](/incident/INC-04270.html)

**The AI ChatBot plugin for WordPress is vulnerable to unauthorized access of data due to a missing capability check on the openai_file_list_callback function in all versions up t...**  
_2024-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-0451`, `CVE-2024-0452`, `CVE-2024-0453`
CWEs: `CWE-284`, `CWE-862`
CVSS: **5.0** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:C/C:L/I:N/A:N`

The AI ChatBot plugin for WordPress is vulnerable to unauthorized access of data due to a missing capability check on the openai_file_list_callback function in all versions up to, and including, 5.3.4. This makes it possible for authenticated attackers, with subscriber-level access and above, to list files existing in a linked OpenAI account.

**Affected:** quantumcloud/wpbot  
**Attack vector:** `other`
