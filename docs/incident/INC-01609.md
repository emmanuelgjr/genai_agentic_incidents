### INC-01609  [↗](/incident/INC-01609.html)

**OrcaStatLLM Researcher — Xss (CVE-2026-24903)**  
_2026-02 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-24903`
CVSS: **5.4**

OrcaStatLLM Researcher is an LLM Based Research Paper Generator. A Stored Cross-Site Scripting (XSS) vulnerability was discovered in the Log Message in the Session Page in OrcaStatLLM-Researcher that allows attackers to inject and execute arbitrary JavaScript code in victims' browsers through malicious research topic inputs.

**Affected:** algonet/orcastatllm_researcher  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
