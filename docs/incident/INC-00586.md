### INC-00586  [↗](/incident/INC-00586.html)

**Android Facial Recognition Flaw Allows Unauthorized Access via Photos**  
_2026-04-16 · real-world · Severity: High_

Consumer group Which? found that 64% of Android smartphones tested since 2022 can be unlocked using a printed photo, exposing a major security flaw in AI-based facial recognition systems. This vulnerability affects flagship models and risks user privacy and data security in the UK.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`  
**OWASP Agentic (ASI):** `ASI03`  
**NIST AI RMF:** `GOVERN-1.4`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0057`
