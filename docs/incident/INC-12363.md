### INC-12363  [↗](/incident/INC-12363.html)

**Cross-site Scripting in Jenkins Build Failure Analyzer plugin**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2016-4988`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Cross-site scripting (XSS) vulnerability in the Build Failure Analyzer plugin before 1.16.0 in Jenkins allows remote attackers to inject arbitrary web script or HTML via an unspecified parameter.

**Affected:** maven/com.sonyericsson.jenkins.plugins.bfa:build-failure-analyzer  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
