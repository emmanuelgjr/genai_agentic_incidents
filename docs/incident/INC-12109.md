### INC-12109  [↗](/incident/INC-12109.html)

**Access control bypass in beego**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2022-31259`
CWEs: `CWE-284`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

The route lookup process in beego prior to 1.12.9 and 2.x prior to 2.0.3 allows attackers to bypass access control. When a /`p1`/`p2`/`:name` route is configured, attackers can access it by appending .xml in various places (e.g., p1.xml instead of p1).

**Affected:** go/github.com/beego/beego, go/github.com/beego/beego/v2  
**Attack vector:** `auth-bypass`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`
