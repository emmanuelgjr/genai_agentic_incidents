### INC-02872  [↗](/incident/INC-02872.html)

**MCP Server Kubernetes — Prompt Injection (CVE-2025-66404)**  
_2025-12 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-66404`
CWEs: `CWE-77`
CVSS: **6.4** — `CVSS:3.1/AV:N/AC:H/PR:H/UI:R/S:U/C:H/I:H/A:H`

MCP Server Kubernetes is an MCP Server that can connect to a Kubernetes cluster and manage it. Prior to 2.9.8, there is a security issue exists in the exec_in_pod tool of the mcp-server-kubernetes MCP Server. The tool accepts user-provided commands in both array and string formats. When a string format is provided, it is passed directly to shell interpretation (sh -c) without input validation, allowing shell metacharacters to be interpreted. This vulnerability can be exploited through direct command injection or indirect prompt injection attacks, where AI agents may execute commands without explicit user intent. This vulnerability is fixed in 2.9.8.

**Affected:** suyogs/mcp-server-kubernetes  
**Attack vector:** `prompt-injection`
