### INC-08085  [↗](/incident/INC-08085.html)

**OpenAI Codex Enables Discovery of HTTP/2 Bomb DoS Attack on Major Web Servers**  
_2026-06-03 · real-world · Severity: Medium_

Researchers at Calif used OpenAI's Codex AI system to discover the HTTP/2 Bomb, a new denial-of-service attack that can rapidly crash major web servers (NGINX, Apache, IIS, Envoy, Cloudflare Pingora) by exploiting compression and flow-control vulnerabilities. The attack can exhaust server memory in seconds, disrupting critical infrastructure globally.

**Attack vector:** `dos`
