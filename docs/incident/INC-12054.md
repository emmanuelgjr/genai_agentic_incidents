### INC-12054  [↗](/incident/INC-12054.html)

**Remote Code Execution vulnerability in Jenkins Literate Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-2137`, `CVE-2020-2138`, `CVE-2020-2144`, `CVE-2020-2146`, `CVE-2020-2158`
CWEs: `CWE-347`, `CWE-502`, `CWE-611`, `CWE-79`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

Jenkins Literate Plugin 1.0 and earlier does not configure its YAML parser to prevent the instantiation of arbitrary types, resulting in a remote code execution vulnerability.

**Affected:** maven/org.jenkins-ci.plugins:literate  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
