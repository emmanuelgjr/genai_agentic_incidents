### INC-12283  [↗](/incident/INC-12283.html)

**OISF suricata-update unsafely deserializes YAML data**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2018-1000167`
CWEs: `CWE-502`
CVSS: **7.8** — `CVSS:3.0/AV:L/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

Suricata-Update uses the insecure `yaml.load()` function. Code will be executed if the yaml-file contains lines like: ```yaml hello: !!python/object/apply:os.system ['ls -l > /tmp/output'] ``` The vulnerable function can be triggered by "suricata-update list-sources". The locally stored index.yaml will be loaded in this function and the malicious code gets executed.

**Affected:** pip/suricata-update  
**Attack vector:** `deserialization`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0010.001`, `AML.T0050`
