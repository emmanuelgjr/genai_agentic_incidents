**A prompt injection vulnerability in the chatbox of Butterfly Effect Limited Monica Your AI Copilot powered by ChatGPT4 v6.3.0 allows attackers to access and exfiltrate all previ...**  
_2024-10 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-45989`, `CVE-2024-48140`, `CVE-2024-48142`
CWEs: `CWE-77`
CVSS: **7.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N`

A prompt injection vulnerability in the chatbox of Butterfly Effect Limited Monica Your AI Copilot powered by ChatGPT4 v6.3.0 allows attackers to access and exfiltrate all previous and subsequent chat data between the user and the AI assistant via a crafted message.

**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM05`  
**OWASP Agentic (ASI):** `ASI01`, `ASI05`  
**NIST AI RMF:** `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0050`, `AML.T0051`
