### INC-12478  [↗](/incident/INC-12478.html)

**XML external entity (XXE) attacks in Jenkins Xcode integration Plugin**  
_2022-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2021-21656`
CWEs: `CWE-611`
CVSS: **7.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:L/A:N`

Jenkins Xcode integration Plugin 2.0.14 and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks.

**Affected:** maven/org.jenkins-ci.plugins:xcode-plugin  
**Attack vector:** `other`
