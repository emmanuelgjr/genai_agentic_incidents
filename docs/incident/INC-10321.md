### INC-10321  [↗](/incident/INC-10321.html)

**ExecuTorch integer overflow vulnerability**  
_2025-08 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2025-30404`, `CVE-2025-30405`
CWEs: `CWE-190`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

An integer overflow vulnerability in the loading of ExecuTorch models can cause overlapping allocations, potentially resulting in code execution or other undesirable effects. This issue affects ExecuTorch prior to commit d158236b1dc84539c1b16843bc74054c9dcba006.

**Affected:** swift/github.com/pytorch/executorch, maven/org.pytorch:executorch-android, pip/executorch  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
