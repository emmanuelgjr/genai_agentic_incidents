### INC-00604  [↗](/incident/INC-00604.html)

**Anthropic Faces Security Scrutiny After Claude Code and Mythos AI Leaks**  
_2026-03-30 · real-world · Severity: High_

Anthropic experienced two major AI-related leaks: the accidental exposure of Claude Code's internal source code and the public disclosure of the unreleased Claude Mythos model due to human error. While no direct harm has occurred, experts warn these leaks could enable sophisticated cyberattacks, raising significant AI security concerns.

**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM02`, `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI01`, `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0050`, `AML.T0051`, `AML.T0057`
