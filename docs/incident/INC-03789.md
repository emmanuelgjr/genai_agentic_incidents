### INC-03789  [↗](/incident/INC-03789.html)

**Flowise — Path Traversal (CVE-2024-36420)**  
_2024-07 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-36420`, `CVE-2024-36421`, `CVE-2024-36422`, `CVE-2024-36423`, `CVE-2024-37145`, `CVE-2024-37146`
CVSS: **7.5**

Flowise is a drag & drop user interface to build a customized large language model flow. In version 1.4.3 of Flowise, the `/api/v1/openai-assistants-file` endpoint in `index.ts` is vulnerable to arbitrary file read due to lack of sanitization of the `fileName` body parameter. No known patches for this issue are available.

**Affected:** flowiseai/flowise  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0050`
