### INC-09784  [↗](/incident/INC-09784.html)

**IBM Langflow Desktop 1.2.0 through 1.8.4 Langflow could allow an authenticated attacker to traverse directories on the system.**  
_2026-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-4502`
CWEs: `CWE-22`
CVSS: **6.5** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:H/A:N`

IBM Langflow Desktop 1.2.0 through 1.8.4 Langflow could allow an authenticated attacker to traverse directories on the system. An attacker could send a specially crafted URL request containing "dot dot" sequences (/../) to write arbitrary files on the system.

**Affected:** langflow/langflow_desktop  
**Attack vector:** `other`
