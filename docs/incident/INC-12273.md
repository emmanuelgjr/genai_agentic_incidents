### INC-12273  [↗](/incident/INC-12273.html)

**Improper Restriction of XML External Entity Reference in Jenkins JUnit Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2018-1000054`, `CVE-2018-1000055`, `CVE-2018-1000056`
CWEs: `CWE-611`
CVSS: **8.3** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:L/A:H`

Jenkins JUnit Plugin 1.23 and earlier processes XML external entities in files it parses as part of the build process, allowing attackers with user permissions in Jenkins to extract secrets from the Jenkins master, perform server-side request forgery, or denial-of-service attacks.

**Affected:** maven/org.jenkins-ci.plugins:junit  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
