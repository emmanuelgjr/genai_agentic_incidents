### INC-11981  [↗](/incident/INC-11981.html)

**Uncontrolled Recursion in Akka HTTP**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2021-42697`
CWEs: `CWE-674`, `CWE-787`
CVSS: **7.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H`

Akka HTTP 10.1.x and 10.2.x before 10.2.7 can encounter stack exhaustion while parsing HTTP headers, which allows a remote attacker to conduct a Denial of Service attack by sending a User-Agent header with deeply nested comments.

**Affected:** maven/com.typesafe.akka:akka-http-core_2.11, maven/com.typesafe.akka:akka-http-core_2.12, maven/com.typesafe.akka:akka-http-core_2.12  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
