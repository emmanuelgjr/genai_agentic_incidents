### INC-12274  [↗](/incident/INC-12274.html)

**phpMyAdmin Cross-site scripting (XSS) vulnerability in central columns feature**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2018-7260`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

Cross-site scripting (XSS) vulnerability in db_central_columns.php in phpMyAdmin before 4.7.8 allows remote authenticated users to inject arbitrary web script or HTML via a crafted URL.

**Affected:** composer/phpmyadmin/phpmyadmin  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
