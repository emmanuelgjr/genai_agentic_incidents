### INC-11681  [↗](/incident/INC-11681.html)

**XML external entity vulnerability on agents in Jenkins MSTest Plugin**  
_2023-01 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2023-24429`, `CVE-2023-24430`, `CVE-2023-24441`, `CVE-2023-24443`, `CVE-2023-24450`
CWEs: `CWE-256`, `CWE-312`, `CWE-611`, `CWE-776`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

Jenkins MSTest Plugin 1.0.0 and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks.

**Affected:** maven/org.jvnet.hudson.plugins:mstest  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
