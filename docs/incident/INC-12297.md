### INC-12297  [↗](/incident/INC-12297.html)

**Improper Input Validation in Apache Jackrabbit**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2015-1833`
CWEs: `CWE-20`

XML external entity (XXE) vulnerability in Apache Jackrabbit before 2.0.6, 2.2.x before 2.2.14, 2.4.x before 2.4.6, 2.6.x before 2.6.6, 2.8.x before 2.8.1, and 2.10.x before 2.10.1 allows remote attackers to read arbitrary files and send requests to intranet servers via a crafted WebDAV request.

**Affected:** maven/org.apache.jackrabbit:jackrabbit-core, maven/org.apache.jackrabbit:jackrabbit-core, maven/org.apache.jackrabbit:jackrabbit-core  
**Attack vector:** `other`
