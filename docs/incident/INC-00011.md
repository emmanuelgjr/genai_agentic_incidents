### INC-00011  [↗](/incident/INC-00011.html)

**A path traversal vulnerability exists in the `extract_archive_to_dir` function within the `mlflow/pyfunc/dbconnect_artifact_cache.py` file of the mlflow/mlflow repository.**  
_2026-03 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2025-15036`
CVSS: **10.0**

A path traversal vulnerability exists in the `extract_archive_to_dir` function within the `mlflow/pyfunc/dbconnect_artifact_cache.py` file of the mlflow/mlflow repository. This vulnerability, present in versions before v3.7.0, arises due to the lack of validation of tar member paths during extraction. An attacker with control over the tar.gz file can exploit this issue to overwrite arbitrary files or gain elevated privileges, potentially escaping the sandbox directory in multi-tenant or shared cluster environments.

**Affected:** lfprojects/mlflow  
**Attack vector:** `path-traversal`
