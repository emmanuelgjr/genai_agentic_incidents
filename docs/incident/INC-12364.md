### INC-12364  [↗](/incident/INC-12364.html)

**Jenkins Extra Columns Plugin allows Cross-Site Scripting (XSS)**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2016-3101`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

Cross-site scripting (XSS) vulnerability in the Extra Columns plugin before 1.17 in Jenkins allows remote attackers to inject arbitrary web script or HTML by leveraging failure to filter tool tips through the configured markup formatter.

**Affected:** maven/org.jenkins-ci.plugins:extra-columns  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
