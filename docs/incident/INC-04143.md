### INC-04143  [↗](/incident/INC-04143.html)

**RAIL documents are an XML-based format invented by Guardrails AI to enforce formatting checks on LLM outputs.**  
_2024-07 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-6961`
CVSS: **5.9**

RAIL documents are an XML-based format invented by Guardrails AI to enforce formatting checks on LLM outputs. Guardrails users that consume RAIL documents from external sources are vulnerable to XXE, which may cause leakage of internal file data via the SYSTEM entity.

**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
