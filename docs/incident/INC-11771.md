### INC-11771  [↗](/incident/INC-11771.html)

**Jenkins NUnit Plugin vulnerable to Protection Mechanism Failure**  
_2022-10 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2022-43414`, `CVE-2022-43415`, `CVE-2022-43416`, `CVE-2022-43420`, `CVE-2022-43422`, `CVE-2022-43423`, `CVE-2022-43424`, `CVE-2022-43428`, `CVE-2022-43429`, `CVE-2022-43430`, `CVE-2022-43435`
CWEs: `CWE-284`, `CWE-552`, `CWE-610`, `CWE-611`, `CWE-693`, `CWE-79`
CVSS: **5.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N`

Jenkins NUnit Plugin 0.27 and earlier implements an agent-to-controller message that parses files inside a user-specified directory as test results, allowing attackers able to control agent processes to obtain test results from files in an attacker-specified directory on the Jenkins controller. NUnit Plugin 0.28 changes the message type from agent-to-controller to controller-to-agent, preventing execution on the controller.

**Affected:** maven/org.jenkins-ci.plugins:nunit  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
