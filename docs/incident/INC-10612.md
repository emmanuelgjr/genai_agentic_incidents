### INC-10612  [↗](/incident/INC-10612.html)

**PrismJS DOM Clobbering vulnerability**  
_2025-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-53382`
CWEs: `CWE-79`, `CWE-94`
CVSS: **4.9** — `CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:C/C:L/I:L/A:N`

Prism (aka PrismJS) through 1.29.0 allows DOM Clobbering (with resultant XSS for untrusted input that contains HTML but does not directly contain JavaScript), because document.currentScript lookup can be shadowed by attacker-injected HTML elements.

**Affected:** npm/prismjs  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
