### INC-00696  [↗](/incident/INC-00696.html)

**Blinko — Rce (CVE-2026-23882)**  
_2026-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-23882`
CVSS: **7.2**

Blinko is an AI-powered card note-taking project. Prior to version 1.8.4, the MCP (Model Context Protocol) server creation function allows specifying arbitrary commands and arguments, which are executed when testing the connection. This issue has been patched in version 1.8.4.

**Affected:** blinko/blinko  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
