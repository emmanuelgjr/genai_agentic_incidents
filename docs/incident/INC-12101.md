### INC-12101  [↗](/incident/INC-12101.html)

**Jenkins Azure AD Plugin stored the client secret unencrypted**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2019-10309`, `CVE-2019-10318`
CWEs: `CWE-522`, `CWE-611`
CVSS: **3.3** — `CVSS:3.0/AV:L/AC:L/PR:L/UI:N/S:U/C:L/I:N/A:N`

Jenkins Azure AD Plugin stored the client secret unencrypted in the global config.xml configuration file on the Jenkins controller. These credentials could be viewed by users with access to the Jenkins controller file system. Azure AD Plugin now stores the client secret encrypted.

**Affected:** maven/org.jenkins-ci.plugins:azure-ad  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`
