### INC-11269  [↗](/incident/INC-11269.html)

**Grafana Arbitrary File Read**  
_2024-01 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2019-19499`
CWEs: `CWE-200`, `CWE-22`, `CWE-89`
CVSS: **6.2** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N/E:P`

Grafana <= 6.4.3 has an Arbitrary File Read vulnerability, which could be exploited by an authenticated attacker that has privileges to modify the data source configurations.

**Affected:** go/github.com/grafana/grafana  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
