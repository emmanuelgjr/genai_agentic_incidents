### INC-12173  [↗](/incident/INC-12173.html)

**Jenkins allows Cross-Site Scripting (XSS)**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2011-4344`, `CVE-2012-0324`, `CVE-2012-0325`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in Jenkins Core in Jenkins before 1.438, and 1.409 LTS before 1.409.3 LTS, when a stand-alone container is used, allows remote attackers to inject arbitrary web script or HTML via vectors related to error messages.

**Affected:** maven/org.jenkins-ci.main:jenkins-core, maven/org.jenkins-ci.main:jenkins-core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
