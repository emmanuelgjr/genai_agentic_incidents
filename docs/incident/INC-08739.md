### INC-08739  [↗](/incident/INC-08739.html)

**Spring AI has SQL Injection in CosmosDBVectorStore.doDelete()**  
_2026-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-40978`
CWEs: `CWE-89`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

SQL injection vulnerability in Spring AI's `CosmosDBVectorStore` allows attackers to execute arbitrary SQL queries via crafted document IDs. Affected versions: Spring AI: 1.0.0 - 1.0.5 (fixed in 1.0.6), 1.1.0 - 1.1.4 (fixed in 1.1.5).

**Affected:** maven/org.springframework.ai:spring-ai-azure-cosmos-db-store, maven/org.springframework.ai:spring-ai-azure-cosmos-db-store  
**Attack vector:** `sql-injection`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
