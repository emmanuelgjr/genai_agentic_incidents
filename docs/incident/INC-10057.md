### INC-10057  [↗](/incident/INC-10057.html)

**phpMyFAQ has Authenticated SQL Injection in Configuration Update Functionality**  
_2025-11 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-62519`
CWEs: `CWE-89`
CVSS: **7.2** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:H/A:H`

### Summary An authenticated SQL injection vulnerability in the main configuration update functionality of phpMyFAQ (v4.0.13 and prior) allows a privileged user with 'Configuration Edit' permissions to execute arbitrary SQL commands. Successful exploitation can lead to a full compromise of the database, including reading, modifying, or deleting all data, as well as potential remote code execution depending on the database configuration. ### Details The vulnerability exists in the `save` method within the `src/phpMyFAQ/Controller/Administration/ConfigurationTabController.php` controller. This method handles the saving of application-wide configuration settings. It retrieves all submitted form data as an associative array via `$request->get('edit')`.
