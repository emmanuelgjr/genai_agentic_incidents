### INC-10536  [↗](/incident/INC-10536.html)

**NVIDIA Nemo Framework contains a vulnerability where a user could cause a relative path traversal issue by arbitrary file write.**  
_2025-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-23360`
CWEs: `CWE-23`
CVSS: **7.1** — `CVSS:3.1/AV:L/AC:L/PR:N/UI:R/S:U/C:N/I:H/A:H`

NVIDIA Nemo Framework contains a vulnerability where a user could cause a relative path traversal issue by arbitrary file write. A successful exploit of this vulnerability may lead to code execution and data tampering.

**Affected:** nvidia/nemo, apple/macos, linux/linux_kernel, microsoft/windows  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
