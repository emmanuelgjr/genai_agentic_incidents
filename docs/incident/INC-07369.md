### INC-07369  [↗](/incident/INC-07369.html)

**Airwatch Agent for Android contains a vulnerability that may allow a device to bypass root detection.**  
_2017-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2017-4895`
CVSS: **8.8** — `CVSS:3.0/AV:L/AC:L/PR:L/UI:N/S:C/C:H/I:H/A:H`

Airwatch Agent for Android contains a vulnerability that may allow a device to bypass root detection. Successful exploitation of this issue may result in an enrolled device having unrestricted access over local Airwatch security controls and data.

**Affected:** vmware/airwatch_agent, vmware/airwatch_inbox  
**Attack vector:** `other`
