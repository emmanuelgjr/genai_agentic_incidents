### INC-00520  [↗](/incident/INC-00520.html)

**AI-Generated VoidLink Malware Marks New Era in Cyber Threats**  
_2026-01-19 · real-world · Severity: High_

Check Point Research discovered VoidLink, an advanced malware framework for Linux cloud environments, generated almost entirely by AI. Developed rapidly by a single actor, VoidLink demonstrates how AI accelerates sophisticated cyberattacks, enabling stealthy, hard-to-detect threats that target major cloud platforms and pose significant cybersecurity risks.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`
