### INC-12328  [↗](/incident/INC-12328.html)

**Croogo vulnerable to XSS in title field**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2019-7168`, `CVE-2019-7169`, `CVE-2019-7170`, `CVE-2019-7171`, `CVE-2019-7173`
CWEs: `CWE-79`
CVSS: **4.8** — `CVSS:3.0/AV:N/AC:L/PR:H/UI:R/S:C/C:L/I:L/A:N`

A stored-self XSS exists in Croogo through v3.0.5, allowing an attacker to execute HTML or JavaScript code in a vulnerable Title field to /admin/blocks/blocks/edit/8.

**Affected:** composer/croogo/croogo  
**Attack vector:** `xss`

**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
