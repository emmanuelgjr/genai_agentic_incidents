### INC-10643  [↗](/incident/INC-10643.html)

**Improper Authorization vulnerability in Magento and Adobe Commerce**  
_2025-02 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2025-24406`, `CVE-2025-24408`, `CVE-2025-24410`, `CVE-2025-24411`, `CVE-2025-24412`, `CVE-2025-24413`, `CVE-2025-24414`, `CVE-2025-24415`, `CVE-2025-24416`, `CVE-2025-24417`, `CVE-2025-24421`, `CVE-2025-24424`, `CVE-2025-24425`, `CVE-2025-24427`, `CVE-2025-24428`, `CVE-2025-24429`, `CVE-2025-24430`, `CVE-2025-24432`, `CVE-2025-24434`, `CVE-2025-24435`, `CVE-2025-24436`, `CVE-2025-24437`, `CVE-2025-24438`
CWEs: `CWE-200`, `CWE-22`, `CWE-284`, `CWE-285`, `CWE-367`, `CWE-79`, `CWE-863`
CVSS: **9.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N`

Adobe Commerce versions 2.4.8-beta1, 2.4.7-p3, 2.4.6-p8, 2.4.5-p10, 2.4.4-p11 and earlier are affected by an Improper Authorization vulnerability that could result in Privilege escalation. An attacker could leverage this vulnerability to bypass security measures and gain unauthorized access. Exploitation of this issue does not require user interaction. A successful attacker can abuse this to achieve session takeover, increasing the confidentiality and integrity impact as high.

**Affected:** composer/magento/project-community-edition, composer/magento/community-edition, composer/magento/community-edition  
**Attack vector:** `auth-bypass`
