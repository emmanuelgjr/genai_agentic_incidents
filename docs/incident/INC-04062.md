### INC-04062  [↗](/incident/INC-04062.html)

**Open WebUI — Ssrf (CVE-2024-30256)**  
_2024-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-30256`
CVSS: **6.4**

Open WebUI is a user-friendly WebUI for LLMs. Open-webui is vulnerable to authenticated blind server-side request forgery. This vulnerability is fixed in 0.1.117.

**Affected:** openwebui/open_webui  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
