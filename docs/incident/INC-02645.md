### INC-02645  [↗](/incident/INC-02645.html)

**GPT Academic version 3.83 is vulnerable to a Server-Side Request Forgery (SSRF) vulnerability through its HotReload plugin function, which calls the crazy_utils.get_files_from_e...**  
_2025-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-11030`
CWEs: `CWE-918`
CVSS: **7.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N`

GPT Academic version 3.83 is vulnerable to a Server-Side Request Forgery (SSRF) vulnerability through its HotReload plugin function, which calls the crazy_utils.get_files_from_everything() API without proper sanitization. This allows attackers to exploit the vulnerability to abuse the victim GPT Academic's Gradio Web server's credentials to access unauthorized web resources.

**Affected:** binary-husky/gpt_academic  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
