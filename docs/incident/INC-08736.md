### INC-08736  [↗](/incident/INC-08736.html)

**Jenkins HTML Publisher Plugin has a XSS vulnerability in the legacy wrapper file**  
_2026-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-42524`
CWEs: `CWE-79`
CVSS: **8.0** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:U/C:H/I:H/A:H`

Jenkins HTML Publisher Plugin versoins 427 and earlier do not escape the job name and URL in the legacy wrapper file. This results in a stored cross-site scripting (XSS) vulnerability exploitable by attackers with Item/Configure permission. HTML Publisher Plugin 427.1 escapes job name and URL when generating the legacy wrapper file.

**Affected:** maven/org.jenkins-ci.plugins:htmlpublisher  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
