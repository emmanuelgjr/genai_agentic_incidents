### INC-12012  [↗](/incident/INC-12012.html)

**qlib Deserialization of Untrusted Data vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2021-23338`
CWEs: `CWE-502`, `CWE-94`
CVSS: **6.6** — `CVSS:3.1/AV:N/AC:H/PR:H/UI:N/S:U/C:H/I:H/A:H`

This affects all versions of package qlib. The workflow function in cli part of qlib was using an unsafe YAML load function.

**Affected:** pip/pyqlib  
**Attack vector:** `deserialization`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0010.001`, `AML.T0050`
