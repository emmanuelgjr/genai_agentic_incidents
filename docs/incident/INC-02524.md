### INC-02524  [↗](/incident/INC-02524.html)

**DisMech AI Curation Agent Reportedly Completed GitHub Issue Intended as New Contributor&#x27;s Learning Task**  
_2025 · real-world · Severity: Medium_
AIID: [`#1470`](https://incidentdatabase.ai/cite/1470/)

An automated AI curation agent in the Monarch Initiative&#x27;s DisMech GitHub repository reportedly began work on a beginner-friendly dyslexia curation task before the new human contributor it was intended for could do so. A maintainer apologized, saying the agent had deprived the contributor of a learning opportunity, and opened a policy issue to prevent automated agents from taking newcomer-oriented GitHub tasks too quickly.
