### INC-12237  [↗](/incident/INC-12237.html)

**Symphony Vulnerable to PHP Code Injection via YAML Parsing**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2013-1348`
CWEs: `CWE-94`

The `Yaml::parse` function in Symfony 2.0.x before 2.0.22 remote attackers to execute arbitrary PHP code via a PHP file, a different vulnerability than CVE-2013-1397.

**Affected:** composer/symfony/yaml, composer/symfony/symfony  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
