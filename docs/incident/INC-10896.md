### INC-10896  [↗](/incident/INC-10896.html)

**Mage AI Path Traversal vulnerability**  
_2024-08 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-45188`, `CVE-2024-45189`, `CVE-2024-45190`
CWEs: `CWE-22`, `CWE-35`
CVSS: **6.5** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`

Mage AI allows remote users with the "Viewer" role to leak arbitrary files from the Mage server due to a path traversal in the "File Content" request

**Affected:** pip/mage-ai  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
