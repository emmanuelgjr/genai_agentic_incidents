### INC-11963  [↗](/incident/INC-11963.html)

**Path Traversal in FileGator**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2022-1850`
CWEs: `CWE-22`
CVSS: **5.4** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:L/A:N`

Path Traversal in FileGator prior to 7.8.0 for non-admin users. Files created with `..\` as part of their name will be interpreted as a path. Users are thus able to add filesystem entries outside the scope of their user to their dashboard and subsequently are able to modify those files.

**Affected:** composer/filegator/filegator  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
