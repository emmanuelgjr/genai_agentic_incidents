### INC-10774  [↗](/incident/INC-10774.html)

**CRLF injection in Refit's [Header], [HeaderCollection] and [Authorize] attributes**  
_2024-11 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2024-51501`
CWEs: `CWE-93`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

### Summary The various header-related Refit attributes (Header, HeaderCollection and Authorize) are vulnerable to CRLF injection. ### Details The way HTTP headers are added to a request is via the `HttpHeaders.TryAddWithoutValidation` method: <https://github.com/reactiveui/refit/blob/258a771f44417c6e48e103ac921fe4786f3c2a1e/Refit/RequestBuilderImplementation.cs#L1328> This method does not check for CRLF characters in the header value. This means that any headers added to a refit request are vulnerable to CRLF-injection.
