### INC-12473  [↗](/incident/INC-12473.html)

**XML External Entity Reference vulnerability in Jenkins Pipeline: Phoenix AutoTest Plugin**  
_2022-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2022-28140`, `CVE-2022-28141`, `CVE-2022-28154`, `CVE-2022-28155`, `CVE-2022-28156`
CWEs: `CWE-22`, `CWE-522`, `CWE-611`
CVSS: **7.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:L/A:N`

Jenkins Pipeline: Phoenix AutoTest Plugin 1.3 and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks. This allows attackers able to control the input files for the `readXml` or `writeXml` build step to have Jenkins parse a crafted file that uses external entities for extraction of secrets from the Jenkins controller or server-side request forgery.

**Affected:** maven/com.surenpi.jenkins:phoenix-autotest  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
