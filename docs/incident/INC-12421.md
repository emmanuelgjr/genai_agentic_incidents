### INC-12421  [↗](/incident/INC-12421.html)

**Alkacon OpenCMS XSS via searchfilter or listSearchFilter parameter**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2008-1045`, `CVE-2008-1510`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in system/workplace/admin/accounts/users_list.jsp in Alkacon OpenCMS 7.0.3 allows remote attackers to inject arbitrary web script or HTML via the (1) searchfilter or (2) listSearchFilter parameter.

**Affected:** maven/org.opencms:opencms-core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
