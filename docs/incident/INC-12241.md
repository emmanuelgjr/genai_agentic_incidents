### INC-12241  [↗](/incident/INC-12241.html)

**Static Info Tables (static_info_tables) extension TYPO3 vulnerable to Cross-site Scripting**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2013-5323`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the Static Info Tables (static_info_tables) extension before 2.3.1 for TYPO3 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/sjbr/static-info-tables  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
