### INC-12141  [↗](/incident/INC-12141.html)

**Apache Solr for TYPO3 (solr) extension is vulnerable to Cross-site scripting (XSS)**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2013-6289`
CWEs: `CWE-79`
CVSS: **4.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:L/A:N`

Cross-site scripting (XSS) vulnerability in the Apache Solr for TYPO3 (solr) extension before 2.8.3 for TYPO3 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/apache-solr-for-typo3/solr  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
