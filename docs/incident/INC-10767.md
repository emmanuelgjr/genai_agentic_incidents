### INC-10767  [↗](/incident/INC-10767.html)

**powertac-server XML External Entity vulnerability**  
_2024-11 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-51135`
CWEs: `CWE-79`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

An XML External Entity (XXE) vulnerability in the component DocumentBuilderFactory of powertac-server v1.9.0 allows attackers to access sensitive information or execute arbitrary code via supplying a crafted request containing malicious XML entities.

**Affected:** maven/org.powertac:server-interface  
**Attack vector:** `info-disclosure`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`  
**OWASP Agentic (ASI):** `ASI02`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0024`, `AML.T0053`, `AML.T0057`
