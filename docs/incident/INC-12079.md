### INC-12079  [↗](/incident/INC-12079.html)

**Cleartext Storage of Sensitive Information in Jenkins ElasticBox CI Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2019-10440`, `CVE-2019-10443`, `CVE-2019-10447`, `CVE-2019-10448`, `CVE-2019-10450`
CWEs: `CWE-312`, `CWE-522`
CVSS: **3.3** — `CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:L/I:N/A:N`

Jenkins ElasticBox CI Plugin stores credentials unencrypted in the global config.xml configuration file on the Jenkins master where they can be viewed by users with access to the master file system.

**Affected:** maven/com.elasticbox.jenkins-ci.plugins:elasticbox  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`
