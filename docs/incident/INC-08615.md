### INC-08615  [↗](/incident/INC-08615.html)

**Gotenberg vulnerable to unauthenticated SSRF via default deny-list bypass in downloadFrom and webhook**  
_2026-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2026-42596`
CWEs: `CWE-918`
CVSS: **9.4** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:L`

### Summary The default deny-lists used by Gotenberg's `downloadFrom` feature and `webhook` feature are bypassable. Because the filter is regex-based and case-sensitive, an unauthenticated attacker can supply URLs such as `http://[::ffff:127.0.0.1]:...` and reach loopback or private HTTP services that the default deny-list is intended to block.
