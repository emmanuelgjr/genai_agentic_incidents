### INC-10503  [↗](/incident/INC-10503.html)

**QMarkdown Cross-Site Scripting (XSS) vulnerability**  
_2025-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-43954`
CWEs: `CWE-79`
CVSS: **4.9** — `CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:C/C:L/I:L/A:N`

QMarkdown (aka quasar-ui-qmarkdown) before 2.0.5 allows XSS via headers even when when no-html is set.

**Affected:** npm/@quasar/quasar-ui-qmarkdown  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
