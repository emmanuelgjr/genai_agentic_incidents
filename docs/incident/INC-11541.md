### INC-11541  [↗](/incident/INC-11541.html)

**Hashicorp Vault vulnerable to Cross-site Scripting**  
_2023-06 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2023-2121`
CWEs: `CWE-79`
CVSS: **4.3** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:L/A:N`

Vault and Vault Enterprise's (Vault) key-value v2 (kv-v2) diff viewer allowed HTML injection into the Vault web UI through key values. This vulnerability, CVE-2023-2121, is fixed in Vault 1.14.0, 1.13.3, 1.12.7, and 1.11.11.

**Affected:** go/github.com/hashicorp/vault, go/github.com/hashicorp/vault, go/github.com/hashicorp/vault  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
