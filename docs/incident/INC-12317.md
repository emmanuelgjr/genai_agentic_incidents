### INC-12317  [↗](/incident/INC-12317.html)

**Subrion CMS Cross-site scripting in search**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2014-9120`
CWEs: `CWE-79`

A cross-site scripting (XSS) vulnerability in Subrion CMS before 3.2.3 allows remote attackers to inject arbitrary web script or HTML via the `PATH_INFO` to `subrion/search/`.

**Affected:** composer/intelliants/subrion  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
