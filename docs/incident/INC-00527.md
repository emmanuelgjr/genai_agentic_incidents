### INC-00527  [↗](/incident/INC-00527.html)

**AI-Obfuscated DeepLoad Malware Steals Credentials via ClickFix**  
_2026-03-30 · real-world · Severity: High_

Researchers at ReliaQuest identified a malware campaign using DeepLoad, which employs AI-generated obfuscation to evade detection and persist in enterprise networks. Delivered through the ClickFix social engineering technique, the malware rapidly steals credentials and maintains access, causing significant harm to enterprise security and user privacy.
