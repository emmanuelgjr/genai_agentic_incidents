**apconw Aix-DB — Sql Injection (CVE-2026-4530)**  
_2026-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-3686`, `CVE-2023-7215`, `CVE-2024-2057`, `CVE-2024-3078`, `CVE-2025-10619`, `CVE-2025-11445`, `CVE-2025-11489`, `CVE-2025-12345`, `CVE-2025-15453`, `CVE-2025-1953`, `CVE-2025-2148`, `CVE-2025-2149`, `CVE-2025-2733`, `CVE-2025-2953`, `CVE-2025-2998`, `CVE-2025-2999`, `CVE-2025-3000`, `CVE-2025-3001`, `CVE-2025-3121`, `CVE-2025-3136`, `CVE-2025-3730`, `CVE-2025-4287`, `CVE-2025-5320`, `CVE-2025-6092`, `CVE-2025-6107`, `CVE-2025-63396`, `CVE-2025-6853`, `CVE-2025-6854`, `CVE-2025-6855`, `CVE-2025-8665`, `CVE-2026-4530`, `CVE-2026-4538`
CVSS: **5.3**

A security flaw has been discovered in apconw Aix-DB up to 1.2.3. This impacts an unknown function of the file agent/text2sql/rag/terminology_retriever.py. Performing a manipulation of the argument Description results in sql injection. The attack requires a local approach. The exploit has been released to the public and may be used for attacks. The vendor was contacted early about this disclosure but did not respond in any way.

**Attack vector:** `sql-injection`
