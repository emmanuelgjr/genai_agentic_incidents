### INC-12213  [↗](/incident/INC-12213.html)

**XML External Entity Reference in Apache Sling**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2016-6798`
CWEs: `CWE-611`
CVSS: **9.8** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

In the XSS Protection API module before 1.0.12 in Apache Sling, the method XSS.getValidXML() uses an insecure SAX parser to validate the input string, which allows for XXE attacks in all scripts which use this method to validate user input, potentially allowing an attacker to read sensitive data on the filesystem, perform same-site-request-forgery (SSRF), port-scanning behind the firewall or DoS the application.

**Affected:** maven/org.apache.sling:org.apache.sling.xss.compat, maven/org.apache.sling:org.apache.sling.xss  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
