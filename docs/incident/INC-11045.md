### INC-11045  [↗](/incident/INC-11045.html)

**Multiple Cross-Site Scripting vulnerabilities in TYPO3 backend**  
_2024-06 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2015-8755`
CWEs: `CWE-79`

Failing to properly encode user input, several backend components are susceptible to Cross-Site Scripting, allowing authenticated editors to inject arbitrary HTML or JavaScript.

**Affected:** composer/typo3/cms, composer/typo3/cms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
