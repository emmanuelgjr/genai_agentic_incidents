### INC-12029  [↗](/incident/INC-12029.html)

**XXE vulnerability in Jenkins Klocwork Analysis Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-2245`, `CVE-2020-2246`, `CVE-2020-2247`
CWEs: `CWE-611`, `CWE-79`
CVSS: **7.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:L/A:N`

Klocwork Analysis Plugin 2020.2.1 and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks. This allows a user able to control the input files for the Klocwork plugin parser to have Jenkins parse a crafted file that uses external entities for extraction of secrets from the Jenkins controller or server-side request forgery.

**Affected:** maven/org.jenkins-ci.plugins:klocwork  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
