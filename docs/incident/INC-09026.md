**SciTokens is vulnerable to SQL Injection in KeyCache**  
_2026-03 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2026-32714`
CWEs: `CWE-89`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

### Summary The `KeyCache` class in `scitokens` was vulnerable to SQL Injection because it used Python's `str.format()` to construct SQL queries with user-supplied data (such as `issuer` and `key_id`). This allowed an attacker to execute arbitrary SQL commands against the local SQLite database.
