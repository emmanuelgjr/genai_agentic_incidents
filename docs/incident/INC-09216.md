**StudioCMS: IDOR in User Notification Preferences Allows Any Authenticated User to Modify Any User's Settings**  
_2026-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-32104`
CWEs: `CWE-639`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:L/A:L`

## Summary The `updateUserNotifications` endpoint accepts a user ID from the request payload and uses it to update that user's notification preferences. It checks that the caller is logged in but never verifies that the caller owns the target account (`id !== userData.user.id`).
