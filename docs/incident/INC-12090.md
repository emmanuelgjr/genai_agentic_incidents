### INC-12090  [↗](/incident/INC-12090.html)

**Magento Stored cross-site scripting in admin panel**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2019-7863`
CWEs: `CWE-79`
CVSS: **4.8** — `CVSS:3.0/AV:N/AC:L/PR:H/UI:R/S:C/C:L/I:L/A:N`

A stored cross-site scripting vulnerability exists in the admin panel for Magento 2.1 prior to 2.1.18, Magento 2.2 prior to 2.2.9, Magento 2.3 prior to 2.3.2. This can be exploited by an authenticated user with access to products and categories.

**Affected:** composer/magento/community-edition, composer/magento/community-edition, composer/magento/community-edition  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
