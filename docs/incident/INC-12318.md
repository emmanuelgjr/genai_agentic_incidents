### INC-12318  [↗](/incident/INC-12318.html)

**Subrion CMS Cross-site Scripting**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2018-14840`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

`uploads/.htaccess` in Subrion CMS 4.2.1 allows XSS because it does not block .html file uploads (but does block, for example, .htm file uploads).

**Affected:** composer/intelliants/subrion  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
