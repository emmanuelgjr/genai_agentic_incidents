**AI-Driven Cyberattacks Exploit Zero-Day Vulnerabilities, Escalating Security Risks**  
_2026-05-12 · real-world · Severity: Critical_

Hackers are increasingly using advanced AI models to discover and weaponize zero-day software vulnerabilities, enabling faster and more effective cyberattacks. Google and security experts confirm AI-assisted attacks have already bypassed security measures, targeting critical infrastructure and open-source tools, prompting urgent defensive measures in Taiwan and globally.

**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM02`, `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI01`, `ASI02`, `ASI03`, `ASI04`, `ASI05`, `ASI10`
