### INC-11966  [↗](/incident/INC-11966.html)

**Cross site scripting in publify**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2021-25975`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

In publify, versions v8.0 to v9.2.4 are vulnerable to stored XSS as a result of an unrestricted file upload. This issue allows a user with “publisher” role to inject malicious JavaScript via the uploaded html file.

**Affected:** rubygems/publify_core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
