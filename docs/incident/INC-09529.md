### INC-09529  [↗](/incident/INC-09529.html)

**XDocReport affected by an XML External Entity (XXE) vulnerability**  
_2026-01 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2025-65482`
CWEs: `CWE-611`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

An XML External Entity (XXE) vulnerability in opensagres XDocReport v0.9.2 to v2.0.3 allows attackers to execute arbitrary code via uploading a crafted .docx file.

**Affected:** maven/fr.opensagres.xdocreport:fr.opensagres.xdocreport.document  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
