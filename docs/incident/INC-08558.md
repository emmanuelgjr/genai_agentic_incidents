### INC-08558  [↗](/incident/INC-08558.html)

**Duplicate Advisory: OpenClaw: Isolated cron awareness events were recorded as trusted system events**  
_2026-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-44999`
CWEs: `CWE-345`
CVSS: **5.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N`

### Duplicate Advisory This advisory has been withdrawn because it is a duplicate of GHSA-57r2-h2wj-g887. This link is maintained to preserve external references. ### Original Description OpenClaw before 2026.4.20 fails to properly preserve untrusted labels for isolated cron awareness events, allowing webhook-triggered cron agent output to be recorded as trusted system events. Attackers can exploit this trust-labeling issue to strengthen prompt-injection attacks by rendering untrusted events as trusted System events.

**Affected:** npm/openclaw  
**Attack vector:** `prompt-injection`
