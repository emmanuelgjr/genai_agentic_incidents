### INC-12391  [↗](/incident/INC-12391.html)

**Improper Restriction of XML External Entity Reference in Castor**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2014-3004`
CWEs: `CWE-611`

The default configuration for the Xerces SAX Parser in Castor before 1.3.3 allows context-dependent attackers to conduct XML External Entity (XXE) attacks via a crafted XML document.

**Affected:** maven/castor:castor, maven/org.codehaus.castor:castor  
**Attack vector:** `other`
