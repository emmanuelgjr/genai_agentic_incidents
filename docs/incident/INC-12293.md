### INC-12293  [↗](/incident/INC-12293.html)

**Drupal PECL YAML parser unsafe object handling**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2017-6920`, `CVE-2017-6921`
CWEs: `CWE-20`, `CWE-94`
CVSS: **9.8** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

Drupal core 8 before versions 8.3.4 allows remote attackers to execute arbitrary code due to the PECL YAML parser not handling PHP objects safely during certain operations.

**Affected:** composer/drupal/drupal, composer/drupal/core  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
