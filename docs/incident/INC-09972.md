### INC-09972  [↗](/incident/INC-09972.html)

**Kimai contains a SameSite cookie vulnerability**  
_2025-12 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-53957`
CWEs: `CWE-1275`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

Kimai 1.30.10 contains a SameSite cookie vulnerability that allows attackers to steal user session cookies through malicious exploitation. Attackers can trick victims into executing a crafted PHP script that captures and writes session cookie information to a file, enabling potential session hijacking.

**Affected:** composer/kimai/kimai  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
