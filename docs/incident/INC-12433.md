### INC-12433  [↗](/incident/INC-12433.html)

**Alkacon OpenCms XSS via unsanitized message body**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2006-3933`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in Alkacon OpenCms before 6.2.2 allows remote authenticated users to inject arbitrary web script or HTML via the message body.

**Affected:** maven/org.opencms:opencms-core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
