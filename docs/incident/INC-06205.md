### INC-06205  [↗](/incident/INC-06205.html)

**A RCE vulnerability exists in Raysync below 3.3.3.8.**  
_2020-12 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-35370`
CWEs: `CWE-22`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

A RCE vulnerability exists in Raysync below 3.3.3.8. An unauthenticated unauthorized attacker sending a specifically crafted request to override the specific file in server with malicious content can login as "admin", then to modify specific shell file to achieve remote code execution(RCE) on the hosting server.

**Affected:** raysync/raysync  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`

- [NVD](https://nvd.nist.gov/vuln/detail/CVE-2020-35370) _(advisory)_
- [cve@mitre.org](https://www.exploit-db.com/exploits/49265) _(exploit)_
