### INC-05012  [↗](/incident/INC-05012.html)

**A stack-based buffer overflow vulnerability exists in both the LLMNR functionality of Sealevel Systems, Inc.**  
_2022-02 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2021-21960`
CWEs: `CWE-121`, `CWE-1284`
CVSS: **10.0** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H`

A stack-based buffer overflow vulnerability exists in both the LLMNR functionality of Sealevel Systems, Inc. SeaConnect 370W v1.3.34. A specially-crafted network packet can lead to remote code execution. An attacker can send a malicious packet to trigger this vulnerability.

**Affected:** sealevel/seaconnect_370w_firmware, sealevel/seaconnect_370w  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
