### INC-01110  [↗](/incident/INC-01110.html)

**Google Cloud Vertex AI Agents Exploited Due to Excessive Default Permissions**  
_2026-03-31 · real-world · Severity: High_

Security researchers discovered that Google Cloud's Vertex AI Agent Engine had excessive default permissions, allowing attackers to hijack AI agents as "double agents." This enabled unauthorized access to sensitive customer data and proprietary Google code, exposing critical infrastructure and intellectual property. Google has since updated its documentation and issued mitigation guidance.

**Attack vector:** `other`
