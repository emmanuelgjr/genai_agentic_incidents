### INC-04927  [↗](/incident/INC-04927.html)

**TensorFlow — Vulnerability (CVE-2023-25671)**  
_2023-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-25671`
CVSS: **7.5**

TensorFlow is an open source platform for machine learning. There is out-of-bounds access due to mismatched integer type sizes. A fix is included in TensorFlow version 2.12.0 and version 2.11.1.

**Affected:** google/tensorflow  
**Attack vector:** `other`
