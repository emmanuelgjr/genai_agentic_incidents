### INC-11781  [↗](/incident/INC-11781.html)

**Liferay Portal Insecure Default Configuration in auth.login.prompt.enabled**  
_2022-10 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2022-41414`
CWEs: `CWE-276`
CVSS: **5.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N`

An insecure default in the component auth.login.prompt.enabled of Liferay Portal v7.0.0 through v7.4.2 allows attackers to enumerate usernames, site names, and pages.

**Affected:** maven/com.liferay.portal:com.liferay.portal.impl, maven/com.liferay.portal:release.portal.bom  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
