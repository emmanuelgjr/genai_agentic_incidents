### INC-10604  [↗](/incident/INC-10604.html)

**Spacy-LLM Server-Side Template Injection (SSTI) vulnerability**  
_2025-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-25362`
CWEs: `CWE-1336`, `CWE-94`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

A Server-Side Template Injection (SSTI) vulnerability in Spacy-LLM v0.7.2 allows attackers to execute arbitrary code via injecting a crafted payload into the template field.

**Affected:** pip/spacy-llm  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
