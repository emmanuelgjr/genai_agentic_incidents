### INC-11466  [↗](/incident/INC-11466.html)

**Cockpit Cross-site Scripting vulnerability**  
_2023-08 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-4196`
CWEs: `CWE-79`
CVSS: **8.3** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:L`

Cross-site Scripting (XSS) - Stored in GitHub repository cockpit-hq/cockpit prior to 2.6.3. For any role that has permission to execute function assets, an attacker can upload a html file and that leads to XSS.

**Affected:** composer/cockpit-hq/cockpit  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
