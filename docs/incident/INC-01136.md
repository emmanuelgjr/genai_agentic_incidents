### INC-01136  [↗](/incident/INC-01136.html)

**GrafanaGhost AI Vulnerability Enables Silent Data Exfiltration**  
_2026-04-07 · real-world · Severity: High_

Security researchers discovered a critical vulnerability, 'GrafanaGhost,' in Grafana's AI components that allowed attackers to bypass AI guardrails via indirect prompt injection. This flaw enabled silent exfiltration of sensitive enterprise data—including financial and customer information—without user interaction or credentials. Grafana has since patched the vulnerability.

**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM02`, `LLM05`  
**OWASP Agentic (ASI):** `ASI01`, `ASI02`, `ASI03`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `MAP-3.5`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0050`, `AML.T0051`, `AML.T0053`, `AML.T0057`
