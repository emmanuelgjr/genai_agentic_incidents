### INC-12245  [↗](/incident/INC-12245.html)

**Fastly Magento2 sensitive information disclosure**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2017-13761`
CWEs: `CWE-200`
CVSS: **6.5** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`

The Fastly CDN module before 1.2.26 for Magento2, when used with a third-party authentication plugin, might allow remote authenticated users to obtain sensitive information from authenticated sessions via vectors involving caching of redirect responses.

**Affected:** composer/fastly/magento2  
**Attack vector:** `info-disclosure`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`  
**OWASP Agentic (ASI):** `ASI02`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0024`, `AML.T0053`, `AML.T0057`
