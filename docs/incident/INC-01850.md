### INC-01850  [↗](/incident/INC-01850.html)

**Tencent&#x27;s WeChat-Integrated Yuanbao Chatbot Reportedly Insulted User During Coding Debug Request**  
_2026-01-02 · real-world · Severity: Medium_
AIID: [`#1382`](https://incidentdatabase.ai/cite/1382/)

Screenshots reportedly circulated on RedNote showed Tencent&#x27;s WeChat-integrated AI assistant Yuanbao insulting a user seeking help debugging code, allegedly calling the request &quot;stupid&quot; and telling the user to &quot;get lost.&quot; Tencent reportedly apologized, attributed the exchange to a rare model output anomaly, and said system logs showed no human intervention while it investigated and optimized the model.
