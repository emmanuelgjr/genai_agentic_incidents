### INC-02609  [↗](/incident/INC-02609.html)

**GitHub Copilot Chat vulnerability exposes private code and secrets**  
_2025-10-08 · vulnerability-disclosure · Severity: Critical_

A critical vulnerability in GitHub Copilot Chat allowed attackers to exfiltrate private repository source code and secrets via prompt injection in repository content combined with abuse of Copilot's image-proxying behavior, leaking data through attacker-controlled image URLs.

**Affected:** GitHub Copilot Chat users  
**Attack vector:** `indirect-prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM02`  
**OWASP Agentic (ASI):** `ASI01`, `ASI03`  
**NIST AI RMF:** `GOVERN-1.4`, `MANAGE-2.4`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0024`, `AML.T0051`, `AML.T0057`  

**References:**
- [OECD AIM - GitHub Copilot Chat Vulnerability Exposes Private Code and Secrets](https://oecd.ai/en/incidents/2025-10-08-0fbf) _(advisory)_
