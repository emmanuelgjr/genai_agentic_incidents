**Magento Improper Access Control leads to Security feature bypass**  
_2025-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-27188`, `CVE-2025-27190`, `CVE-2025-27191`, `CVE-2025-27192`

CVSS: **5.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:L/A:N`

Magento versions 2.4.7-p4, 2.4.6-p9, 2.4.5-p11, 2.4.4-p12, 2.4.8-beta2 and earlier are affected by an Improper Access Control vulnerability that could result in a Security feature bypass.
