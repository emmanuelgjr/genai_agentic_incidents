### INC-12190  [↗](/incident/INC-12190.html)

**concrete5 vulnerable to Cross-site Scripting**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2015-3989`
CWEs: `CWE-79`

Multiple cross-site scripting (XSS) vulnerabilities in concrete5 before 5.7.4 allow remote attackers to inject arbitrary web script or HTML via vectors related to private messages or other unspecified vectors.

**Affected:** composer/concrete5/concrete5  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
