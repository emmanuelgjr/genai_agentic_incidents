### INC-12253  [↗](/incident/INC-12253.html)

**TeamPass Cross-Site Scripting (XSS)**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2017-15278`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

Cross-Site Scripting (XSS) was discovered in TeamPass before 2.1.27.9. The vulnerability exists due to insufficient filtration of data (in /sources/folders.queries.php). An attacker could execute arbitrary HTML and script code in a browser in the context of the vulnerable website.

**Affected:** composer/nilsteampassnet/teampass  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
