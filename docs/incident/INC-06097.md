### INC-06097  [↗](/incident/INC-06097.html)

**Tesla Ordered to Pay Damages After AI Software Update Reduces Battery Performance**  
_2021-05-24 · real-world · Severity: Medium_

A 2019 software update in Tesla Model S vehicles, using AI-based battery management, reduced battery capacity and driving range, harming owners. Norwegian courts ordered Tesla to pay $16,000 to each affected customer. Similar lawsuits are ongoing in the US. The incident highlights risks from AI-driven software changes in vehicles.
