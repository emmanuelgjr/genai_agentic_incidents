### INC-03412  [↗](/incident/INC-03412.html)

**A flaw was found in the X.Org server.**  
_2024-01 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-0409`
CVSS: **7.8**

A flaw was found in the X.Org server. The cursor code in both Xephyr and Xwayland uses the wrong type of private at creation. It uses the cursor bits type with the cursor as private, and when initiating the cursor, that overwrites the XSELINUX context.

**Affected:** tigervnc/tigervnc, x.org/x_server, x.org/xwayland, fedoraproject/fedora  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
