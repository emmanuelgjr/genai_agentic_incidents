### INC-12057  [↗](/incident/INC-12057.html)

**Passwords stored in plain text by Harvest SCM Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-2115`, `CVE-2020-2120`, `CVE-2020-2121`, `CVE-2020-2123`, `CVE-2020-2124`, `CVE-2020-2126`, `CVE-2020-2128`, `CVE-2020-2130`, `CVE-2020-2131`, `CVE-2020-2132`, `CVE-2020-2133`
CWEs: `CWE-256`, `CWE-502`, `CWE-522`, `CWE-611`
CVSS: **4.3** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:N/A:N`

Harvest SCM Plugin 0.5.1 and earlier stores SCM passwords unencrypted in its global configuration file `hudson.plugins.harvest.HarvestSCM.xml and in job config.xml` files on the Jenkins controller. These credentials can be viewed by users with Extended Read permission (job config.xml only) or access to the Jenkins controller file system (both).

**Affected:** maven/org.jenkins-ci.plugins:harvest  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`
