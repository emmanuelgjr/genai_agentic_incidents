### INC-01606  [↗](/incident/INC-01606.html)

**OpenCode — Vulnerability (CVE-2026-22812)**  
_2026-01 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-22812`
CWEs: `CWE-306`, `CWE-749`, `CWE-942`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

OpenCode is an open source AI coding agent. Prior to 1.0.216, OpenCode automatically starts an unauthenticated HTTP server that allows any local process (or any website via permissive CORS) to execute arbitrary shell commands with the user's privileges. This vulnerability is fixed in 1.0.216.

**Affected:** anoma/opencode  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
