### INC-09022  [↗](/incident/INC-09022.html)

**Admidio has CSRF and Form Validation Bypass in Inventory Item Save via `imported` Parameter**  
_2026-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-34383`
CWEs: `CWE-20`, `CWE-352`
CVSS: **4.3** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:L/A:N`

## Summary The inventory module's `item_save` endpoint accepts a user-controllable POST parameter `imported` that, when set to `true`, completely bypasses both CSRF token validation and server-side form validation.
