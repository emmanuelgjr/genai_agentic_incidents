**Cross-site scripting (XSS) vulnerability in the View URL Database functionality in Sun Java System Web Proxy Server 4.x before 4.0.6 and 3.x before 3.6 SP11 allows remote attack...**  
_2007-12 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2007-6570`
CWEs: `CWE-79`
CVSS: **4.3**

Cross-site scripting (XSS) vulnerability in the View URL Database functionality in Sun Java System Web Proxy Server 4.x before 4.0.6 and 3.x before 3.6 SP11 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors, aka BugID 6566309.

**Affected:** sun/java_system_web_proxy_server, sun/java_system_web_server  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`
