### INC-08906  [↗](/incident/INC-08906.html)

**Beszel has an IDOR in hub API endpoints that read system ID from URL parameter**  
_2026-04 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2026-40077`
CWEs: `CWE-184`
CVSS: **3.5** — `CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:C/C:L/I:N/A:N`

## Summary Some API endpoints in the Beszel hub accept a user-supplied system ID and proceed without further checks that the user should have access to that system. As a result, any authenticated user can access these routes for any system if they know the system's ID. System IDs are random 15 character alphanumeric strings, and are not exposed to all users. However, it is theoretically possible for an authenticated user to enumerate a valid system ID via web API.
