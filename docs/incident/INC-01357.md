### INC-01357  [↗](/incident/INC-01357.html)

**Lovable AI App Builder Exposes Sensitive User Data via API Flaw**  
_2026-04-20 · real-world · Severity: High_

A critical API vulnerability in Lovable, a Stockholm-based AI app-building platform, allowed unauthorized access to sensitive data—including AI chat histories, source code, and customer records—from thousands of projects. Despite Lovable denying a data breach, unclear documentation and broken authorization led to significant privacy and security risks for users.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0050`, `AML.T0057`
