### INC-03209  [↗](/incident/INC-03209.html)

**SesameOp: Novel backdoor uses OpenAI Assistants API for command and control**  
_2025-07-01 · real-world · Severity: Critical_

The Microsoft Incident Response - Detection and Response Team (DART) investigated a compromised system where a threat actor utilized SesameOp, a backdoor implant that abuses the OpenAI Assistants API as a covert command and control channel, for espionage activities. The SesameOp malware used the OpenAI API to fetch and execute the threat actor’s commands and to exfiltrate encrypted results from the victim system. The threat actor had maintained a presence on the compromised system for several months. They had control of multiple internal web shells which executed commands from malicious processes that relied on compromised Visual Studio utilities. Investigation of other Visual Studio utilities led to the discovery of the novel SesameOp backdoor.

**Affected:** OpenAI Assistants API  
**Attack vector:** `adversarial-input`  

**OWASP LLM Top 10:** `LLM06`, `LLM10`
