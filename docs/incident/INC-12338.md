### INC-12338  [↗](/incident/INC-12338.html)

**jQuery vulnerable to Cross-Site Scripting (XSS)**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2010-4408`, `CVE-2011-4969`, `CVE-2016-5005`, `CVE-2017-5657`
CWEs: `CWE-352`, `CWE-79`, `CWE-862`

Cross-site scripting (XSS) vulnerability in jQuery before 1.6.3, when using location.hash to select elements, allows remote attackers to inject arbitrary web script or HTML via a crafted tag.

**Affected:** maven/org.webjars.npm:jquery, rubygems/jquery-rails, nuget/jQuery  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
