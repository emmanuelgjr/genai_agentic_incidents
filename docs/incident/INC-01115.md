### INC-01115  [↗](/incident/INC-01115.html)

**Google Gemini AI API Key Exposure Leads to Data and Financial Breaches in Android Apps**  
_2026-04-07 · real-world · Severity: High_

A security flaw in Google's Gemini AI API allowed hardcoded API keys in 22 popular Android apps (over 500 million installs) to grant unauthorized access to AI services and user data. This led to privacy breaches and financial losses for developers, as attackers exploited the exposed credentials.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0050`, `AML.T0057`
