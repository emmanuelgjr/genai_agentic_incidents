### INC-02306  [↗](/incident/INC-02306.html)

**An Improper Input Validation vulnerability in the scanning logic of mmaitre314 picklescan versions up to and including 0.0.30 allows a remote attacker to bypass pickle files sec...**  
_2025-09 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2025-10155`, `CVE-2025-10156`, `CVE-2025-10157`
CWEs: `CWE-20`, `CWE-502`, `CWE-693`, `CWE-755`
CVSS: **7.8** — `CVSS:3.1/AV:L/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

An Improper Input Validation vulnerability in the scanning logic of mmaitre314 picklescan versions up to and including 0.0.30 allows a remote attacker to bypass pickle files security checks by supplying a standard pickle file with a PyTorch-related file extension. When the pickle file incorrectly considered safe is loaded, it can lead to the execution of malicious code.

**Affected:** mmaitre314/picklescan  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0010.001`, `AML.T0050`
