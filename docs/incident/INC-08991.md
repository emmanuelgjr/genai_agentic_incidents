**PraisonAI Has SSRF in FileTools.download_file() via Unvalidated URL**  
_2026-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-34954`
CWEs: `CWE-918`

### Summary `FileTools.download_file()` in `praisonaiagents` validates the destination path but performs no validation on the `url` parameter, passing it directly to `httpx.stream()` with `follow_redirects=True`.
