### INC-12165  [↗](/incident/INC-12165.html)

**The Preview plugin in CKEditor allows Cross-site scripting (XSS)**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2014-5191`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the Preview plugin before 4.4.3 in CKEditor allows remote attackers to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/ckeditor/ckeditor  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
