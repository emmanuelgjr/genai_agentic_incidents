**Polish Students Develop AI-Powered Drone Detection Sensor Network**  
_2026-03-29 · real-world · Severity: Medium_

Students from Rzeszów University of Technology are developing a low-cost, mesh-based sensor network using machine learning to detect drones, primarily for military and critical infrastructure protection. The system, which recently won an international hackathon, is in the testing phase and poses plausible future risks if misused or malfunctioning.
