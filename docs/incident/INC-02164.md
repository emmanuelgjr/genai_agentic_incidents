### INC-02164  [↗](/incident/INC-02164.html)

**A use-after-free flaw was found in X.Org and Xwayland.**  
_2025-02 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-26594`
CWEs: `CWE-416`
CVSS: **7.8** — `CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

A use-after-free flaw was found in X.Org and Xwayland. The root cursor is referenced in the X server as a global variable. If a client frees the root cursor, the internal reference points to freed memory and causes a use-after-free.

**Affected:** tigervnc/tigervnc, x.org/x_server, x.org/xwayland, redhat/enterprise_linux  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`
