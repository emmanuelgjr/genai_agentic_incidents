### INC-09983  [↗](/incident/INC-09983.html)

**MJML allows mj-include directory traversal due to an incomplete fix for CVE-2020-12827**  
_2025-12 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-12827`, `CVE-2025-67898`
CWEs: `CWE-22`, `CWE-36`
CVSS: **4.5** — `CVSS:3.1/AV:L/AC:H/PR:N/UI:N/S:C/C:L/I:N/A:L`

MJML through 4.18.0 allows mj-include directory traversal to test file existence and (in the type="css" case) read files. NOTE: this issue exists because of an incomplete fix for CVE-2020-12827.

**Affected:** npm/mjml  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
