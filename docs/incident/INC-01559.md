### INC-01559  [↗](/incident/INC-01559.html)

**Open Neural Network Exchange (ONNX) is an open standard for machine learning interoperability.**  
_2026-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-27489`, `CVE-2026-28500`, `CVE-2026-34445`, `CVE-2026-34446`, `CVE-2026-34447`
CVSS: **7.5**

Open Neural Network Exchange (ONNX) is an open standard for machine learning interoperability. Prior to version 1.21.0, a path traversal vulnerability via symlink allows to read arbitrary files outside model or user-provided directory. This issue has been patched in version 1.21.0.

**Affected:** linuxfoundation/onnx  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0050`
