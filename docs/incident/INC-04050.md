### INC-04050  [↗](/incident/INC-04050.html)

**NVIDIA Triton Inference Server contains a vulnerability where a user may cause an out-of-bounds read issue by releasing a shared memory region while it is in use.**  
_2024-10 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-0116`
CWEs: `CWE-125`
CVSS: **4.9** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:U/C:N/I:N/A:H`

NVIDIA Triton Inference Server contains a vulnerability where a user may cause an out-of-bounds read issue by releasing a shared memory region while it is in use. A successful exploit of this vulnerability may lead to denial of service.

**Affected:** nvidia/triton_inference_server, linux/linux_kernel  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`

**MITRE ATLAS:** `AML.T0010`
