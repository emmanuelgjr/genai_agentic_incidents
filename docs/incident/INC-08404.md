**Pimcore Vulnerable to SQL Injection in Custom Reports Column Configuration**  
_2026-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-44739`
CWEs: `CWE-89`
CVSS: **8.7** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:H/I:H/A:N`

### Summary The columnConfigAction endpoint in the CustomReportsBundle is vulnerable to SQL injection. An attacker with the reports_config permission can supply a malicious SQL configuration that is concatenated into a query and executed. Although the application attempts to filter certain DDL/DML keywords (like UPDATE, DELETE, DROP), it fails to prevent arbitrary SELECT queries, UNION statements, or the use of dangerous database functions.
