### INC-12120  [↗](/incident/INC-12120.html)

**phpMyAdmin Cross-site Scripting vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2010-2958`, `CVE-2011-1940`, `CVE-2011-2505`, `CVE-2011-2506`, `CVE-2011-4634`, `CVE-2011-4782`
CWEs: `CWE-79`, `CWE-94`

Cross-site scripting (XSS) vulnerability in libraries/Error.class.php in phpMyAdmin 3.x before 3.3.6 allows remote attackers to inject arbitrary web script or HTML via vectors related to a PHP backtrace and error messages (aka debugging messages), a different vulnerability than CVE-2010-3056.

**Affected:** composer/phpmyadmin/phpmyadmin  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
