**AVideo: Missing Authorization in Playlist Schedule Creation Allows Cross-User Broadcast Hijacking**  
_2026-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-34245`
CWEs: `CWE-862`

## Summary The `plugin/PlayLists/View/Playlists_schedules/add.json.php` endpoint allows any authenticated user with streaming permission to create or modify broadcast schedules targeting any playlist on the platform, regardless of ownership.
