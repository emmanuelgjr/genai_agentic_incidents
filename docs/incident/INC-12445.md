### INC-12445  [↗](/incident/INC-12445.html)

**Tomcat uses trusted privileges when processing web.xml file**  
_2022-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2003-0043`
CWEs: `CWE-250`

Jakarta Tomcat before 3.3.1a, when used with JDK 1.3.1 or earlier, uses trusted privileges when processing the web.xml file, which could allow remote attackers to read portions of some files through the web.xml file.

**Affected:** maven/org.apache.tomcat:tomcat  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
