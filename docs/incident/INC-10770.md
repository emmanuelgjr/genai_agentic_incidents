### INC-10770  [↗](/incident/INC-10770.html)

**HAPI FHIR XML External Entity (XXE) vulnerability**  
_2024-11 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-51132`
CWEs: `CWE-601`, `CWE-611`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

An XML External Entity (XXE) vulnerability in HAPI FHIR before v6.4.0 allows attackers to access sensitive information or execute arbitrary code via supplying a crafted request containing malicious XML entities.

**Affected:** maven/ca.uhn.hapi.fhir:org.hl7.fhir.validation, maven/ca.uhn.hapi.fhir:org.hl7.fhir.utilities, maven/ca.uhn.hapi.fhir:org.hl7.fhir.r5  
**Attack vector:** `info-disclosure`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`  
**OWASP Agentic (ASI):** `ASI02`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0024`, `AML.T0053`, `AML.T0057`
