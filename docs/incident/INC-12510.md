### INC-12510  [↗](/incident/INC-12510.html)

**Improper Privilege Management and Execution with Unnecessary Privileges in Kata Containers**  
_2022-02 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2020-2023`
CWEs: `CWE-250`, `CWE-269`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

Kata Containers doesn't restrict containers from accessing the guest's root filesystem device. Malicious containers can exploit this to gain code execution on the guest and masquerade as the kata-agent. This issue affects Kata Containers 1.11 versions earlier than 1.11.1; Kata Containers 1.10 versions earlier than 1.10.5; and Kata Containers 1.9 and earlier versions.

**Affected:** go/github.com/kata-containers/runtime, go/github.com/kata-containers/runtime, go/github.com/kata-containers/runtime  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
