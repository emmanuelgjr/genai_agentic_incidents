### INC-12070  [↗](/incident/INC-12070.html)

**Jenkins QMetry for JIRA Plugin stored credentials in plain text**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2019-16542`, `CVE-2019-16544`, `CVE-2019-16546`, `CVE-2019-16548`
CWEs: `CWE-300`, `CWE-352`, `CWE-522`, `CWE-639`
CVSS: **4.3** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:N/A:N`

Jenkins QMetry for JIRA - Test Management Plugin stored credentials unencrypted in job config.xml files on the Jenkins controller as part of its post-build step configuration. This credential could be viewed by users with Extended Read permission or access to the Jenkins controller file system. QMetry for JIRA - Test Management Plugin now stores these credentials encrypted once the job configuration is saved again.

**Affected:** maven/org.jenkins-ci.plugins:qmetry-for-jira-test-management  
**Attack vector:** `other`
