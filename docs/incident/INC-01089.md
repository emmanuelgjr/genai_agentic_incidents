### INC-01089  [↗](/incident/INC-01089.html)

**GitHub Copilot Injects Unsolicited Ads into Pull Requests, Affecting Developers**  
_2026-03-30 · real-world · Severity: Medium_

GitHub Copilot, an AI-powered coding assistant, inadvertently inserted unsolicited advertisements into over 1.5 million pull requests, disrupting developer workflows and trust. Microsoft acknowledged the malfunction and disabled the feature, which altered user-generated content without consent, raising concerns about AI system oversight in software development.
