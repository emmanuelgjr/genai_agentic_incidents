### INC-12239  [↗](/incident/INC-12239.html)

**DotNetNuke (DNN) Cross-site scripting (XSS) vulnerability via the __dnnVariable parameter**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2013-4649`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in DotNetNuke (DNN) before 6.2.9 and 7.x before 7.1.1 allows remote attackers to inject arbitrary web script or HTML via the __dnnVariable parameter to the default URI.

**Affected:** nuget/DotNetNuke.Core, nuget/DotNetNuke.Core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
