### INC-02769  [↗](/incident/INC-02769.html)

**Invisible 'Rules File Backdoor' threatens AI code assistants**  
_2025-03-18 · vulnerability-disclosure · Severity: High_

Pillar Security disclosed the 'Rules File Backdoor' technique, hiding malicious instructions in IDE rules files (Cursor, GitHub Copilot) so that AI coding assistants emit attacker-controlled code while appearing to follow benign guidance, creating a stealthy supply-chain compromise of generated code.

**Affected:** Cursor and GitHub Copilot users  
**Attack vector:** `supply-chain`  

**OWASP LLM Top 10:** `LLM01`, `LLM03`, `LLM04`  
**OWASP Agentic (ASI):** `ASI01`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MANAGE-2.4`, `MAP-4.2`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0020`, `AML.T0051`  

**References:**
- [OECD AIM - Invisible 'Rules File Backdoor' Threatens AI Code Assistants](https://oecd.ai/en/incidents/2025-03-18-06ed) _(advisory)_
