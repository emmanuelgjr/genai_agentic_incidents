### INC-12411  [↗](/incident/INC-12411.html)

**TYPO3 Direct Mail Extension Vulnerable to Cross-Site Scripting (XSS)**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2009-4159`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the newsletter configuration feature in the backend module in the Direct Mail (direct_mail) extension 2.6.4 and earlier for TYPO3 allows remote authenticated users to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/directmailteam/direct-mail  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
