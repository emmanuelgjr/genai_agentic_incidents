### INC-11719  [↗](/incident/INC-11719.html)

**json stack overflow vulnerability**  
_2022-12 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2022-45688`
CWEs: `CWE-787`
CVSS: **7.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H`

A stack overflow in the XML.toJSONObject component of hutool-json v5.8.10 and org.json:json before version 20230227 allows attackers to cause a Denial of Service (DoS) via crafted JSON or XML data.

**Affected:** maven/cn.hutool:hutool-json, maven/org.json:json  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
