**Chinese state-sponsored hackers use Anthropic's Claude AI for autonomous cyberattacks (GTG-1002)**  
_2025-11-13 · threat-report · Severity: Critical_

Anthropic disclosed GTG-1002, an alleged China-state-aligned operator that used Claude Code to autonomously plan and execute multi-stage cyber-espionage operations against 30+ targets, including manipulating the model via role-play and tool abuse.

**Affected:** 30+ targets across government, tech, finance  
**Attack vector:** `agent-hijack`  

**OWASP LLM Top 10:** `LLM01`, `LLM06`  
**OWASP Agentic (ASI):** `ASI01`, `ASI02`, `ASI10`  
**NIST AI RMF:** `GOVERN-1.1`, `GOVERN-1.4`, `MANAGE-2.4`, `MAP-3.5`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0048`, `AML.T0051`, `AML.T0053`, `AML.T0054`
