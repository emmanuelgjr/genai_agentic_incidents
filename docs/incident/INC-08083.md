### INC-08083  [↗](/incident/INC-08083.html)

**Critical Vulnerability in Hugging Face Transformers Enables Remote Code Execution**  
_2026-06-04 · real-world · Severity: High_

A critical flaw (CVE-2026-4372) in the Hugging Face Transformers AI library allowed attackers to execute arbitrary code on users' systems by embedding malicious payloads in model configuration files. The vulnerability bypassed key security controls, exposing millions of workflows to data breaches and supply chain risks globally.

**Attack vector:** `data-exfiltration`
