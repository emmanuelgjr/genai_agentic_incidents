### INC-03561  [↗](/incident/INC-03561.html)

**An issue has been discovered in GitLab EE affecting all versions starting from 16.0 prior to 17.2.8, from 17.3 prior to 17.3.4, and from 17.4 prior to 17.4.1.**  
_2024-09 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2024-4099`
CWEs: `CWE-116`
CVSS: **3.1** — `CVSS:3.1/AV:N/AC:H/PR:N/UI:R/S:U/C:N/I:L/A:N`

An issue has been discovered in GitLab EE affecting all versions starting from 16.0 prior to 17.2.8, from 17.3 prior to 17.3.4, and from 17.4 prior to 17.4.1. An AI feature was found to read unsanitized content in a way that could have allowed an attacker to hide prompt injection.

**Affected:** gitlab/gitlab  
**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM05`  
**OWASP Agentic (ASI):** `ASI01`, `ASI05`  
**NIST AI RMF:** `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0050`, `AML.T0051`
