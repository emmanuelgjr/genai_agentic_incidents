### INC-07110  [↗](/incident/INC-07110.html)

**Voatz Voting App Security Flaws Raise Election Integrity Concerns**  
_2020-02-16 · real-world · Severity: Medium_

Researchers from MIT found that the Voatz mobile voting app, which uses AI-based facial recognition, has significant security vulnerabilities that could allow votes to be altered, blocked, or exposed. Despite these risks and expert warnings, the app has been used in several U.S. elections, raising concerns about election integrity.
