### INC-12164  [↗](/incident/INC-12164.html)

**October CMS XSS In Caption Tag of Profile**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2015-5612`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in October CMS build 271 and earlier allows remote attackers to inject arbitrary web script or HTML via the caption tag of a profile image.

**Affected:** composer/october/october  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
