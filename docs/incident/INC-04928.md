### INC-04928  [↗](/incident/INC-04928.html)

**TensorFlow — Vulnerability (CVE-2023-25672)**  
_2023-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-25672`
CVSS: **7.5**

TensorFlow is an open source platform for machine learning. The function `tf.raw_ops.LookupTableImportV2` cannot handle scalars in the `values` parameter and gives an NPE. A fix is included in TensorFlow version 2.12.0 and version 2.11.1.

**Affected:** google/tensorflow  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
