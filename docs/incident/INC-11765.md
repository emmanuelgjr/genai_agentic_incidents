### INC-11765  [↗](/incident/INC-11765.html)

**Untrusted code execution in Apache XML Graphics Batik**  
_2022-10 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2022-42890`
CWEs: `CWE-918`
CVSS: **7.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N`

A vulnerability in Batik of Apache XML Graphics allows an attacker to run Java code from untrusted SVG via JavaScript. This issue affects Apache XML Graphics prior to 1.16. Users are recommended to upgrade to version 1.16.

**Affected:** maven/org.apache.xmlgraphics:batik-bridge, maven/org.apache.xmlgraphics:batik  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
