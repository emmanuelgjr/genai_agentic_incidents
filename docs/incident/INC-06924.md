**South Korean Go Player Jailed for Using AI to Cheat in Tournament**  
_2020-07-19 · real-world · Severity: High_

A South Korean Go player and an accomplice were sentenced to prison after using the AI tool Leela Zero to cheat in a professional tournament. The scheme involved transmitting real-time game data via hidden devices for AI analysis and move suggestions, undermining fair competition before being detected by officials.
