### INC-09987  [↗](/incident/INC-09987.html)

**Fetch MCP Server has a Server-Side Request Forgery (SSRF) vulnerability**  
_2025-12 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-65513`
CWEs: `CWE-918`

fetch-mcp v1.0.2 and before is vulnerable to Server-Side Request Forgery (SSRF) vulnerability, which allows attackers to bypass private IP validation and access internal network resources.

**Affected:** npm/mcp-fetch-server  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
