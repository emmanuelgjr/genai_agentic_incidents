**Use-after-free vulnerability in Google Chrome before 27.0.1453.110 allows remote attackers to cause a denial of service or possibly have unspecified other impact via vectors inv...**  
_2013-06 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2010-1230`, `CVE-2010-3411`, `CVE-2010-4484`, `CVE-2010-4578`, `CVE-2011-0474`, `CVE-2011-1203`, `CVE-2011-1305`, `CVE-2011-3017`, `CVE-2011-3954`, `CVE-2013-0829`, `CVE-2013-0880`, `CVE-2013-0911`, `CVE-2013-2860`
CWEs: `CWE-200`, `CWE-22`, `CWE-264`, `CWE-362`, `CWE-400`, `CWE-416`, `CWE-617`
CVSS: **7.5**

Use-after-free vulnerability in Google Chrome before 27.0.1453.110 allows remote attackers to cause a denial of service or possibly have unspecified other impact via vectors involving access to a database API by a worker process.

**Affected:** debian/debian_linux, google/chrome  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
