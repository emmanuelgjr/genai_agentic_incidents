### INC-09782  [↗](/incident/INC-09782.html)

**IBM Langflow Desktop 1.0.0 through 1.8.4 IBM Langflow is vulnerable to server-side request forgery (SSRF).**  
_2026-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-3340`
CWEs: `CWE-918`
CVSS: **6.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N`

IBM Langflow Desktop 1.0.0 through 1.8.4 IBM Langflow is vulnerable to server-side request forgery (SSRF). This may allow an authenticated attacker to send unauthorized requests from the system, potentially leading to network enumeration or facilitating other attacks.

**Affected:** langflow/langflow_desktop  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`
