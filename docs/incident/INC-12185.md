### INC-12185  [↗](/incident/INC-12185.html)

**MediaElement Vulnerable to Reflected XSS**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2016-4567`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Cross-site scripting (XSS) vulnerability in flash/FlashMediaElement.swf in MediaElement.js before 2.21.0, as used in WordPress before 4.5.2, allows remote attackers to inject arbitrary web script or HTML via an obfuscated form of the jsinitfunction parameter, as demonstrated by "jsinitfunctio%gn."

**Affected:** composer/contao/core, composer/contao-components/mediaelement, npm/mediaelement  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
