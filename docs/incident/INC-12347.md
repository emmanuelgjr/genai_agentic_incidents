### INC-12347  [↗](/incident/INC-12347.html)

**SimpleXML has XML External Entity (XXE) vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2013-6429`, `CVE-2014-0054`, `CVE-2014-0107`, `CVE-2014-1904`, `CVE-2015-1832`, `CVE-2017-1000190`
CWEs: `CWE-285`, `CWE-352`, `CWE-611`, `CWE-79`
CVSS: **9.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:H`

SimpleXML (latest version 2.7.1) is vulnerable to an XXE vulnerability resulting SSRF, information disclosure, DoS and so on.

**Affected:** maven/org.simpleframework:simple-xml  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
