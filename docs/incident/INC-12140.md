### INC-12140  [↗](/incident/INC-12140.html)

**OpenStack Compute (Nova) vulnerable to denial of service via XML Entity Expansion attack**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2013-4179`, `CVE-2013-4202`
CWEs: `CWE-119`

The security group extension in OpenStack Compute (Nova) Grizzly 2013.1.3, Havana before havana-3, and earlier allows remote attackers to cause a denial of service (resource consumption and crash) via an XML Entity Expansion (XEE) attack. NOTE: this issue is due to an incomplete fix for CVE-2013-1664.

**Affected:** pip/nova  
**Attack vector:** `dos`
