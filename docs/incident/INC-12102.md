### INC-12102  [↗](/incident/INC-12102.html)

**Gitea Allows 1FA Even for 2FA-Enrolled Accounts**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2019-11576`
CWEs: `CWE-287`
CVSS: **9.8** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

Gitea before 1.8.0 allows 1FA for user accounts that have completed 2FA enrollment. If a user's credentials are known, then an attacker could send them to the API without requiring the 2FA one-time password.

**Affected:** go/code.gitea.io/gitea  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`
