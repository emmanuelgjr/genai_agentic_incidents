### INC-01348  [↗](/incident/INC-01348.html)

**LlamaIndex SQL injection via prompt in NLSQLTableQueryEngine**  
_2024-01 · real-world · Severity: Critical_

CVEs: `CVE-2024-12704`, `CVE-2024-12910`, `CVE-2024-12911`, `CVE-2024-14021`, `CVE-2024-23751`, `CVE-2024-3098`, `CVE-2024-3271`, `CVE-2024-4181`, `CVE-2024-45201`, `CVE-2024-58339`, `CVE-2025-1752`, `CVE-2025-1793`, `CVE-2025-3044`, `CVE-2025-3046`, `CVE-2025-3108`, `CVE-2025-5302`, `CVE-2025-5472`, `CVE-2025-6208`, `CVE-2025-6209`, `CVE-2025-6211`, `CVE-2025-7647`, `CVE-2025-7707`
CWEs: `CWE-1112`, `CWE-22`, `CWE-29`, `CWE-377`, `CWE-378`, `CWE-400`, `CWE-440`, `CWE-502`, `CWE-674`, `CWE-77`, `CWE-770`, `CWE-835`, `CWE-89`, `CWE-94`
CVSS: **8.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

LlamaIndex (llama_index) through 0.9.34 allows SQL injection in the NLSQLTableQueryEngine when an attacker can control the natural-language query, which is translated to SQL and executed without proper safeguards.

**Affected:** llama_index <= 0.9.34  
**Attack vector:** `sql-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM02`, `LLM03`, `LLM05`, `LLM06`, `LLM08`  
**OWASP Agentic (ASI):** `ASI01`, `ASI02`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0010.001`, `AML.T0018`, `AML.T0050`, `AML.T0051`, `AML.T0053`, `AML.T0057`, `AML.T0066`
