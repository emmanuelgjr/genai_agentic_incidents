### INC-08581  [↗](/incident/INC-08581.html)

**Kimai has an arbitrary file read in its invoice PDF renderer (admin)**  
_2026-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-44298`
CWEs: `CWE-22`
CVSS: **4.1** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:C/C:L/I:N/A:N`

## Summary Users with the role `System-Admin` (`ROLE_SYSTE_ADMIN`) and the permission `upload_invoice_template` can upload PDF invoice templates, which can call `pdfContext.setOption('associated_files', ...)` inside the sandboxed Twig render. This is forwarded to mPDF's `SetAssociatedFiles()`, whose writer calls `file_get_contents($entry['path'])` during PDF output and embeds the bytes as a FlateDecode stream in the PDF.
