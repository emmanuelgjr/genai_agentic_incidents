### INC-08848  [↗](/incident/INC-08848.html)

**OpenRemote has XXE in Velbus Asset Import**  
_2026-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-40882`
CWEs: `CWE-611`
CVSS: **7.6** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:L/A:L`

### Summary The Velbus asset import path parses attacker-controlled XML without explicit XXE hardening. An authenticated user who can call the import endpoint may trigger XML external entity processing, which can lead to server-side file disclosure and SSRF.
