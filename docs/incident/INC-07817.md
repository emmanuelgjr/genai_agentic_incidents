### INC-07817  [↗](/incident/INC-07817.html)

**Claude Code AI Sandbox Vulnerability Exposes Sensitive Developer Data**  
_2026-05-20 · real-world · Severity: High_

Anthropic's Claude Code AI coding assistant suffered from critical sandbox bypass vulnerabilities for over five months, allowing attackers to exfiltrate credentials, source code, and environment variables from developer systems. The flaws, discovered by security researcher Aonan Guan, were silently patched by Anthropic without public disclosure or advisories.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`, `LLM05`  
**OWASP Agentic (ASI):** `ASI02`, `ASI03`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `MAP-3.5`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0050`, `AML.T0053`, `AML.T0057`
