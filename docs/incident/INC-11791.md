### INC-11791  [↗](/incident/INC-11791.html)

**Jenkins Compuware Common Configuration Plugin vulnerable to Improper Restriction of XML External Entity Reference**  
_2022-09 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2022-41226`, `CVE-2022-41235`, `CVE-2022-41237`, `CVE-2022-41241`
CWEs: `CWE-22`, `CWE-284`, `CWE-502`, `CWE-611`, `CWE-693`
CVSS: **7.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:L/A:N`

Jenkins Compuware Common Configuration Plugin 1.0.14 and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks. This allows attackers able to change the contents of the Topaz Workbench CLI home directory on agents to have Jenkins parse a crafted file that uses external entities for extraction of secrets from the Jenkins controller or server-side request forgery.

**Affected:** maven/com.compuware.jenkins:compuware-common-configuration  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
