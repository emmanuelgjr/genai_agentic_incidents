### INC-02920  [↗](/incident/INC-02920.html)

**ModelCache for LLM through v0.2.0 was discovered to contain an deserialization vulnerability via the component /manager/data_manager.py.**  
_2025-08 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2025-24357`, `CVE-2025-45146`
CVSS: **9.8**

ModelCache for LLM through v0.2.0 was discovered to contain an deserialization vulnerability via the component /manager/data_manager.py. This vulnerability allows attackers to execute arbitrary code via supplying crafted data.

**Affected:** codefuse/modelcache  
**Attack vector:** `deserialization`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0010.001`, `AML.T0050`
