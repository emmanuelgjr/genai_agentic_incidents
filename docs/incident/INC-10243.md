### INC-10243  [↗](/incident/INC-10243.html)

**Liferay Portal and Liferay DXP vulnerable to Stored Cross-site Scripting**  
_2025-09 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2024-26266`, `CVE-2025-43785`
CWEs: `CWE-79`

A stored cross-site scripting (XSS) vulnerability in Liferay Portal 7.4.3.45 through 7.4.3.128, and Liferay DXP 2024 Q2.0 through 2024.Q2.9, 2024.Q1.1 through 2024.Q1.12, and 7.4 update 45 through update 92 allows remote attackers to execute an arbitrary web script or HTML in the My Workflow Tasks page.

**Affected:** maven/com.liferay:com.liferay.portal.workflow.task.web, maven/com.liferay.portal:release.dxp.bom, maven/com.liferay.portal:release.dxp.bom  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
