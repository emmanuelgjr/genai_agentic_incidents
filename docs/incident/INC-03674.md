### INC-03674  [↗](/incident/INC-03674.html)

**ComfyUI-Ace-Nodes is vulnerable to Code Injection.**  
_2024-12 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2024-21577`
CWEs: `CWE-94`
CVSS: **10.0** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H`

ComfyUI-Ace-Nodes is vulnerable to Code Injection. The ACE_ExpressionEval node contains an eval() in its entrypoint function that accepts arbitrary user-controlled data. A user can create a workflow that results in executing arbitrary code on the server.

**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
