### INC-12558  [↗](/incident/INC-12558.html)

**Deserialization of Untrusted Data in Apache Heron**  
_2022-01 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-1964`
CWEs: `CWE-502`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

It was noticed that Apache Heron 0.20.2-incubating, Release 0.20.1-incubating, and Release v-0.20.0-incubating does not configure its YAML parser to prevent the instantiation of arbitrary types, resulting in a remote code execution vulnerabilities (CWE-502: Deserialization of Untrusted Data).

**Affected:** maven/org.apache.heron:heron-simulator  
**Attack vector:** `deserialization`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0010.001`, `AML.T0050`
