The alert rule name is not properly sanitized, and can be used to inject HTML code. # Affected versions The latest version at the time of writing (25.10.0) is vulnerable. # Root cause When an alert rule is created or updated via the API, function `add_edit_rule()` in `includes/html/api_functions.inc.php` is called to add/update the entry in the database. When an alert rule is created via the web interface, HTML tags are stripped from the rule name, however this is not the case when using the API. As such, it is possible to create an alert rule where the name is: ``` <script>alert(1)</script> ``` Later, when a victim browses to the Alerts > Alert Rule page, PHP script\xc2\xa0`includes/html/print-alert/rules.php`\xc2\xa0is called.
