### INC-02172  [↗](/incident/INC-02172.html)

**A vulnerability in the `default_jsonalyzer` function of the `JSONalyzeQueryEngine` in the run-llama/llama_index repository allows for SQL injection via prompt injection.**  
_2025-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-12911`
CVSS: **7.1**

A vulnerability in the `default_jsonalyzer` function of the `JSONalyzeQueryEngine` in the run-llama/llama_index repository allows for SQL injection via prompt injection. This can lead to arbitrary file creation and Denial-of-Service (DoS) attacks. The vulnerability affects the latest version and is fixed in version 0.5.1.

**Affected:** llamaindex/llamaindex  
**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM05`  
**OWASP Agentic (ASI):** `ASI01`, `ASI05`  
**NIST AI RMF:** `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0050`, `AML.T0051`
