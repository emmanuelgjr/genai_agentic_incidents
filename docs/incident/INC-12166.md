### INC-12166  [↗](/incident/INC-12166.html)

**Cross-site Scripting in SmartyException**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2012-4437`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the `SmartyException` class in Smarty (aka smarty-php) before 3.1.12 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors that trigger a Smarty exception.

**Affected:** composer/smarty/smarty  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
