### INC-01602  [↗](/incident/INC-01602.html)

**OpenClaw versions prior to 2026.2.14 contain server-side request forgery vulnerabilities in the Feishu extension that allow attackers to fetch attacker-controlled remote URLs wi...**  
_2026-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-26320`, `CVE-2026-26321`, `CVE-2026-27487`, `CVE-2026-28451`
CVSS: **8.3**

OpenClaw versions prior to 2026.2.14 contain server-side request forgery vulnerabilities in the Feishu extension that allow attackers to fetch attacker-controlled remote URLs without SSRF protections via sendMediaFeishu function and markdown image processing. Attackers can influence tool calls through direct manipulation or prompt injection to trigger requests to internal services and re-upload responses as Feishu media.

**Affected:** openclaw/openclaw  
**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0050`, `AML.T0051`
