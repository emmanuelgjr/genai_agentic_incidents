### INC-04135  [↗](/incident/INC-04135.html)

**PyTorch before v2.2.0 was discovered to contain a heap buffer overflow vulnerability in the component /runtime/vararg_functions.cpp.**  
_2024-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-31580`
CVSS: **4.0**

PyTorch before v2.2.0 was discovered to contain a heap buffer overflow vulnerability in the component /runtime/vararg_functions.cpp. This vulnerability allows attackers to cause a Denial of Service (DoS) via a crafted input.

**Affected:** linuxfoundation/pytorch  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
