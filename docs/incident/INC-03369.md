### INC-03369  [↗](/incident/INC-03369.html)

**While editing pages managed by MegaBIP a user with high privileges is prompted to give a reasoning for performing this action.**  
_2025-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-3893`
CWEs: `CWE-89`

While editing pages managed by MegaBIP a user with high privileges is prompted to give a reasoning for performing this action. Input provided by the the user is not sanitized, leading to SQL Injection vulnerability. Version 5.20 of MegaBIP fixes this issue.

**Attack vector:** `sql-injection`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
