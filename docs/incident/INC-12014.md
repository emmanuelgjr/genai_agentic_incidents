### INC-12014  [↗](/incident/INC-12014.html)

**Zen Cart vulnerable to authenticated remote code execution**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2021-3291`
CWEs: `CWE-78`
CVSS: **7.2** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:H/A:H`

Zen Cart 1.5.7b allows admins to execute arbitrary OS commands by inspecting an HTML radio input element (within the modules edit page) and inserting a command.

**Affected:** composer/zencart/zencart  
**Attack vector:** `command-injection`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
