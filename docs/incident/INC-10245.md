### INC-10245  [↗](/incident/INC-10245.html)

**Liferay Portal is vulnerable to XSS attacks via its remote app title field**  
_2025-09 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-43775`
CWEs: `CWE-79`

A stored cross-site scripting (XSS) vulnerability in Liferay Portal 7.4.0 through 7.4.3.128, and Liferay DXP 2024.Q3.0 through 2024.Q3.5, 2024.Q2.0 through 2024.Q2.12, 2024.Q1.1 through 2024.Q1.12, and 7.4 GA through update 92 allows remote attackers to inject arbitrary web script or HTML via remote app title field.

**Affected:** maven/com.liferay:com.liferay.client.extension.web  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
