### INC-12326  [↗](/incident/INC-12326.html)

**Stored XSS vulnerability in Config File Provider Plugin**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2018-1000407`, `CVE-2018-1000413`, `CVE-2018-1000415`, `CVE-2018-1000416`, `CVE-2018-1000426`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

A cross-site scripting vulnerability exists in Jenkins Config File Provider Plugin 3.1 and earlier in configfiles.jelly, providerlist.jelly that allows users with the ability to configure configuration files to insert arbitrary HTML into some pages in Jenkins.

**Affected:** maven/org.jenkins-ci.plugins:config-file-provider  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
