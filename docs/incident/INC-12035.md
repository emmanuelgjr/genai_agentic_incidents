### INC-12035  [↗](/incident/INC-12035.html)

**MunkiReport Cross-Site Scripting (XSS) Filter Bypass On Comment**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2020-15881`, `CVE-2020-15883`, `CVE-2020-15885`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

A Cross-Site Scripting (XSS) vulnerability in the comment module before 4.0 for MunkiReport allows remote attackers to inject arbitrary web script or HTML by posting a new comment.

**Affected:** composer/munkireport/comment  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
