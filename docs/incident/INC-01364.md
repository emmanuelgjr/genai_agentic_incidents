### INC-01364  [↗](/incident/INC-01364.html)

**Malicious LiteLLM PyPI Package Compromises AI Developer Systems**  
_2026-03-24 · real-world · Severity: Critical_

The popular AI middleware Python package LiteLLM was compromised on PyPI, with versions 1.82.7 and 1.82.8 containing malicious code that stole credentials and enabled backdoor access. The attack, attributed to TeamPCP, exposed developer and cloud environments to significant risk, affecting systems relying on AI agent stacks globally.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI02`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MANAGE-2.4`, `MAP-3.5`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`, `AML.T0053`, `AML.T0057`
