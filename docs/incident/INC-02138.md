### INC-02138  [↗](/incident/INC-02138.html)

**A Cross-Site Request Forgery (CSRF) vulnerability exists in the Signup feature of mlflow/mlflow versions 2.17.0 to 2.20.1.**  
_2025-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-1473`
CVSS: **7.1**

A Cross-Site Request Forgery (CSRF) vulnerability exists in the Signup feature of mlflow/mlflow versions 2.17.0 to 2.20.1. This vulnerability allows an attacker to create a new account, which may be used to perform unauthorized actions on behalf of the malicious user.

**Affected:** lfprojects/mlflow
