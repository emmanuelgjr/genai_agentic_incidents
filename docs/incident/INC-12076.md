### INC-12076  [↗](/incident/INC-12076.html)

**Improper Restriction of XML External Entity Reference in Apache POI**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2014-3529`, `CVE-2014-3574`, `CVE-2019-12415`
CWEs: `CWE-20`, `CWE-611`
CVSS: **5.5** — `CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`

In Apache POI up to 4.1.0, when using the tool XSSFExportToXml to convert user-provided Microsoft Excel documents, a specially crafted document can allow an attacker to read files from the local filesystem or from internal network resources via XML External Entity (XXE) Processing.

**Affected:** maven/org.apache.poi:poi  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
