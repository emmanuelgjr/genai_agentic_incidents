### INC-11453  [↗](/incident/INC-11453.html)

**PandasAI vulnerable to arbitrary code execution**  
_2023-08 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2023-39661`
CWEs: `CWE-74`, `CWE-94`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

An issue in pandas-ai v.0.8.1 and before allows a remote attacker to execute arbitrary code via the `_is_jailbreak` function.

**Affected:** pip/pandasai  
**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM05`  
**OWASP Agentic (ASI):** `ASI01`, `ASI05`  
**NIST AI RMF:** `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0050`, `AML.T0051`
