### INC-11001  [↗](/incident/INC-11001.html)

**WooCommerce has a Cross-Site Scripting (XSS) Vulnerability in checkout & registration forms**  
_2024-06 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-37297`
CWEs: `CWE-79`, `CWE-80`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

### Impact A vulnerability introduced in WooCommerce 8.8 allows for cross-site scripting. A bad actor can manipulate a link to include malicious HTML & JavaScript content. While the content is not saved to the database, the links may be sent to victims for malicious purposes. The injected JavaScript could hijack content & data stored in the browser, including the session.
