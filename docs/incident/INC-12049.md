### INC-12049  [↗](/incident/INC-12049.html)

**Stored XSS vulnerability in Jenkins FitNesse Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-2172`, `CVE-2020-2175`
CWEs: `CWE-611`, `CWE-776`, `CWE-79`
CVSS: **5.4** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

Jenkins FitNesse Plugin 1.31 and earlier does not correctly escape report contents before showing them on the Jenkins UI. This results in a stored cross-site scripting (XSS) vulnerability exploitable by users able to control the XML input files processed by the plugin. Jenkins FitNesse Plugin 1.32 escapes content from XML input files before rendering it on the Jenkins UI.

**Affected:** maven/org.jenkins-ci.plugins:fitnesse  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
