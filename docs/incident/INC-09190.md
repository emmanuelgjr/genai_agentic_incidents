**Admidio has an HTMLPurifier Bypass in eCard Message Allows HTML Email Injection**  
_2026-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-32755`, `CVE-2026-32757`, `CVE-2026-32812`, `CVE-2026-32816`
CWEs: `CWE-352`, `CWE-79`, `CWE-918`

## Summary The eCard send handler in Admidio uses the raw `$_POST['ecard_message']` value instead of the HTMLPurifier-sanitized `$formValues['ecard_message']` when constructing the greeting card HTML.
