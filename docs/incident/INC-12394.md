### INC-12394  [↗](/incident/INC-12394.html)

**Cross-Site Request Forgery in Spring Framework**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2013-4152`
CWEs: `CWE-352`

The Spring OXM wrapper in Spring Framework before 3.2.4 and 4.0.0.M1, when using the JAXB marshaller, does not disable entity resolution, which allows context-dependent attackers to read arbitrary files, cause a denial of service, and conduct CSRF attacks via an XML external entity declaration in conjunction with an entity reference in a (1) DOMSource, (2) StAXSource, (3) SAXSource, or (4) StreamSource, aka an XML External Entity (XXE) issue.

**Affected:** maven/org.springframework:spring-oxm  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
