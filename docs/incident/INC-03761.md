### INC-03761  [↗](/incident/INC-03761.html)

**Excessive directory permissions in MLflow leads to local privilege escalation when using spark_udf.**  
_2024-11 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-27134`
CVSS: **7.0**

Excessive directory permissions in MLflow leads to local privilege escalation when using spark_udf. This behavior can be exploited by a local attacker to gain elevated permissions by using a ToCToU attack. The issue is only relevant when the spark_udf() MLflow API is called.

**Affected:** lfprojects/mlflow  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
