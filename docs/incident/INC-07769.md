### INC-07769  [↗](/incident/INC-07769.html)

**Telegram Enables Autonomous AI Bot-to-Bot Communication, Raising Security Concerns**  
_2026-05-18 · real-world · Severity: Medium_

Telegram has introduced a feature allowing autonomous AI bots to communicate directly with each other, enabling advanced multi-agent workflows. While this innovation supports developer requests, experts warn it outpaces current security standards, potentially exposing the platform’s billion users to future risks if exploited or malfunctioning.
