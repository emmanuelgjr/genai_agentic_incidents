### INC-11998  [↗](/incident/INC-11998.html)

**LavaLite Stored Cross-site Scripting vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2020-36397`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

A stored cross site scripting (XSS) vulnerability in the `/admin/contact/contact` component of LavaLite 5.8.0 allows authenticated attackers to execute arbitrary web scripts or HTML via a crafted payload entered into the `New` parameter.

**Affected:** composer/lavalite/cms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`

- [NVD](https://nvd.nist.gov/vuln/detail/CVE-2020-36397) _(advisory)_
- [GHSA-3cfg-rxh6-h2rh](https://github.com/advisories/GHSA-3cfg-rxh6-h2rh) _(advisory)_
