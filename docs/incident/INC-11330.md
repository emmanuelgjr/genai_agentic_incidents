**Apache Cocoon Improper Restriction of XML External Entity Reference vulnerability**

CWEs: `CWE-611`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`
