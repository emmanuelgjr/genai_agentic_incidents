### INC-01455  [↗](/incident/INC-01455.html)

**Mistral AI Source Code Stolen in Major Data Breach**  
_2026-05-12 · real-world · Severity: High_

Hackers from TeamPCP stole 450 repositories containing Mistral AI's proprietary source code and training data, threatening to leak them online if not sold. Mistral AI confirmed a breach linked to SDK contamination but stated core systems and user data were unaffected. The incident involves significant intellectual property harm.

**Attack vector:** `data-exfiltration`
