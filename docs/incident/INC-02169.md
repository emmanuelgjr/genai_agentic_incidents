### INC-02169  [↗](/incident/INC-02169.html)

**A vulnerability in ollama/ollama <=0.3.14 allows a malicious user to create a customized GGUF model file, upload it to the Ollama server, and create it.**  
_2025-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-0315`
CVSS: **7.5**

A vulnerability in ollama/ollama <=0.3.14 allows a malicious user to create a customized GGUF model file, upload it to the Ollama server, and create it. This can cause the server to allocate unlimited memory, leading to a Denial of Service (DoS) attack.

**Affected:** ollama/ollama  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
