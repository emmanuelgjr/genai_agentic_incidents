### INC-12554  [↗](/incident/INC-12554.html)

**Cross-site Scripting in Scratch-Svg-Renderer**  
_2022-01 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2020-27428`
CWEs: `CWE-79`

A DOM-based cross-site scripting (XSS) vulnerability in Scratch-Svg-Renderer v0.2.0 allows attackers to execute arbitrary web scripts or HTML via a crafted sb3 file.

**Affected:** npm/scratch-svg-renderer  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
