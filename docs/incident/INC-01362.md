### INC-01362  [↗](/incident/INC-01362.html)

**Malicious AI Agent Supply Chain Attack Exploits MCP Server Lookalikes**  
_2026-04-29 · real-world · Severity: High_

Researchers discovered a supply chain attack where threat actors created lookalike Model Context Protocol (MCP) servers and malicious forks, exploiting AI agent trust to steal credentials and exfiltrate data. The attack, observed over four months, highlights significant security risks in AI agent infrastructure, particularly in software supply chains.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`, `LLM04`, `LLM09`
