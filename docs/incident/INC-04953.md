### INC-04953  [↗](/incident/INC-04953.html)

**The zanllp sd-webui-infinite-image-browsing (aka Infinite Image Browsing) extension before 977815a for stable-diffusion-webui (aka Stable Diffusion web UI), if Gradio authentica...**  
_2023-10 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-46315`
CVSS: **7.5**

The zanllp sd-webui-infinite-image-browsing (aka Infinite Image Browsing) extension before 977815a for stable-diffusion-webui (aka Stable Diffusion web UI), if Gradio authentication is enabled without secret key configuration, allows remote attackers to read any local file via /file?path= in the URL, as demonstrated by reading /proc/self/environ to discover credentials.

**Affected:** zanllp/stable_diffusion_webui_infinite_image_browsing  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`
