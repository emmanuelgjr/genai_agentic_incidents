### INC-03916  [↗](/incident/INC-03916.html)

**It was possible to move the cursor using pointerlock from an iframe.**  
_2024-07 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2015-0810`, `CVE-2018-5110`, `CVE-2019-11695`, `CVE-2020-15654`, `CVE-2021-43546`, `CVE-2022-22744`, `CVE-2022-36319`, `CVE-2022-45418`, `CVE-2024-1549`, `CVE-2024-6608`
CWEs: `CWE-1021`, `CWE-116`, `CWE-20`, `CWE-835`
CVSS: **4.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:N/A:L`

It was possible to move the cursor using pointerlock from an iframe. This allowed moving the cursor outside of the viewport and the Firefox window. This vulnerability affects Firefox < 128 and Thunderbird < 128.

**Affected:** mozilla/firefox, mozilla/thunderbird  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
