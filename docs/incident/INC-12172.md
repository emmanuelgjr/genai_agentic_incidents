### INC-12172  [↗](/incident/INC-12172.html)

**Apache Jetspeed vulnerable to Cross-site Scripting**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2016-0711`, `CVE-2016-0712`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Multiple cross-site scripting (XSS) vulnerabilities in Apache Jetspeed before 2.3.1 allow remote attackers to inject arbitrary web script or HTML via the title parameter when adding a (1) link, (2) page, or (3) folder resource.

**Affected:** maven/org.apache.portals.jetspeed-2:jetspeed-commons  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
