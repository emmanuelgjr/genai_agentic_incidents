### INC-11852  [↗](/incident/INC-11852.html)

**RuoYi 4.7.3 vulnerable to arbitrary file upload in background management module**  
_2022-07 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2022-32065`
CWEs: `CWE-434`, `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

An arbitrary file upload vulnerability in the background management module of RuoYi v4.7.3 and below allows attackers to execute arbitrary code via a crafted HTML file.

**Affected:** maven/com.ruoyi:ruoyi  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
