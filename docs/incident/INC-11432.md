### INC-11432  [↗](/incident/INC-11432.html)

**Job Configuration History Plugin's path traversal allows exploiting XXE vulnerability**  
_2023-09 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-41933`, `CVE-2023-41944`
CWEs: `CWE-611`, `CWE-79`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

Jenkins Job Configuration History Plugin 1227.v7a_79fc4dc01f and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks.

**Affected:** maven/org.jenkins-ci.plugins:jobConfigHistory  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
