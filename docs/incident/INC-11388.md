### INC-11388  [↗](/incident/INC-11388.html)

**Liferay Portal and Liferay DXP Vulnerable to XSS via the Page Tree Menu**  
_2023-10 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2023-44310`
CWEs: `CWE-79`
CVSS: **9.0** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:H/I:H/A:H`

Stored cross-site scripting (XSS) vulnerability in Page Tree menu in Liferay Layout Implementation before 6.0.102 from Liferay Portal (7.3.6 through 7.4.3.78), and Liferay DXP 7.3 fix pack 1 through update 23, and 7.4 before update 79 allows remote attackers to inject arbitrary web script or HTML via a crafted payload injected into page's "Name" text field.

**Affected:** maven/com.liferay.portal:release.dxp.bom, maven/com.liferay.portal:release.dxp.bom, maven/com.liferay:com.liferay.layout.impl  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
