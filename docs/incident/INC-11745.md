### INC-11745  [↗](/incident/INC-11745.html)

**Liferay Portal and Liferay DXP Vulnerable to XSS via the Sharing Module**  
_2022-11 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2022-42111`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

A Cross-site scripting (XSS) vulnerability in the Sharing module's user notification before 3.0.9 from Liferay Portal (7.2.1 through 7.4.2), and Liferay DXP 7.2 before fix pack 19, and 7.3 before update 4 allows remote attackers to inject arbitrary web script or HTML by sharing an asset with a crafted payload.

**Affected:** maven/com.liferay.portal:release.dxp.bom, maven/com.liferay.portal:release.dxp.bom, maven/com.liferay:com.liferay.sharing.web  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
