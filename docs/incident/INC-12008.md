### INC-12008  [↗](/incident/INC-12008.html)

**CSRF vulnerability in Jenkins Libvirt Agents Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2021-21627`
CWEs: `CWE-352`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

Jenkins Libvirt Agents Plugin 1.9.0 and earlier does not require POST requests for a form submission endpoint, resulting in a cross-site request forgery (CSRF) vulnerability. This vulnerability allows attackers to stop hypervisor domains. Jenkins Libvirt Agents Plugin 1.9.1 requires POST requests for the affected HTTP endpoint.

**Affected:** maven/org.jenkins-ci.plugins:libvirt-slave  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
