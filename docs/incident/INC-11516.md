### INC-11516  [↗](/incident/INC-11516.html)

**pypdf and PyPDF2 possible Infinite Loop when a comment isn't followed by a character**  
_2023-06 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2023-36464`
CWEs: `CWE-835`
CVSS: **6.2** — `CVSS:3.1/AV:L/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H`

### Impact An attacker who uses this vulnerability can craft a PDF which leads to an infinite loop if `__parse_content_stream` is executed. This infinite loop blocks the current process and can utilize a single core of the CPU by 100%. It does not affect memory usage. That is, for example, the case if the user extracted text from such a PDF.
