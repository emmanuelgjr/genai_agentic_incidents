### INC-10918  [↗](/incident/INC-10918.html)

**memos vulnerable to Server-Side Request Forgery in /o/get/httpmeta**  
_2024-08 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-29028`
CWEs: `CWE-918`
CVSS: **5.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:L/I:N/A:N`

memos is a privacy-first, lightweight note-taking service. In memos 0.13.2, an SSRF vulnerability exists at the /o/get/httpmeta that allows unauthenticated users to enumerate the internal network and receive limited html values in json form. This vulnerability is fixed in 0.16.1.

**Affected:** go/github.com/usememos/memos  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
