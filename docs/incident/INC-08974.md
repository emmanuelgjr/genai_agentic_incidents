### INC-08974  [↗](/incident/INC-08974.html)

**Roundcube Webmail: Insufficient CSS sanitization in HTML e-mail messages**  
_2026-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-35540`
CWEs: `CWE-669`, `CWE-918`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:C/C:L/I:L/A:N`

An issue was discovered in Roundcube Webmail 1.6.0 before 1.6.14. Insufficient Cascading Style Sheets (CSS) sanitization in HTML e-mail messages may lead to SSRF or Information Disclosure, e.g., if stylesheet links point to local network hosts.

**Affected:** composer/roundcube/roundcubemail  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
