### INC-06343  [↗](/incident/INC-06343.html)

**Amazon Alexa Vulnerability Exposed Users' Personal Data to Hackers**  
_2020-08-13 · real-world · Severity: High_

Security researchers discovered vulnerabilities in Amazon Alexa devices that could allow hackers to access users' personal information, voice histories, and control device functions via malicious links. Although Amazon quickly fixed the flaws, the incident highlighted significant privacy risks associated with AI-powered smart home assistants.

**Attack vector:** `data-exfiltration`
