### INC-11042  [↗](/incident/INC-11042.html)

**Cross-Site Scripting (XSS) in TYPO3 component CSS styled content**  
_2024-06 · vulnerability-disclosure · Severity: Medium_
CWEs: `CWE-79`

Failing to properly encode user input, the CSS styled content component is susceptible to Cross-Site Scripting, allowing authenticated editors to inject arbitrary HTML or JavaScript.

**Affected:** composer/typo3/cms, composer/typo3/cms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
