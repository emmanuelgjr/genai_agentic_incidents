### INC-02179  [↗](/incident/INC-02179.html)

**A vulnerability in the Ollama server version 0.5.11 allows a malicious user to cause a Denial of Service (DoS) attack by customizing the manifest content and spoofing a service.**  
_2025-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-1975`
CVSS: **7.5**

A vulnerability in the Ollama server version 0.5.11 allows a malicious user to cause a Denial of Service (DoS) attack by customizing the manifest content and spoofing a service. This is due to improper validation of array index access when downloading a model via the /api/pull endpoint, which can lead to a server crash.

**Affected:** ollama/ollama  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`
