### INC-12163  [↗](/incident/INC-12163.html)

**ZF-Commons ZfcUser Vulnerable to XSS in Login Redirect**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2015-1039`
CWEs: `CWE-79`
CVSS: **5.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:L/A:N`

Cross-site scripting (XSS) vulnerability in `user/login.phtml` in ZF-Commons ZfcUser before 1.2.2 allows remote attackers to inject arbitrary web script or HTML via the redirect parameter.

**Affected:** composer/zf-commons/zfc-user  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
