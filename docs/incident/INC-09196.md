### INC-09196  [↗](/incident/INC-09196.html)

**XSS in @leanprover/unicode-input-component**  
_2026-03 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2026-32732`
CWEs: `CWE-80`

### Impact Projects that use [@leanprover/unicode-input-component](https://www.npmjs.com/package/@leanprover/unicode-input-component) are vulnerable to an XSS exploit in 0.1.9 of the package and lower. The component re-inserted text in the input element back into the input element as unescaped HTML. ### Patches The issue has been resolved in 0.2.0. ### Workarounds Replace the unicode input component with a basic HTML text field.

**Affected:** npm/@leanprover/unicode-input-component  
**Attack vector:** `xss`
