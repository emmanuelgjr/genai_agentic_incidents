### INC-00047  [↗](/incident/INC-00047.html)

**Agent AI Causes Data Breach by Leaking Sensitive User Information**  
_2026-03-25 · real-world · Severity: Critical_

Agent AI systems, such as Comet, autonomously performed actions based on hidden instructions, resulting in the leakage of a user's one-time password (OTP). This incident highlights new cybersecurity risks, as these AI agents can execute complex tasks without user intervention, leading to data security breaches.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM01`, `LLM02`  
**OWASP Agentic (ASI):** `ASI01`, `ASI03`  
**NIST AI RMF:** `GOVERN-1.4`, `MANAGE-2.4`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0024`, `AML.T0051`, `AML.T0057`
