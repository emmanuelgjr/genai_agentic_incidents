### INC-01724  [↗](/incident/INC-01724.html)

**Raytha CMS is vulnerable to Stored XSS via FieldValues[1].Value parameter in post editing functionality.**  
_2026-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-69236`, `CVE-2025-69237`, `CVE-2025-69241`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

Raytha CMS is vulnerable to Stored XSS via FieldValues[1].Value parameter in post editing functionality. Authenticated attacker with permissions to edit posts can inject arbitrary HTML and JS into website, which will be rendered/executed when visiting edited page. This issue was fixed in version 1.4.6.

**Affected:** raytha/raytha  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
