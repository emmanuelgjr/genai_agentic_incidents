### INC-12091  [↗](/incident/INC-12091.html)

**Skytap Cloud CI Plugin stored credentials in plain text**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2019-10343`, `CVE-2019-10360`, `CVE-2019-10366`
CWEs: `CWE-522`, `CWE-532`, `CWE-79`
CVSS: **6.5** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`

Jenkins Skytap Cloud CI Plugin 2.06 and earlier stored credentials unencrypted in job config.xml files on the Jenkins master where they could be viewed by users with Extended Read permission, or access to the master file system.

**Affected:** maven/org.jenkins-ci.plugins:skytap  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0050`
