**Anthropic MCP Git Server Triple Flaw (CVE-2025-68143, -68144, -68145)**  
_2025-06 · real-world · Severity: High_

CVEs: `CVE-2025-68143`, `CVE-2025-68144`, `CVE-2025-68145`
