### INC-11412  [↗](/incident/INC-11412.html)

**OpenCart Path Traversal vulnerability**  
_2023-09 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-2315`
CWEs: `CWE-20`, `CWE-22`
CVSS: **8.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:H/A:H`

Path Traversal in OpenCart versions 4.0.0.0 to 4.0.2.2 allows an authenticated user with access/modify privilege on the Log component to empty out arbitrary files on the server

**Affected:** composer/opencart/opencart
