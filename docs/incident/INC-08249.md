### INC-08249  [↗](/incident/INC-08249.html)

**Froxlor's API Authentication bypasses 2FA Authentication**  
_2026-06 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-41236`, `CVE-2026-52793`
CWEs: `CWE-287`, `CWE-59`
CVSS: **8.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:N`

## Summary Froxlor's API authentication (`FroxlorRPC::validateAuth`) does not enforce Two-Factor Authentication. When a user (admin or customer) enables 2FA on their account, the web UI correctly requires a TOTP code after password verification. However, the API accepts requests authenticated with only an API key and secret — no TOTP challenge is issued, checked, or required.
