### INC-12055  [↗](/incident/INC-12055.html)

**Deserialization of Untrusted Data in JYaml**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2020-8441`
CWEs: `CWE-502`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

JYaml through 1.3 allows remote code execution during deserialization of a malicious payload through the load() function. NOTE: this is a discontinued product.

**Affected:** maven/org.jyaml:jyaml  
**Attack vector:** `deserialization`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
