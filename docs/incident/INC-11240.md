### INC-11240  [↗](/incident/INC-11240.html)

**Liferay Portal Message Board widget and Liferay DXP vulnerable to stored Cross-site Scripting**  
_2024-02 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2024-25152`
CWEs: `CWE-79`
CVSS: **9.0** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:H/I:H/A:H`

Stored cross-site scripting (XSS) vulnerability in Message Board widget in Liferay Portal 7.2.0 through 7.4.2, and older unsupported versions, and Liferay DXP 7.3 before service pack 3, 7.2 before fix pack 17, and older unsupported versions allows remote authenticated users to inject arbitrary web script or HTML via the filename of an attachment.

**Affected:** maven/com.liferay.portal:release.dxp.bom, maven/com.liferay.portal:release.dxp.bom, maven/com.liferay.portal:release.portal.bom  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
