### INC-12009  [↗](/incident/INC-12009.html)

**ShopXO RCE Vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2021-27817`
CWEs: `CWE-434`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

A remote command execution vulnerability in shopxo 1.9.3 allows an attacker to upload malicious code generated by phar where the suffix is JPG, which is uploaded after modifying the phar suffix.

**Affected:** composer/shopxo/shopxo  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
