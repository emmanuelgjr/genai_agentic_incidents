**South Korea Launches AI-Enabled Vulnerability Disclosure Pilot to Counter Hacking Threats**  
_2026-05-28 · real-world · Severity: Medium_

South Korea's government has launched a pilot program allowing white-hat hackers to use AI tools to identify and report security vulnerabilities in real-world systems. The initiative, involving major companies and public institutions, aims to proactively address rising AI-driven hacking threats by enabling continuous, transparent vulnerability discovery and remediation.
