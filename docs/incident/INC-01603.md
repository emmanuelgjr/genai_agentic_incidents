### INC-01603  [↗](/incident/INC-01603.html)

**OpenClaw — Path Traversal (CVE-2026-25475)**  
_2026-02 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-25475`
CWEs: `CWE-200`, `CWE-22`
CVSS: **6.5** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`

OpenClaw is a personal AI assistant. Prior to version 2026.1.30, the isValidMedia() function in src/media/parse.ts allows arbitrary file paths including absolute paths, home directory paths, and directory traversal sequences. An agent can read any file on the system by outputting MEDIA:/path/to/file, exfiltrating sensitive data to the user/channel. This issue has been patched in version 2026.1.30.

**Affected:** openclaw/openclaw  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
