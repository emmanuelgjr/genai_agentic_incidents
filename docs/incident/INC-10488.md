### INC-10488  [↗](/incident/INC-10488.html)

**NVIDIA NeMo Framework contains a vulnerability where a user could cause a deserialization of untrusted data by remote code execution.**  
_2025-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-23249`, `CVE-2025-23250`, `CVE-2025-23251`
CWEs: `CWE-22`, `CWE-502`, `CWE-94`
CVSS: **7.6** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:L/I:H/A:L`

NVIDIA NeMo Framework contains a vulnerability where a user could cause a deserialization of untrusted data by remote code execution. A successful exploit of this vulnerability might lead to code execution and data tampering.

**Affected:** nvidia/nemo, apple/macos, linux/linux_kernel, microsoft/windows  
**Attack vector:** `deserialization`
