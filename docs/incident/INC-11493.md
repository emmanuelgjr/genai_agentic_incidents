### INC-11493  [↗](/incident/INC-11493.html)

**Apache Ambari Expression Language Injection vulnerability**  
_2023-07 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2022-42009`
CWEs: `CWE-917`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

SpringEL injection in the server agent in Apache Ambari version 2.7.0 to 2.7.6 allows a malicious authenticated user to execute arbitrary code remotely. Users are recommended to upgrade to 2.7.7.

**Affected:** maven/org.apache.ambari:ambari  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
