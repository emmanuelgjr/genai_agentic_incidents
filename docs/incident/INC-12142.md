### INC-12142  [↗](/incident/INC-12142.html)

**Tiki Wiki CMS Groupware Cross-site scripting (XSS) vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2013-4714`
CWEs: `CWE-79`
CVSS: **4.7** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:N/I:L/A:N`

Cross-site scripting (XSS) vulnerability in Tiki Wiki CMS Groupware 6 LTS before 6.13LTS, 9 LTS before 9.7LTS, 10.x before 10.4, and 11.x before 11.1 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/tikiwiki/tiki-manager, composer/tikiwiki/tiki-manager, composer/tikiwiki/tiki-manager  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
