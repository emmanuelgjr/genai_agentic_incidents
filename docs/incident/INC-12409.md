### INC-12409  [↗](/incident/INC-12409.html)

**Commerce extension for TYPO3 vulnerable to Cross-site Scripting**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2009-4963`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the Commerce extension before 0.9.9 for TYPO3 allows remote authenticated users to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/commerceteam/commerce  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
