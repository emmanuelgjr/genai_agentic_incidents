### INC-01166  [↗](/incident/INC-01166.html)

**Hugging Face Transformers load_repo_checkpoint pickle RCE**  
_2024-04 · real-world · Severity: Critical_

CVEs: `CVE-2023-2800`, `CVE-2023-6730`, `CVE-2023-7018`, `CVE-2024-11392`, `CVE-2024-11393`, `CVE-2024-11394`, `CVE-2024-12720`, `CVE-2024-3568`, `CVE-2025-1194`, `CVE-2025-2099`, `CVE-2025-3262`, `CVE-2025-3263`, `CVE-2025-3264`, `CVE-2025-3777`, `CVE-2025-3933`, `CVE-2025-5197`, `CVE-2025-6051`, `CVE-2025-6638`, `CVE-2025-6921`, `CVE-2026-1839`
CWEs: `CWE-1333`, `CWE-20`, `CWE-377`, `CWE-400`, `CWE-502`
CVSS: **8.8** — `CVSS:3.0/AV:N/AC:H/PR:N/UI:R/S:C/C:N/I:N/A:L`

Hugging Face Transformers library is vulnerable to arbitrary code execution through deserialization of untrusted data in load_repo_checkpoint() of TFPreTrainedModel. pickle.load on external checkpoint data enables RCE. The fix removed the function.

**Affected:** huggingface/transformers (multiple)  
**Attack vector:** `deserialization`  

**OWASP LLM Top 10:** `LLM03`, `LLM04`, `LLM05`, `LLM10`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`, `ASI08`  
**NIST AI RMF:** `GOVERN-6.1`, `MANAGE-4.1`, `MAP-4.2`, `MEASURE-2.4`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0010.001`, `AML.T0011`, `AML.T0020`, `AML.T0029`, `AML.T0034`, `AML.T0048`, `AML.T0050`
