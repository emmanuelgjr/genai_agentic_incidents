### INC-08951  [↗](/incident/INC-08951.html)

**Feehi CMS has an authenticated stored cross-site scripting (XSS) vulnerability via the creation/editing module**  
_2026-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2026-31313`, `CVE-2026-31350`, `CVE-2026-31351`, `CVE-2026-31352`, `CVE-2026-31353`, `CVE-2026-31354`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

An authenticated stored cross-site scripting (XSS) vulnerability in the creation/editing module of Feehi CMS v2.1.1 allows attackers to execute arbitrary web scripts or HTML via injecting a crafted payload into the Content field.

**Affected:** composer/feehi/cms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
