### INC-11127  [↗](/incident/INC-11127.html)

**NVIDIA NeMo framework for Ubuntu contains a vulnerability in tools/asr_webapp where an attacker may cause an allocation of resources without limits or throttling.**  
_2024-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-0081`
CWEs: `CWE-770`
CVSS: **8.6** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:N/I:N/A:H`
