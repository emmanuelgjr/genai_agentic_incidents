**Boxlite: Path Traversal Vulnerability Leads to Arbitrary File Write on the Host**  
_2026-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2026-46703`
CWEs: `CWE-22`

#### Summary Boxlite is a sandbox service that allows users to create lightweight virtual machines (Boxes) and run OCI containers within them. Boxlite allows users to specify the OCI image used by containers in the sandbox. However, when processing tar entries in OCI images, Boxlite does not account for the possibility that entries may be symlinks pointing to absolute paths. An attacker can craft a malicious OCI image and distribute it on image hosting platforms such as DockerHub, tricking users into using it. Once a user loads the malicious image, the attacker can write arbitrary content to any path on the host, which can further lead to remote code execution on the host. #### Details 1.
