### INC-07554  [↗](/incident/INC-07554.html)

**Cross-site scripting (XSS) vulnerability in the file browser in notebook/notebookapp.py in IPython Notebook before 3.2.2 and Jupyter Notebook 4.0.x before 4.0.5 allows remote at...**  
_2015-09 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2015-6938`
CWEs: `CWE-79`
CVSS: **4.3**

Cross-site scripting (XSS) vulnerability in the file browser in notebook/notebookapp.py in IPython Notebook before 3.2.2 and Jupyter Notebook 4.0.x before 4.0.5 allows remote attackers to inject arbitrary web script or HTML via a folder name. NOTE: this was originally reported as a cross-site request forgery (CSRF) vulnerability, but this may be inaccurate.

**Affected:** jupyter/notebook, fedoraproject/fedora, opensuse/opensuse, ipython/notebook  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
