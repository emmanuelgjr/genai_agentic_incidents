### INC-04683  [↗](/incident/INC-04683.html)

**IBM Watson Machine Learning on Cloud Pak for Data 4.0 and 4.5 is vulnerable to server-side request forgery (SSRF).**  
_2023-04 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-30444`
CWEs: `CWE-918`
CVSS: **7.1** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:L/A:N`

IBM Watson Machine Learning on Cloud Pak for Data 4.0 and 4.5 is vulnerable to server-side request forgery (SSRF). This may allow an authenticated attacker to send unauthorized requests from the system, potentially leading to network enumeration or facilitating other attacks. IBM X-Force ID: 253350.

**Affected:** ibm/watson_machine_learning_on_cloud_pak_for_data  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
