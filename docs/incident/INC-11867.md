### INC-11867  [↗](/incident/INC-11867.html)

**Missing Authorization in Jenkins XPath Configuration Viewer Plugin**  
_2022-07 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2022-34786`, `CVE-2022-34788`, `CVE-2022-34793`, `CVE-2022-34794`, `CVE-2022-34803`, `CVE-2022-34811`
CWEs: `CWE-256`, `CWE-522`, `CWE-611`, `CWE-79`, `CWE-862`
CVSS: **4.3** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:N/A:N`

XPath Configuration Viewer Plugin 1.1.1 and earlier does not perform a permission check in an HTTP endpoint. This allows attackers with Overall/Read permission to access the XPath Configuration Viewer page. Given appropriate XPath expressions, this page grants access to job configuration XML data to every user with Item/Read permission. The encrypted values of secrets stored in the job configuration are not redacted, as they would be by the config.xml API for users without Item/Configure permission.

**Affected:** maven/org.jenkins-ci.plugins:xpath-config-viewer  
**Attack vector:** `auth-bypass`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`
