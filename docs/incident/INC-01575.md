### INC-01575  [↗](/incident/INC-01575.html)

**OpenAI Codex Flaw Exposed GitHub Credentials via Command Injection**  
_2026-03-30 · real-world · Severity: High_

A critical vulnerability in OpenAI's Codex coding agent allowed attackers to exploit unsanitized branch names, enabling command injection and theft of GitHub OAuth tokens. This flaw exposed developers' credentials and private repositories, risking unauthorized access and enterprise security breaches. OpenAI has since patched the vulnerability after researchers demonstrated its exploitability.
