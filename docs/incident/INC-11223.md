### INC-11223  [↗](/incident/INC-11223.html)

**Bagisto Cross-Site Request Forgery vulnerability**  
_2024-02 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-36237`
CWEs: `CWE-352`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

Cross Site Request Forgery vulnerability in Bagisto before v.1.3.2 allows an attacker to execute arbitrary code via a crafted HTML script.

**Affected:** composer/bagisto/bagisto  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`
