### INC-12256  [↗](/incident/INC-12256.html)

**Improper Input Validation in Apache Batik**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2015-0250`
CWEs: `CWE-20`

XML external entity (XXE) vulnerability in the SVG to (1) PNG and (2) JPG conversion classes in Apache Batik 1.x before 1.8 allows remote attackers to read arbitrary files or cause a denial of service via a crafted SVG file.

**Affected:** maven/org.apache.xmlgraphics:batik  
**Attack vector:** `dos`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
