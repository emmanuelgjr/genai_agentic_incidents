### INC-12412  [↗](/incident/INC-12412.html)

**Apache Solr Search for TYPO3 vulnerable to Cross-site Scripting**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2009-3821`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the Apache Solr Search (solr) extension 1.0.0 for TYPO3 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/apache-solr-for-typo3/solr  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
