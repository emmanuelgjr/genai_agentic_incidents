### INC-11013  [↗](/incident/INC-11013.html)

**ebookmeta XML External Entity vulnerability**  
_2024-06 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-36827`, `CVE-2024-37388`
CWEs: `CWE-611`, `CWE-776`
CVSS: **9.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:H`

An XML External Entity (XXE) vulnerability in the `ebookmeta.get_metadata` function via lxml dependency allows attackers to access sensitive information or cause a Denial of Service (DoS) via crafted XML input.

**Affected:** pip/ebookmeta  
**Attack vector:** `info-disclosure`  

**OWASP LLM Top 10:** `LLM02`, `LLM03`  
**OWASP Agentic (ASI):** `ASI02`, `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`, `MAP-3.5`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0024`, `AML.T0053`, `AML.T0057`
