**Grav is vulnerable to RCE via SSTI through Twig Sandbox Bypass**  
_2025-12 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-66294`
CWEs: `CWE-1336`, `CWE-94`

### Summary A Server-Side Template Injection (SSTI) vulnerability exists in Grav that allows authenticated attackers with editor permissions to execute arbitrary commands on the server and, under certain conditions, may also be exploited by unauthenticated attackers.
