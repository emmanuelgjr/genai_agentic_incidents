### INC-11612  [↗](/incident/INC-11612.html)

**thorsten/phpmyfaq vulnerable to stored cross-site scripting (XSS) via HTML export**  
_2023-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2023-1756`
CWEs: `CWE-79`
CVSS: **4.7** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:U/C:L/I:L/A:L`

thorsten/phpmyfaq prior to 3.1.12 is vulnerable to stored cross-site scripting (XSS) because it fails to sanitize user input in the FAQ site while generating an HTML Export. This has been fixed in 3.1.12.

**Affected:** composer/thorsten/phpmyfaq  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
