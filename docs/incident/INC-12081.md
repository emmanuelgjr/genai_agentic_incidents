### INC-12081  [↗](/incident/INC-12081.html)

**OpenStack Octavia Amphora-Agent not requiring Client-Certificate**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2019-17134`
CWEs: `CWE-287`
CVSS: **9.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N`

Amphora Images in OpenStack Octavia >=0.10.0 <2.1.2, >=3.0.0 <3.2.0, >=4.0.0 <4.1.0 allows anyone with access to the management network to bypass client-certificate based authentication and retrieve information or issue configuration commands via simple HTTP requests to the Agent on port https/9443, because the `cmd/agent.py` gunicorn cert_reqs option is True but is supposed to be ssl.CERT_REQUIRED.

**Affected:** pip/octavia, pip/octavia, pip/octavia  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
