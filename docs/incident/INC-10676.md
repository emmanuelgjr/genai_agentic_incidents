**XSS/HTML Injection Vulnerability in Umbraco Backoffice Components**  
_2025-01 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-24012`
CWEs: `CWE-79`
CVSS: **4.6** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:U/C:L/I:L/A:N`
