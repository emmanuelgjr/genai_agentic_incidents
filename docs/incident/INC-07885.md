### INC-07885  [↗](/incident/INC-07885.html)

**Manipulation of X's Recommendation Algorithm in Turkey via Security Flaw and Bot Networks**  
_2026-05-25 · real-world · Severity: Medium_

A coordinated operation exploited a security vulnerability (CVE-2023-29218) in X's recommendation algorithm, using bot networks to suppress pro-government accounts and amplify opposition content in Turkey. This manipulation distorted public discourse, spread misinformation, and undermined democratic information access, causing harm to communities and political rights.

**Attack vector:** `misinformation`
