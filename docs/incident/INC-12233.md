### INC-12233  [↗](/incident/INC-12233.html)

**Basic SEO Features (seo_basics) extension TYPO3 vulnerable to Cross-site Scripting**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2012-5888`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in Basic SEO Features (seo_basics) extension before 0.8.2 for TYPO3 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/b13/seo_basics  
**Attack vector:** `xss`
