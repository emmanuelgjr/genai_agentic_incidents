### INC-11761  [↗](/incident/INC-11761.html)

**OpenStack Sushy-Tools and VirtualBMC Improper Preservation of Permissions**  
_2022-10 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2022-44020`
CWEs: `CWE-281`
CVSS: **5.5** — `CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:U/C:N/I:H/A:N`

An issue was discovered in OpenStack Sushy-Tools through 0.21.0 and VirtualBMC through 2.2.2. Changing the boot device configuration with these packages removes password protection from the managed libvirt XML domain. NOTE: this only affects an "unsupported, production-like configuration."

**Affected:** pip/virtualbmc, pip/sushy-tools  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`  
**OWASP Agentic (ASI):** `ASI04`  
**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
