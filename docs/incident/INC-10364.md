### INC-10364  [↗](/incident/INC-10364.html)

**Eclipse GlassFish is vulnerable to Stored XSS attacks through configuration file modifications**  
_2025-07 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-10031`
CWEs: `CWE-79`

In Eclipse GlassFish version 7.0.15 is possible to perform Stored Cross-site Scripting attacks by modifying the configuration file in the underlying operating system.

**Affected:** maven/org.glassfish.main.admingui:console-common  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
