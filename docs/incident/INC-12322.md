### INC-12322  [↗](/incident/INC-12322.html)

**Apache XML-RPC XXE Vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2016-5002`
CWEs: `CWE-611`
CVSS: **7.8** — `CVSS:3.0/AV:L/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

XML external entity (XXE) vulnerability in the Apache XML-RPC (aka ws-xmlrpc) library 3.1.3, as used in Apache Archiva, allows remote attackers to conduct server-side request forgery (SSRF) attacks via a crafted DTD.

**Affected:** maven/org.apache.xmlrpc:xmlrpc  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
