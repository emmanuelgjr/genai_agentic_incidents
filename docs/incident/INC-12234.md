### INC-12234  [↗](/incident/INC-12234.html)

**Cross-site scripting in yui 2.4.0**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2012-5881`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the Flash component infrastructure in YUI 2.4.0 through 2.9.0 allows remote attackers to inject arbitrary web script or HTML via vectors related to charts.swf, a similar issue to CVE-2010-4207.

**Affected:** npm/yui2  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
