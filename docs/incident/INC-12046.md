### INC-12046  [↗](/incident/INC-12046.html)

**Dolibarr Stored Cross-site Scripting via file upload**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2020-13239`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

The DMS/ECM module in Dolibarr 11.0.4 renders user-uploaded .html files in the browser when the attachment parameter is removed from the direct download link. This causes XSS.

**Affected:** composer/dolibarr/dolibarr  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
