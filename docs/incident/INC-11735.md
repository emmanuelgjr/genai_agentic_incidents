### INC-11735  [↗](/incident/INC-11735.html)

**PyroCMS vulnerable to stored Cross Site Scripting**  
_2022-11 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2022-37721`
CWEs: `CWE-79`
CVSS: **9.0** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:H/I:H/A:H`

PyroCMS 3.9 is vulnerable to a stored Cross Site Scripting (XSS) when a low privileged user, such as an author, injects a crafted html and javascript payload in a blog post, leading to full admin account takeover or privilege escalation.

**Affected:** composer/pyrocms/pyrocms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
