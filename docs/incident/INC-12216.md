### INC-12216  [↗](/incident/INC-12216.html)

**typo3/cms-felogin Cross-site Scripting vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2008-5656`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the frontend plugin for the felogin system extension in TYPO3 4.2.0, 4.2.1 and 4.2.2 allows remote attackers to inject arbitrary web script or HTML via unknown vectors.

**Affected:** composer/typo3/cms-felogin  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
