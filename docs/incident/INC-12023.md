### INC-12023  [↗](/incident/INC-12023.html)

**XXE vulnerability in Jenkins Nerrvana Plugin**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2020-2298`
CWEs: `CWE-611`
CVSS: **6.5** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`

Jenkins Nerrvana Plugin 1.02.06 and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks. This allows attackers with Overall/Read permission to have Jenkins parse a crafted HTTP request with XML data that uses external entities for extraction of secrets from the Jenkins controller or server-side request forgery. Additionally, XML parsing is exposed as a form validation endpoint that does not require POST requests, allowing exploitation by users without Overall/Read permission via CSRF.

**Affected:** maven/org.jenkins-ci.plugins:nerrvana-plugin  
**Attack vector:** `ssrf`
