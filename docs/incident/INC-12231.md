### INC-12231  [↗](/incident/INC-12231.html)

**Typo3 Exception Handler XSS**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2012-2112`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the Exception Handler in TYPO3 4.4.x before 4.4.15, 4.5.x before 4.5.15, 4.6.x before 4.6.8, and 4.7 allows remote attackers to inject arbitrary web script or HTML via exception messages.

**Affected:** composer/typo3/cms, composer/typo3/cms, composer/typo3/cms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
