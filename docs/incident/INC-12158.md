### INC-12158  [↗](/incident/INC-12158.html)

**Mayan EDMS multiple cross-site scripting (XSS) vulnerabilities**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2014-3840`
CWEs: `CWE-79`

Multiple cross-site scripting (XSS) vulnerabilities in apps/common/templates/calculate_form_title.html in Mayan EDMS 0.13 allow remote authenticated users to inject arbitrary web script or HTML via a (1) tag or the (2) title of a source in a Staging folder, (3) Name field in a bootstrap setup, or Title field in a (4) smart link or (5) web form.

**Affected:** pip/mayan-edms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
