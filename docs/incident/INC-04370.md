### INC-04370  [↗](/incident/INC-04370.html)

**ZenML Server in the ZenML machine learning package before 0.46.7 for Python allows remote privilege escalation because the /api/v1/users/{user_name_or_id}/activate REST API endp...**  
_2024-02 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-25723`
CWEs: `CWE-284`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

ZenML Server in the ZenML machine learning package before 0.46.7 for Python allows remote privilege escalation because the /api/v1/users/{user_name_or_id}/activate REST API endpoint allows access on the basis of a valid username along with a new password in the request body. These are also patched versions: 0.44.4, 0.43.1, and 0.42.2.

**Affected:** zenml/zenml  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`

**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
