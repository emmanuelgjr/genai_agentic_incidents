### INC-11839  [↗](/incident/INC-11839.html)

**Feehi CMS Cross-site Scripting**  
_2022-07 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2022-34140`
CWEs: `CWE-79`
CVSS: **5.4** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N`

A stored cross-site scripting (XSS) vulnerability in `/index.php?r=site%2Fsignup` of Feehi CMS v2.1.1 allows attackers to execute arbitrary web scripts or HTML via a crafted payload injected into the username field.

**Affected:** composer/feehi/cms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
