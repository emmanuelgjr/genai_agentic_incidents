### INC-10349  [↗](/incident/INC-10349.html)

**Mezzanine CMS vulnerable to Cross-site Scripting**  
_2025-07 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-50481`
CWEs: `CWE-79`
CVSS: **4.8** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:R/S:C/C:L/I:L/A:N`

A cross-site scripting (XSS) vulnerability in the component /blog/blogpost/add of Mezzanine CMS v6.1.0 allows attackers to execute arbitrary web scripts or HTML via injecting a crafted payload into a blog post.

**Affected:** pip/Mezzanine  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
