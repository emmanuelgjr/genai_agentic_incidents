### INC-03928  [↗](/incident/INC-03928.html)

**Kohya_ss — Command Injection (CVE-2024-32022)**  
_2024-04 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2024-32022`, `CVE-2024-32023`, `CVE-2024-32024`, `CVE-2024-32025`, `CVE-2024-32026`, `CVE-2024-32027`
CWEs: `CWE-22`, `CWE-77`
CVSS: **9.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N`

Kohya_ss is a GUI for Kohya's Stable Diffusion trainers. Kohya_ss is vulnerable to command injection in basic_caption_gui.py. This vulnerability is fixed in 23.1.5.

**Affected:** bmaltais/kohya_ss  
**Attack vector:** `command-injection`

**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
