**LibreNMS has a Time-Based Blind SQL Injection in address-search.inc.php**  
_2026-02 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2026-26990`
CWEs: `CWE-89`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

### Summary A time-based blind SQL injection vulnerability exists in `address-search.inc.php` via the `address` parameter. When a crafted subnet prefix is supplied, the prefix value is concatenated directly into an SQL query without proper parameter binding, allowing an attacker to manipulate query logic and infer database information through time-based conditional responses. ### Details This vulnerability requires authentication and is exploitable by any authenticated user.
