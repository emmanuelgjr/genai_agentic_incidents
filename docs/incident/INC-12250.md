### INC-12250  [↗](/incident/INC-12250.html)

**Persistent XSS vulnerability in Jenkins OWASP Dependency-Check Plugin**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2017-1000102`, `CVE-2017-1000103`, `CVE-2017-1000109`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

The custom Details view of the Static Analysis Utilities based OWASP Dependency-Check Plugin, was vulnerable to a persisted cross-site scripting vulnerability: Malicious users able to influence the input to this plugin could insert arbitrary HTML into this view.

**Affected:** maven/org.jenkins-ci.plugins:dependency-check-jenkins-plugin  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
