### INC-07313  [↗](/incident/INC-07313.html)

**In Jupyter Notebook before 5.4.1, a maliciously forged notebook file can bypass sanitization to execute JavaScript in the notebook context.**  
_2018-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2018-8768`
CVSS: **7.8** — `CVSS:3.0/AV:L/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

In Jupyter Notebook before 5.4.1, a maliciously forged notebook file can bypass sanitization to execute JavaScript in the notebook context. Specifically, invalid HTML is 'fixed' by jQuery after sanitization, making it dangerous.

**Affected:** jupyter/notebook  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`
