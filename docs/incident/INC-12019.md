### INC-12019  [↗](/incident/INC-12019.html)

**XXE vulnerability in Jenkins CVS Plugin**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2020-2324`
CWEs: `CWE-611`
CVSS: **7.5** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N`

Jenkins CVS Plugin 2.16 and earlier does not configure its XML parser to prevent XML external entity (XXE) attacks. This allows attackers able to control an agent process to have Jenkins parse a crafted changelog file that uses external entities for extraction of secrets from the Jenkins controller or server-side request forgery. Jenkins CVS Plugin 2.17 disables external entity resolution for its XML parser.

**Affected:** maven/org.jenkins-ci.plugins:cvs  
**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`
