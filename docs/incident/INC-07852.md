**UK Launches Pilot Scheme for Self-Driving Taxi and Bus Services**  
_2026-05-21 · real-world · Severity: Medium_

The UK government has opened applications for operators to run self-driving taxi and bus services, allowing firms like Wayve to pilot autonomous vehicles carrying passengers on public roads later this year. The scheme aims to improve accessibility and safety, but introduces potential risks associated with AI-driven transport.
