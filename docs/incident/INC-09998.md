### INC-09998  [↗](/incident/INC-09998.html)

**alexusmai laravel-file-manager is vulnerable to Directory Traversal via the unzip/extraction functionality**  
_2025-12 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-65346`
CWEs: `CWE-22`
CVSS: **9.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N`

alexusmai laravel-file-manager 3.3.1 and below is vulnerable to Directory Traversal. The unzip/extraction functionality improperly allows archive contents to be written to arbitrary locations on the filesystem due to insufficient validation of extraction paths.

**Affected:** composer/alexusmai/laravel-file-manager  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
