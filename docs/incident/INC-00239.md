**AI Tools Expose Security Flaws in Legacy and Smart Home Devices, Leading to Privacy Risks**  
_2026-03-09 · real-world · Severity: High_

AI systems like Claude Opus 4.6 have demonstrated the ability to autonomously discover critical security vulnerabilities in legacy code and smart home devices. Notably, a flaw in DJI Romo robotic vacuums allowed unauthorized access to private user data, highlighting significant privacy and security risks in AI-enabled products. Companies responded with patches and bounties.
