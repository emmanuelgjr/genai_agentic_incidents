### INC-11987  [↗](/incident/INC-11987.html)

**Missing Authentication for Critical Function in Apache Airflow**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2021-38540`
CWEs: `CWE-306`
CVSS: **9.8** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

The variable import endpoint was not protected by authentication in Airflow >=2.0.0, <2.1.3. This allowed unauthenticated users to hit that endpoint to add/modify Airflow variables used in DAGs, potentially resulting in a denial of service, information disclosure or remote code execution. This issue affects Apache Airflow >=2.0.0, <2.1.3.

**Affected:** pip/apache-airflow  
**Attack vector:** `info-disclosure`
