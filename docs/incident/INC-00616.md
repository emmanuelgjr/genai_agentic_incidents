### INC-00616  [↗](/incident/INC-00616.html)

**Anthropic's Claude Desktop Secretly Installs Browser Backdoor on macOS**  
_2026-04-22 · real-world · Severity: High_

Anthropic's Claude Desktop AI application for macOS was found to secretly install configuration files that pre-authorize its browser extensions to access and control browser sessions, even for browsers not yet installed. This was done without user consent, creating significant privacy and security risks, and violating user rights.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`  
**OWASP Agentic (ASI):** `ASI03`  
**NIST AI RMF:** `GOVERN-1.4`, `MEASURE-2.10`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0057`
