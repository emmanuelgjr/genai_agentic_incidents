### INC-10247  [↗](/incident/INC-10247.html)

**MONAI does not prevent path traversal, potentially leading to arbitrary file writes**  
_2025-09 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2025-58755`
CWEs: `CWE-22`
CVSS: **8.8** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

### Summary The extractall function ```zip_file.extractall(output_dir)``` is used directly to process compressed files. It is used in many places in the project. When the Zip file containing malicious content is decompressed, it will overwrite the system files. In addition, the project allows the download of the zip content through the link, which increases the scope of exploitation of this vulnerability.
