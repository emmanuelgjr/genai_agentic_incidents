**Russia Tests AI-Enabled Combat Drones in Syria**  
_2020-12-04 · real-world · Severity: Critical_

Russia's Rostec announced successful combat tests of Kalashnikov AI-enabled drones in Syria, marking their use in real conflict missions. The Defense Ministry has ordered these drones, which feature autonomous reconnaissance and targeting capabilities, raising concerns about AI-driven harm in warfare.
