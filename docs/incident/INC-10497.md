### INC-10497  [↗](/incident/INC-10497.html)

**Laravel Starter Cross Site Scripting (XSS)**  
_2025-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2025-26159`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Laravel Starter 11.11.0 is vulnerable to Cross Site Scripting (XSS) in the tags feature. Any user with the ability of create or modify tags can inject malicious JavaScript code in the name field.

**Affected:** composer/nasirkhan/laravel-starter  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
