### INC-10554  [↗](/incident/INC-10554.html)

**AgentScope directory traversal vulnerability in /read-examples**  
_2025-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-8438`, `CVE-2024-8524`
CWEs: `CWE-22`, `CWE-73`
CVSS: **7.5** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N`

A directory traversal vulnerability exists in modelscope/agentscope version 0.0.4. An attacker can exploit this vulnerability to read any local JSON file by sending a crafted POST request to the /read-examples endpoint.

**Affected:** pip/agentscope  
**Attack vector:** `path-traversal`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
