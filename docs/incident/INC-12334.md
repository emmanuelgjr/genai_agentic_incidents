### INC-12334  [↗](/incident/INC-12334.html)

**Donfig Command Injection in collect_yaml method**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2019-7537`
CWEs: `CWE-77`
CVSS: **9.8** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

An issue was discovered in Donfig 0.3.0. There is a vulnerability in the `collect_yaml` method in `config_obj.py`. It can execute arbitrary Python commands, resulting in command execution.

**Affected:** pip/donfig  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`
