### INC-09524  [↗](/incident/INC-09524.html)

**SiYuan has a Reflected Cross-Site Scripting (XSS) via /api/icon/getDynamicIcon**  
_2026-01 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2026-23847`
CWEs: `CWE-79`
CVSS: **4.6** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:U/C:L/I:L/A:N`

### Summary Reflected XSS in /api/icon/getDynamicIcon due to unsanitized SVG input. ### Details The endpoint generates SVG images for text icons (type=8). The content query parameter is inserted directly into the SVG <text> tag without XML escaping. Since the response Content-Type is image/svg+xml, injecting unescaped tags allows breaking the XML structure and executing JavaScript. ### PoC Payload: `test</text><script>alert(window.origin)</script><text>` 1.
