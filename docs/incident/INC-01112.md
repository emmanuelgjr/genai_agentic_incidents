### INC-01112  [↗](/incident/INC-01112.html)

**Google Deploys AI-Powered Ransomware Detection for Drive Users Globally**  
_2026-03-30 · real-world · Severity: Critical_

Google has rolled out an AI-powered ransomware detection and file restoration system for Google Drive, now available to all Workspace users. The AI model detects ransomware activity, pauses file syncing to prevent data loss, and enables file restoration, significantly improving protection against ransomware attacks on Windows and macOS devices.

**Attack vector:** `rce`  

**OWASP Agentic (ASI):** `ASI05`, `ASI10`  
**NIST AI RMF:** `GOVERN-1.4`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0048`, `AML.T0050`
