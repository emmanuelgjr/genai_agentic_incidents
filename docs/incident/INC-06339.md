### INC-06339  [↗](/incident/INC-06339.html)

**Alipay Facial Recognition System Exploited by Fraudsters Using AI-Generated 3D Avatars**  
_2020-02-16 · real-world · Severity: High_

In 2018, fraudsters exploited Alipay's AI-powered facial recognition by using software-generated 3D avatars and stolen personal data to create fake accounts and claim rewards. Alipay detected the anomaly, alerted authorities, and upgraded security. No user financial losses occurred, but the incident highlighted vulnerabilities in biometric AI systems.

**Attack vector:** `data-exfiltration`  

**OWASP LLM Top 10:** `LLM02`, `LLM09`  
**OWASP Agentic (ASI):** `ASI03`, `ASI09`  
**NIST AI RMF:** `GOVERN-1.4`, `MAP-3.5`, `MEASURE-2.10`, `MEASURE-2.8`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0048.003`, `AML.T0057`, `AML.T0058`
