### INC-12246  [↗](/incident/INC-12246.html)

**NodeBB Cross-site Scripting Vulnerability in Markdown Processing**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2015-3296`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Multiple cross-site scripting (XSS) vulnerabilities in NodeBB before 0.7 allow remote attackers to inject arbitrary web script or HTML via vectors related to (1) javascript: or (2) data: URLs.

**Affected:** npm/nodebb-plugin-markdown, npm/nodebb  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
