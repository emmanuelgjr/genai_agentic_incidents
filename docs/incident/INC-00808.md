### INC-00808  [↗](/incident/INC-00808.html)

**Claude AI Vulnerabilities Enable Silent Data Theft and Malicious Redirects**  
_2026-03-18 · real-world · Severity: Critical_

Security researchers uncovered a chain of vulnerabilities in Anthropic's Claude.ai platform, dubbed "Claudy Day," allowing attackers to silently exfiltrate sensitive user data and redirect users to malicious sites via prompt injection, API misuse, and open redirects. Anthropic has patched the main flaw and is addressing remaining issues.

**Attack vector:** `prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM02`  
**OWASP Agentic (ASI):** `ASI01`, `ASI02`, `ASI03`  
**NIST AI RMF:** `GOVERN-1.4`, `MANAGE-2.4`, `MAP-3.5`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0024`, `AML.T0051`, `AML.T0053`, `AML.T0057`
