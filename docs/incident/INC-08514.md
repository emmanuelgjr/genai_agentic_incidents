### INC-08514  [↗](/incident/INC-08514.html)

**CodeWhale — Ssrf (CVE-2026-45373)**  
_2026-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2026-45373`, `CVE-2026-45374`
CWEs: `CWE-918`, `CWE-94`
CVSS: **7.4** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:H/I:N/A:N`

CodeWhale is a DeepSeek + MiMo coding agent in terminal. Prior to 0.8.26, although SSRF is validated against hostnames that resolve to private IPv6 addresses, when providing the IPV6 in‌‌ URL‌ as http://[::1], the SSRF defenses do not work. This vulnerability is fixed in 0.8.26.

**Attack vector:** `ssrf`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0049`, `AML.T0050`
