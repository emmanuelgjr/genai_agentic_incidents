### INC-12242  [↗](/incident/INC-12242.html)

**Jenkins allows Cross-Site Scripting (XSS) in User Configuration**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2013-5573`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the default markup formatter in Jenkins 1.523 allows remote attackers to inject arbitrary web script or HTML via the Description field in the user configuration.

**Affected:** maven/org.jenkins-ci.main:jenkins-core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
