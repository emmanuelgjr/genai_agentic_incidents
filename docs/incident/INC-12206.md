### INC-12206  [↗](/incident/INC-12206.html)

**Yii Framework Reflected XSS**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2017-7271`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

Reflected Cross-site scripting (XSS) vulnerability in Yii Framework before 2.0.11, when development mode is used, allows remote attackers to inject arbitrary web script or HTML via crafted request data that is mishandled on the debug-mode exception screen.

**Affected:** composer/yiisoft/yii2  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
