### INC-12358  [↗](/incident/INC-12358.html)

**Keycloak Authentication Error**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2018-10894`
CWEs: `CWE-295`
CVSS: **5.4** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:L/A:N`

It was found that SAML authentication in Keycloak 3.4.3.Final incorrectly authenticated expired certificates. A malicious user could use this to access unauthorized data or possibly conduct further attacks.

**Affected:** maven/org.keycloak:keycloak-services, maven/org.keycloak:keycloak-saml-adapter-core  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`

**NIST AI RMF:** `GOVERN-6.1`  
**MITRE ATLAS:** `AML.T0010`
