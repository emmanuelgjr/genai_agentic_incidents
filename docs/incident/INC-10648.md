_2025-02 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2025-24981`
CWEs: `CWE-79`
CVSS: **9.3** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:N/A:L`

It does so by matching protocol schemes like `javascript:` and others.
