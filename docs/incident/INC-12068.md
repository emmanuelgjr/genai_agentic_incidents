### INC-12068  [↗](/incident/INC-12068.html)

**Jenkins Rundeck Plugin stored credentials in plain text**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2019-16549`, `CVE-2019-16550`, `CVE-2019-16556`, `CVE-2019-16557`
CWEs: `CWE-352`, `CWE-522`, `CWE-611`
CVSS: **6.5** — `CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N`

Jenkins Rundeck Plugin 3.6.5 and earlier stores credentials unencrypted in its global configuration file and in job config.xml files on the Jenkins master where they can be viewed by users with Extended Read permission, or access to the master file system.

**Affected:** maven/org.jenkins-ci.plugins:rundeck  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI03`, `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-1.4`, `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0012`, `AML.T0049`, `AML.T0050`
