### INC-12161  [↗](/incident/INC-12161.html)

**WEC Map (wec_map) extension for TYPO3 allows Cross-site Scripting**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2014-6292`, `CVE-2014-6296`
CWEs: `CWE-79`, `CWE-862`

Cross-site scripting (XSS) vulnerability in the WEC Map (wec_map) extension before 3.0.3 for TYPO3 allows remote attackers to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** composer/jbartels/wec-map, composer/web-tp3/wec_map  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
