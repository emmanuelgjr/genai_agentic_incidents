### INC-12353  [↗](/incident/INC-12353.html)

**Improper Privilege Management in Jenkins**  
_2022-05 · vulnerability-disclosure · Severity: Critical_

CVEs: `CVE-2018-1000865`, `CVE-2018-1000866`, `CVE-2019-1003013`, `CVE-2019-1003015`
CWEs: `CWE-269`, `CWE-611`, `CWE-79`
CVSS: **8.8** — `CVSS:3.0/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H`

A sandbox bypass vulnerability exists in Script Security Plugin 1.47 and earlier in groovy-sandbox/src/main/java/org/kohsuke/groovy/sandbox/SandboxTransformer.java that allows attackers with Job/Configure permission to execute arbitrary code on the Jenkins master JVM, if plugins using the Groovy sandbox are installed.

**Affected:** maven/org.jenkins-ci.plugins:script-security  
**Attack vector:** `sandbox-escape`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
