### INC-12266  [↗](/incident/INC-12266.html)

**Fork CMS XSS via Highlight Parameter**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2012-1209`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in `backend/core/engine/base.php` in Fork CMS 3.2.4 and possibly other versions before 3.2.5 allows remote attackers to inject arbitrary web script or HTML via the highlight parameter.

**Affected:** composer/forkcms/forkcms  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
