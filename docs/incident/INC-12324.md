### INC-12324  [↗](/incident/INC-12324.html)

**Apache Struts Code injection due to conversion error**  
_2022-05 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2012-0838`
CWEs: `CWE-20`

Apache Struts 2 before 2.2.3.1 evaluates a string as an OGNL expression during the handling of a conversion error, which allows remote attackers to modify run-time data values, and consequently execute arbitrary code, via invalid input to a field.

**Affected:** maven/org.apache.struts.xwork:xwork-core, maven/org.apache.struts:struts2-core  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
