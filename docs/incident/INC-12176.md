### INC-12176  [↗](/incident/INC-12176.html)

**Jenkins Build Failure Analyzer Plugin allows Cross-Site Scripting (XSS)**  
_2022-05 · vulnerability-disclosure · Severity: Low_

CVEs: `CVE-2013-6374`
CWEs: `CWE-79`

Cross-site scripting (XSS) vulnerability in the Build Failure Analyzer plugin before 1.5.1 for Jenkins allows remote authenticated users to inject arbitrary web script or HTML via unspecified vectors.

**Affected:** maven/com.sonyericsson.jenkins.plugins.bfa:build-failure-analyzer  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
