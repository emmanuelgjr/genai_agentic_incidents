### INC-02539  [↗](/incident/INC-02539.html)

**EchoLeak zero-click vulnerability in Microsoft 365 Copilot**  
_2025-06-11 · vulnerability-disclosure · Severity: Critical_

Aim Security disclosed 'EchoLeak' (CVE-2025-32711), a zero-click indirect-prompt-injection chain that lets an attacker exfiltrate corporate data from Microsoft 365 Copilot merely by sending an email; Microsoft patched the issue server-side.

**Affected:** Microsoft 365 Copilot customers  
**Attack vector:** `indirect-prompt-injection`  

**OWASP LLM Top 10:** `LLM01`, `LLM02`  
**OWASP Agentic (ASI):** `ASI01`, `ASI03`  
**NIST AI RMF:** `GOVERN-1.4`, `MANAGE-2.4`, `MEASURE-2.10`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0012`, `AML.T0024`, `AML.T0051`, `AML.T0057`
