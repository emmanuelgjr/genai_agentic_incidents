### INC-10501  [↗](/incident/INC-10501.html)

**OpenCMS Cross-Site Scripting vulnerability**  
_2025-04 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2024-42699`, `CVE-2024-5520`
CWEs: `CWE-79`

Cross Site Scripting vulnerability in Create/Modify article function in Alkacon OpenCMS 17.0 allows remote attacker to inject javascript payload via image title sub-field in the image field

**Affected:** maven/org.opencms:opencms-core  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
