### INC-11215  [↗](/incident/INC-11215.html)

**ESPHome vulnerable to remote code execution via arbitrary file write**  
_2024-03 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2024-27081`
CWEs: `CWE-22`
CVSS: **7.2** — `CVSS:3.1/AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:H/A:H`

### Summary Security misconfiguration in edit configuration file API in dashboard component of ESPHome version 2023.12.9 (command line installation) allows authenticated remote attackers to read and write arbitrary files under the configuration directory rendering remote code execution possible. ### Details It is possible to abuse this path traversal vulnerability both in command line installation and Home Assistant add-on, but it is possible to read and write files only under the configuration directory.
