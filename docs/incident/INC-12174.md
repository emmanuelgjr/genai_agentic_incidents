### INC-12174  [↗](/incident/INC-12174.html)

**Jenkin allows attackers to obtain passwords by reading the HTML source code**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2014-2061`, `CVE-2014-2065`, `CVE-2014-2067`
CWEs: `CWE-79`

The input control in PasswordParameterDefinition in Jenkins before 1.551 and LTS before 1.532.2 allows remote attackers to obtain passwords by reading the HTML source code, related to the default value.

**Affected:** maven/org.jenkins-ci.main:jenkins-core, maven/org.jenkins-ci.main:jenkins-core  
**Attack vector:** `other`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
