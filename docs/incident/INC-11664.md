### INC-11664  [↗](/incident/INC-11664.html)

**XML External Entity Reference in ureport**  
_2023-02 · vulnerability-disclosure · Severity: High_

CVEs: `CVE-2023-24187`
CWEs: `CWE-611`
CVSS: **7.8** — `CVSS:3.1/AV:L/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H`

An XML External Entity (XXE) vulnerability in ureport v2.2.9 allows attackers to execute arbitrary code via uploading a crafted XML file to /ureport/designer/saveReportFile.

**Affected:** maven/com.bstek.ureport:ureport2-core  
**Attack vector:** `rce`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
