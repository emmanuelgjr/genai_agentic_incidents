### INC-12157  [↗](/incident/INC-12157.html)

**Djblets Cross-site scripting Vulnerability**  
_2022-05 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2014-3994`, `CVE-2014-3995`
CWEs: `CWE-79`
CVSS: **6.1** — `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N`

A cross-site scripting (XSS) vulnerability in `gravatars/templatetags/gravatars.py` in Djblets before 0.7.30 and 0.8.x before 0.8.3 for Django allows remote attackers to inject arbitrary web script or HTML via a user display name.

**Affected:** pip/Djblets, pip/djblets  
**Attack vector:** `xss`  

**OWASP LLM Top 10:** `LLM03`, `LLM05`  
**OWASP Agentic (ASI):** `ASI04`, `ASI05`  
**NIST AI RMF:** `GOVERN-6.1`, `MEASURE-2.7`  
**MITRE ATLAS:** `AML.T0010`, `AML.T0050`
