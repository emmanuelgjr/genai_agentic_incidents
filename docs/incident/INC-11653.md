### INC-11653  [↗](/incident/INC-11653.html)

**Grafana vulnerable to Stored Cross-site Scripting in Text plugin**  
_2023-03 · vulnerability-disclosure · Severity: Medium_

CVEs: `CVE-2023-22462`
CWEs: `CWE-79`
CVSS: **6.4** — `CVSS:3.1/AV:N/AC:H/PR:L/UI:R/S:U/C:H/I:H/A:N`

### Description On 2023-01-01 during an internal audit of Grafana, a member of the security team found a stored XSS vulnerability affecting the core plugin "Text". The stored XSS vulnerability requires several user interactions in order to be fully exploited. The vulnerability was possible due to React's render cycle that will pass though the unsanitized HTML code, but in the next cycle the HTML is cleaned up and saved in Grafana's database. ### Impact An attacker needs to have the Editor role in order to change a Text panel to include JavaScript. later, an another user needs to edit the same Text panel, and click on "Markdown" or "HTML" for the code to be executed. This means that vertical privilege escalation is possible, where a user with Editor role can change to a known password for a user having Admin role if the user with Admin role executes malicious JavaScript viewing a dashboard. ### Impacted versions Grafana versions between 9.2.0 and 9.2.10. and between 9.3.0 and 9.3.4 ### Solutions and mitigations Update your Grafana instance. ## Reporting security issues If you think you have found a security vulnerability, please send a report to security@grafana.com.
